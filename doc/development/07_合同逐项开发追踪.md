# MOP平台合同逐项开发追踪

版本V0.1，2026年9月30日。下表逐行来自实际合同DOCX的功能表，共128项；它连接合同、开发步骤和待执行验收，不表示实现或验收通过。

每项功能按以下顺序执行：读取合同原文与验收 → 按02对应模块步骤建模及接口 → 实现页面和领域逻辑 → 接入已批准适配器 → 执行正向/权限/边界/异常用例 → 关联证据后更新状态。01的D编号规定跨模块先后顺序。

模块关联Q仅为查阅索引，不代表每项需求都受该模块全部Q阻塞；具体暂停动作以04各Q的‘必须暂停’和02冻结点为准。合同固定部分可以先实现。所有需求优先级、负责人、实际结果及证据暂留空，客户未确认的可选项不自行删去。

原文及表格定位见 [合同原文数据](evidence/contract_requirements.json)，具体步骤见 [模块开发](02_模块开发步骤与页面交互.md)，通用执行见 [开发顺序](01_开发顺序与任务拆解.md)，验证流程见 [测试验收](06_测试验收与交付步骤.md)。
