判断分为四类：

- **差距**：已有明确代码门禁、实现范围或证据表明合同完整行为未交付；可能已有可用子功能。

“未见”仅指本次检查的实际API、路由、源码及仓库证据范围，不等于证明其他系统不存在此能力。静态原型和纯算法通过均不视作业务整链完成；所有待验行仍需按对应`TC-Mx-y`执行。
