# 本人账号读取与口令表单范围防护

2026-10-06，基于6b7fd11/API0.45。本人账号页增加独立范围校验，包括账号、租户、角色、权限/账号版本、能力集合、上下文代次与切换状态。范围变化时取消旧读取，清空账号信息、三个口令输入、错误及命令展示。未登录或切换中不读取；账号响应ID必须与当前本人一致，否则拒绝展示。

每次重新读取独立分配代次与取消信号，防止晚到旧响应覆盖新内容；读取失败不保留旧改密表单。新增明确重新读取按钮，放弃草稿确认结束后复核原范围。提交前核验当前身份、已读取账号归属、启用状态、本地用户名和加载状态，保留服务器授权、CSRF、CAS及幂等约束。

新增10项Vue/Element Plus-jsdom隔离回归。最初8项旧实现全失败；最终1801项Web/111文件、类型检查、构建、127契约与生成一致性通过。覆盖登出清理、旧身份响应、错误账号ID、上下文变化、切换期间、确认竞态、保留提交事件、刷新竞争及失败清理。正常App已有重挂载防线，本次不冒充线上泄露复现或真实改密验证。

没有操作真实账号、密码、部署或数据库；API0.45与SQL未改变。真实浏览器、联调与上线门禁仍需单独验证；正式128项保持NOT_RUN。见[证据](evidence/niko-account-read-scope-20261006.json)。
