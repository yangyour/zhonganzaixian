# 维保与超期日期核算：原资产恢复与焦点

资产详情既有日期核算面板增加显式取消和重试原资产入口。核算仍仅为只读日期对照：未登记保留 null/待定，不推断维保覆盖、提醒送达或工单创建，不增加业务默认日期。

## 修复

- 正在读取时普通核算按钮禁用，取消入口可用；取消立即中止读取并清旧数据，恢复目标仍为原资产。同一范围内失败/取消不降低已核验最高资产版本。
- 重试仅在已有尝试时可用，沿用原资产 GET；服务端重新提供当次基准日，不承诺跨日重放旧快照。
- 账号版本、角色/模式/能力集、租户、权限、资产版本、上下文变化同步清理数据及恢复状态。旧 finally 不清新请求的 busy。
- 通知回调可能同步换范围并开始另一读取，现使用原请求自己的 AbortController，并在发送前重新核对 epoch。修复前回归能复现额外旧资产 GET。
- 结果/错误/取消分别聚焦结果区/错误组/标题，主动移开焦点不强抢；状态播报、命名区域、44px按钮和小屏换行。同步更正原提示中与实际按钮不一致的维保入口名称。
