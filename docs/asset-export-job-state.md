# 异步台账导出：命令、租约与存储不确定性模型

## 本次仅为纯领域模型

`AssetExportJobState` 不创建数据库任务/operation，不启动Worker，不发送OSS请求，不生成签名或下载token，不发送站内信。状态SUCCEEDED仅表示显式传入的存储回执描述与已保留的编码信息吻合；`actualStoreVerified=false`、`persisted=false`、`notificationSent=false`。它不能作为真实组件成功证据或独立授权边界。

## 命令与读取范围

命令固定租户、请求人、受理时成员版本/角色及当前台账的type/status/site/q筛选；不接受分页游标作为整份导出范围。过滤值复用实际台账校验，不trim、不转大小写、不猜字典。长度前缀UTF-8指纹区分null/空串、分隔符文本、租户/人员/角色/版本变化，供未来幂等事务使用；目前没有实际幂等表或唯一键执行证明。

模型使用当前内部资料读取的padmin/msp边界，并要求当前成员仍活跃、同租户同请求人、版本和角色与原命令一致；外部租户/其他请求人404，失效/变化401。角色/版本由调用方明确提供，模型不查询PG；未来每次领取、读取、存储确认与下载仍须从真实身份/资源仓储复核。Q09有效矩阵与资源维度不能用该输入对象冒充。

## 转换与故障边界

- QUEUED→RUNNING须明确服务器时间和租期；无默认租期。只有到期后可接管，fence递增、历史追加，旧fence和到期边界不能准备或完成存储
- 准备编码后保留筛选快照hash、文件hash/字节数/行数/生成时间，后续不能改写为另一份快照或文件
- 上传结果不明进入RECONCILING_STORAGE；不允许盲目再传。即使旧状态仍RUNNING，只要已准备编码，租约接管也强制进入核查，覆盖“上传成功但来不及记录未知就崩溃”的窗口
- 只有明确的实际存储“已不存在”核查才能声明允许重传同一份保留编码；403/超时不等于不存在。模型中的该方法是输入声明，真实HEAD/哈希/权限核查尚未实现
- 存储回执必须匹配租户/job、文件hash、字节数及时间；可在核查中确认原成功，不必重新编码。objectId仍需未来仓储/存储适配器验证，格式一致不证明对象存在
- 上传资格本身也复核当前成员/fence/租约时刻，不提供无时刻的永久“可上传”标记
- 已确定失败终止，不自动设置重试预算或退避。存储不确定时只接受明确存储拒绝或授权变化，不能用无关本地错误掩盖未知存储结果
- 当前成员缺失/变化时，未来Worker可对排队或租约已过期的任务登记授权失败；不能抢占仍有效的其他租约，不能改写已完成结果。准备过编码的失败保留可能孤立对象的复核提示，不执行删除

这是不可变快照和逻辑版本比较，不是实际数据库CAS、租约锁、崩溃恢复或竞争执行证明。1000次历史、最长10分钟租期与编码1000行/16MiB是技术边界，不是授权1000次重试或用户资源配额。编码库复用同一行数/产物字节上限，原导入500行约束不变。

## 下载门禁

只有匹配的成功描述且当前授权仍有效时，计算900秒窗口。它不返回URL、签名、密钥、下载许可或对象地址；后续仍须当前对象授权、真实存储和审计。过期成员、错误租户/请求人、旧权限版本、未完成任务不能得到窗口。当前窗口计算通过不表示15分钟链接已实际可用/失效验收通过。

## 验证

31项纯状态/边界测试，包含1项“准备后租约接管仍能盲传”的缺陷回归先红后绿；覆盖hash指纹、null/空串、角色/版本、时间倒退/溢出、fencing、准备信息不变、未知存储核查、授权撤销、1000次有界历史及900秒计算。无新增真实任务、存储或下载链接测试。完整回归结果见 [证据](evidence/niko-export-job-state-20261004.json)。

## 2026-10-04 版本化命令恢复与持久化绑定准备

`AssetExportCommandCodec` 将原有指纹输入提升为可双向恢复的固定v1格式：9个字段，4字节大端UTF-8字节长度，-1表示null。magic、租户、人员、成员版本、角色、type/status/site/q的顺序与此前指纹完全一致；独立黄金向量证明没有改变已发布指纹语义。每次返回独立数组，输入复制后解码；严格UTF-8、字段512字节/整包4096字节技术上限、尾随数据、非规范UUID/整数、必填null及非法筛选均拒绝，不记录原文字段。上限并非业务配额。

`decodeBound` 要求另传不可变的持久化受理列和原SHA256，拒绝其他租户/人员（404）、角色/版本/active或摘要不一致（409）以及非法绑定输入（400）。SHA256只是内容一致性校验，不是签名、MAC或权限证明；受理列也不是当前成员权限。未来真实Worker仍必须读取当前成员、资源授权并调用作业授权检查，不能把解码得到的Access直接当作当前身份。

新增21纯测试，涵盖所有截断前缀、500组固定种子随机字节、非法长度/UTF-8、规范化歧义、null/空串、固定指纹及绑定冲突。首次17项测试暴露必填UUID为null时抛NPE，保留失败日志并改为显式400。无新API/迁移/实际持久化/Worker/OSS/下载/通知；完整回归见[编解码证据](evidence/niko-export-command-codec-20261004.json)。
