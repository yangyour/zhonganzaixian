# 资产导出读取取消、原请求恢复及父子状态保护

## 用户可见变化

- 作业列表、分页和详情加载时可独立取消读取，回到可操作状态并把焦点移到状态说明；保留筛选草稿、原提交身份与原受理回执。
- 失败或取消后可重试原列表游标或原任务ID，即使列表已清空也不会退回第一页。新明确选择替换旧读取目标，身份切换/卸载/新建编辑会清除旧恢复。
- 取消读取同时暂停本页准备进度自动刷新；手动重试不重新开启自动刷新。它不撤销后台导出、发布、下载授权或任何已经提交的命令。
- 未知提交仍只能按原key/body恢复；读取成功不等于原提交确认，不解锁原请求，也不新增导出。
- 子发布/下载面板仍有未确认请求时，父页面不能通过列表刷新、另选任务、重置或新建导出卸载它。父读取/离开确认进行时，保留的子面板暂时禁用发布、授权和刷新按钮，避免形成竞争操作。

## 实现与验收约束

读取目标保存原游标与ID，不保存或生成下载链接。取消增加代际并中止前端AbortController，迟到响应不能恢复旧事实。成功读取清除恢复目标；无效本地ID不显示虚假的重试。

同时补齐工作区同步状态回调后的发送前检查、幂等key生成前后原epoch检查；旧身份的命令不能借用新身份，旧异常不能覆盖新状态。这不替代后端当前授权。

沿用[前端验收标准](frontend-acceptance-standard.md)的可取消、明确错误、原命令恢复、上下文隔离、可见焦点、未知不当零和无自动发布门禁。按钮使用原生语义及44px最小高度；DOM测试不代替真实键盘、读屏、CSS、移动端或WCAG整体验收。
