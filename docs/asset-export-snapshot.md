# 台账导出：完整筛选与同事务资料快照

## 范围

`AssetExportSnapshotRepository` 由现有 `PostgresManualAssetMetadataRepository` 实现。只读取既有PG，不增加API、作业表、Worker、OSS、下载或通知。调用前的命令编解码/受理绑定不能替代这里的真实成员检查；实际发布仍须另行重新核对当前权限。

## 读取语义

- 独立单连接、只读REPEATABLE READ事务，拒绝在平台写事务中调用。成员活跃状态、当前角色和版本、ID筛选及所有手工资料都使用同一事务快照；不会逐行重新打开连接拼接不同时刻的数据
- 角色仅沿用当前内部资料范围padmin/msp，复核数据库实际角色与受理命令完全相同。伪造客户成员为内部角色仍403；缺失/旧成员版本/原内部角色已变更401
- type/status/site精确匹配，q使用主台账相同的ICU名称小写字面子串或区分大小写的地址字面子串，且条件AND组合。百分号、下划线、引号不解释为模式/SQL。包含全部来源，不能误变成只导出manual
- 固定租户谓词，按created_at/id升序。一次取最多1001个ID，超过1000则整个读取413；没有静默截断、翻页后拼接或部分成功返回。1000是技术编码边界，不是业务配额
- 逐项复用既有资料指针/历史和核心漂移检查；缺失资料仍保留资产基础事实与null。Selection列表不可变，禁止重复资产或混入其他租户
- transactionStartedAt是数据库事务起始时间，保留PG微秒精度，不称为实际采样时间、业务更新时间或精确MVCC快照建立时刻。快照完成后发生权限撤销不会追溯取消该读取；未来上传和下载必须重新授权
- 这里没有向客户端开放导出端点，也没有以即时文件下载绕过异步作业与审计

测试严格区分真实PG读取和隔离边界替身。现有数据来自独立niko测试库；本批新增读取测试不创建资产、账号或授权。详细结果见对应证据文件。原库/OSS/故障Worker及完整M3-7合同验收仍未完成。
