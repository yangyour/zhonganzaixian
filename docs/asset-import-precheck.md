# 资产导入逐行纯预检

`cn.mop.domain.assetimport`接收已解析行，保留M3-6的15个标准字段、原始行号、原值、规范值、原因和修正建议。它实现500行上限、批内/库内同名及五类ERROR、三类WARNING的计算；无效日期和非本租户负责人置null，已核验无OID映射的品牌提示仅可用性。备注明确必填，其他必填集合由调用方提供，不擅定15列全部必填。

调用方须从服务端建立获授权租户、完整字典、名称/IP冲突事实和明确的解析规则。缺事实、缺客户规则、歧义字典或日期保持CONFIG_PENDING；不安全租户和无法核验的站点为单独的引用阻断，不冒充合同警告。Q20最终九类名称、Q31冲突域及规范化策略没有被此核心批准；纯测试的合成词典不表示客户确认。真实来源、版本和证据资格仍须由接入层核验。

地址只做纯格式检查，不查询DNS、不验证可达性或地址所有权。JDK URI/IDN支持IPv6及明确的IDN策略；前导零、IPv4映射、单标签、尾随root dot和旧式数字地址歧义均由显式策略决定。日期使用严格JDK格式（例如`uuuu-MM-dd`）和`LocalDate/null`，没有1970年或默认负责人。输出防御复制且不可变；可见原值只来自本次输入，不附带跨租户字典对象。
