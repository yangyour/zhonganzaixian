# 台账导出 XLSX 编码基础

## 实现范围

M3-7新增独立普通Java库 `server/asset-export`，复用工程已有Apache POI5.5.1。不接入API/Worker、不读取数据库或私有配置、不连接OSS、不创建URL或站内信，不改变无凭据导入解析进程的职责。

合同导入模板15列已经包含“维保到期日”，导出编码逐列复用同一标签/顺序，只追加“维保状态”，合计16列；不重复添加同名到期日列。与已提交标准XLSX模板实际读取逐列比对。它不是当前筛选结果的正式导出流程。

输入是显式租户、逐条资产ID、含全部15键的字符串/null集合、显式维保状态、完整性声明和生成时间。所有行声明的租户必须一致、资产ID不得重复；完整性false/null拒绝编码。该检查不核验真实数据库授权或筛选完整性，调用者填true不产生权限。未来提交作业、执行查询、下载都必须重新授权，不能把编码库作为授权边界。

## 文件事实与安全边界

- null保持空白单元格，空字符串和“0000”等原文保留；不填0、不将日期或长序号转换成浮点数字
- 所有非空数据用POI字符串单元格与文本格式；以=、+、-、@开头的内容及HYPERLINK外观文本仍是文字，不创建公式/超链接/外部引用/宏
- 保留Unicode、首尾空白、备注中的换行/制表；拒绝XML非法控制字符及孤立UTF-16代理，不在异常或日志回显输入
- 维保状态与日期均按调用者原值编码，不从到期日声称服务覆盖已核验
- 顶行冻结、自动筛选、固定列宽和换行样式已设置；尚未在Excel/LibreOffice或实际浏览器渲染验收
- 显式生成时间写入属性，ZIP条目时间规范化；同输入/同生成时间在固定当前工具链重编码字节一致。跨POI/JDK版本不承诺相同字节，未来作业仍须保留首次产物hash与存储结果
- 返回字节副本及SHA256；调用者修改返回数组不能改内部结果。文件属性为ENCODED_NOT_PUBLISHED，不声称已发布/送达/可下载

技术资源上限为1000行、每单元格2000 Unicode码点、原始文本总UTF-8 8MiB、产物16MiB；超限失败，不截断导出。它们不是导出业务规模/SLA承诺，也不改D05导入500行约束。数据仅作为显式传入内存对象，库不自行持久化临时文件。普通库JAR不嵌入POI类，不增加API/Worker依赖；将来实际分发仍需整体依赖许可证清单。

## 本次验证与未完成链路

17项纯编码测试实际生成/回读XLSX并检查ZIP/XML，覆盖15+1表头与到期列不重复、公式外观文本及外链/宏不存在、null/空字符串/前导零、Unicode、声明跨租户404/重复资产、完整性缺失、输入资源上限、1000行完整编码、不可变字节/SHA和间隔1.1秒重编码一致。

这些是文件格式/显式输入检查，不是实际资产筛选授权集成。异步202作业、真实筛选快照、对象存储不可覆盖上传、下载再授权及审计、15分钟到期链接、站内信送达、故障重启和完整M3-7仍未实现或未验证。OSS受控认证、通知组件及业务决定缺口继续保留，不提供直接浏览器下载绕过合同。
