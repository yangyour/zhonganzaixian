# 资产扩展资料：原读取恢复与保存回读隔离

## 已补齐

- 资料/修订历史与站点/负责人候选分别记录原读取目标。历史失败重试保留原before_version，不因当前档案更新静默改读首页；候选失败重试保留原查询文字，不采用后来输入的新搜索词。
- 读取可取消，旧响应及finally不覆盖新请求；取消只针对GET，不中止PATCH，不清未知保存的原key/body/version或当前未保存输入。候选读取失败/取消不清已核验档案和历史。
- 当前档案已核验更高资产/资料版本后，即使历史失败也保留最高已见事实；拒绝回退、同版本事实变化、资料版本被清除及创建时间改写。旧命令有效回执单独保留，不冒充最新档案。
- 每次GET/PATCH使用发送前捕获的固定资产范围；通知回调或幂等key生成期间换范围即停止旧请求。先复制原输入再调用key生成器，准备失败明确未发送且不泄露异常文字。
- 已接受保存后的读取取消仍保留原保存回执；只有当前表单仍与实际提交字段/基准相同才清空，后来新输入继续保留。原未知重试采用原payload，不替换成后来表单。
- 账号版本、角色/能力/模式/权限/租户/资产范围变化同步清理；组件卸载后读取器不可复活。只读取消/重试、具名错误组、候选原查询说明、历史原边界说明及成功/失败焦点分别实现；主动移开焦点不强抢。
