# 资产列表与详情读取范围保护

基线main：d47048579498f9c05f3347e120e28513af2eacc6。API0.73.0与V1–V45不变。

## 改动

- 列表与详情使用独立生产读取器：核对租户、详情目标ID、UUID、可安全表示的正版本、设备/状态枚举、IP字面量、UTC时间顺序、独立可用性字段及已知字段集合。
- 列表额外核对当前模式对应的数据来源、技术页上限、游标/has_more一致性、请求页大小和重复资产。明确空结果是0；无权限、读取中、失败或格式不符均不是“0条成功”。
- 缺失可选availability/sync_state不补推断值；sampled_at=null保持未知，不借updated_at充当采样时间。正常资产状态也不推断外部纳管或全平台健康。
- 页面内监控租户、操作者、角色、模式、权限版本、账号版本、读写能力与切换状态；变化时中止旧请求，清空列表、详情、选择、侧面编辑入口和未应用筛选输入。仍有读权限时按URL中明确应用的筛选重新读取。
- 无读权限或切换租户时隐藏资产工作区。卸载递增读取代次，忽略不遵守abort的迟到响应。父布局重挂载和API通用取消机制之外，页面仍有自身边界检查。
- 旧资产的接入检查错误不能写入新资产详情；重复检查与失去写权限时不发请求。此接入接口仍是现有待配置检查，不开始真实纳管任务。
- 全局页脚移除无实时证据的“系统服务运行正常”断言，改为以当前授权接口实际回读为准。

## 验证

保留既有14项资产/列表交互测试，新增读取器、权限变化、错租户/错目标、卸载和旧操作竞态测试，并回放5份真实HTTP响应。已有合成资产fixture改为符合公开接口的UUID和列表元数据，不为适配旧测试降低读取校验。

本地独立PostgreSQL/API生命周期执行17项真实HTTP检查：租户A资产10+8分页、详情、空结果、租户B读取、匿名401、跨租户详情404、覆盖租户/错误页大小/其他上下文游标400。成功GET的105表指纹不变；拒绝只允许安全审计变化。API及数据库随后停止，临时数据库与凭据移除。无资产写入或真实设备采集。
