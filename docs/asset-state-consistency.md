# 资产台账与详情状态一致性

## 代码路径发现与修复

旧台账可用性列只读availability，详情标题却把独立的历史汇总status传给StatusTag。若响应同时为status=ok、availability=UNKNOWN，旧详情会显示“正常”标签，而台账仍显示“未知”。这是根据源码与合成响应边界确认的可触发显示矛盾，不宣称已从真实监控设备复现。

现将详情改为AssetStateFacts，分别复用assetLedgerCell的availability和sync投影。缺失显示“—/当前接口未提供”；未识别代码保持“未识别状态”及原代码文字，Vue按文本转义，不从汇总status、生命周期、更新时间或另一个状态推断正常。当前已接入代码只明确识别UNKNOWN与PENDING_ONBOARDING；没有借此补造其余5态来源、同步/漂移引擎或未确定的上游代码映射。旧汇总筛选仍使用原status查询参数，标签澄清为“汇总状态”，不偷换为实时可用性过滤。

详情采样时刻也复用台账的严格UTC检查，日期非法/格式异常时不会直接交给Date归一化显示成另一天；为空不借更新时间补充。原SampleFreshness与只读刷新、权限/租户请求保护保持，不新增网络或写入。
