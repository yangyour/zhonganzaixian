## 结果不明与读取接口

新增 `GET /api/v1/assets/import-sources/{id}/cmdb-imports`。PostgreSQL只读可重复读快照中核对活动成员、权限版本、`assets:write`、内部角色和来源创建者，再读取同租户/主体/确切路由的不可变幂等回执。跨租户、其他创建者统一404，客户/只读角色403；拒绝查询覆盖。数据不一致、数据库异常返回503，不返回空态替代。

结果为 `COMPLETED` 与原始回执，或 `NO_COMMITTED_RECEIPT` 与null；`absence_proves_failure=false` 固定。没有已提交回执不能证明在途请求失败。GET不创建资产或新的导入回执，拒绝请求仍走统一安全处理；幂等键本身不对外返回。

提交前在当前标签页 sessionStorage 保存最小恢复信息：主体/租户/来源ID、产物ID、原键、来源版本/解析摘要、记录/行号。不存单元格、业务回执、口令、Cookie或CSRF。恢复记录按范围严格解析；存储失败或记录损坏时禁止新建写请求。所有实际授权仍在服务器完成，浏览器存储不是权限依据。

网络错误、超时、未知/损坏成功响应、取消等待均保留原请求为不确定。重试使用原体和原键；不确定请求的重试即使被拒绝，也不能据此改称原请求失败。重新读取回执、关闭重开抽屉、整页刷新后重新打开来源均可恢复。首次明确拒绝才允许用户显式重新读取并准备新请求；没有自动提交或自动换键。

“停止等待”只停止浏览器等待，不取消数据库事务。存在不确定请求时禁用重新选择来源/解析/映射，并阻止正常离页或切租户；强制上下文变更立即清除展示和忽略迟到结果。确认后的回执仍标明提交时配额；不能冒充当前剩余量。
