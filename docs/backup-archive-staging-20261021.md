# 原加密信封持久化与归档任务日志

## 实现与边界

新增 BackupArchivePayload 规范结构载荷，以及 PostgresBackupArchiveRepository 和显式 V48 迁移。原编码信封在任何对象存储派发之前保存，按租户/设备/运行/尝试/版本绑定，完整原字节不可更新。每个运行尝试只允许一份原信封，不能用重新加密后的不同字节替代；密钥引用不是密钥，库内没有原始配置或明文数据密钥。

结构解析核对长度、规范UUID/UTF编码、算法、范围、摘要和尾部边界，不自称通过AEAD认证。仓储必须注入当前授权器、信封真实性验证器、对象/未派发证据验证器，没有默认放行实现，也没有Spring自动装配、API、定时器或后台上传。

- stage 先在事务内授权并核对当前RUNNING尝试，再关闭事务执行完整认证，随后在新事务内重新授权、锁定设备并检查版本，最后一起保存原信封与STAGE事件。
- 数据库延迟约束要求原信封和初始事件同时提交，单独保存原信封会在提交时失败并回滚。两张表都是持久表，仅运行角色SELECT/INSERT；更新、删除和TRUNCATE均不允许。
- 幂等提交绑定原请求标识与原内容；重复返回原命令的原回执，而不是把当前最新事件伪装成原请求结果。每次重放仍必须通过当前授权。
- START_STORE只追加派发事实，不自行调用PUT，不是设备或对象存储执行授权。派发后进程丢失、超时或未知结果保持STORE_STARTED/VERIFY_REQUIRED，只能核查原请求，时间流逝不产生重试许可。
- CONFIRM_NO_DISPATCH必须由独立验证器证明原派发没有在途或已提交的PUT，才允许回到STAGED；单纯缺对象、哈希字符串、租约超时均不是证明。重派需要全新派发UUID，旧UUID不得在历史或其他任务复用。
- VERIFY_OBJECT要求实际读取原对象并完成认证。外部证据查询在SQL事务外进行，返回后再授权和CAS；旧证据不得覆盖并发产生的新事件。
- VERIFIED是当前核查事实，不等于永久存储健康、版本登记、备份运行完成、设备停止或保留策略批准；对应权限标志仍false。后续读取还需重新认证与授权。

新派发要求父运行仍处于同一次RUNNING尝试；原对象只读核查不修改父运行，也不释放设备租约。数据库时钟产生毫秒事件时间，不接受客户端时间；时钟倒退拒绝提交。

## 迁移与数据库核验

显式入口 --apply-backup-archive-staging 只允许从已验证V47进入V48；默认 --check 不修改数据库。Python和PowerShell入口均登记相同版本，Windows要求最新编译的结构核验器。

V48已由隔离PostgreSQL 17.11上的Flyway实际提交，SHA256为3dcb7d51572b6bad4d655e7814ba9d8b1d3f312b7ea23ad4a8753d1355e310da，之后不可修改。V1–V47保持原字节。

新增mop_backup_archive_submission和mop_backup_archive_event两表，总表数109。重复迁移与只读检查后所有表指纹不变；新增结构时既有业务表未改，仅Flyway历史追加。结构核验覆盖列/空值约束、全部约束定义、索引、三处触发器/函数、延迟约束、表持久性及权限；改变时区后仍可核验并恢复调用者会话设置。

[实际应用、仓储与清理证据](evidence/backup-archive-staging-20261021/flyway-attempt-1/summary.json)。最初catalog probe仅在事务内执行并回滚，不作为实际迁移通过证据。

## 测试范围

- 10项规范载荷测试：独立加密向量、复制隔离、篡改摘要不能代替AEAD、所有截断位置、尾部字节、超限长度、非规范UUID/UTF、范围与算法。
- 6项仓储参数/依赖/异常边界及3项迁移门禁测试。
- 隔离PG/JDBC执行48项检查，包括真实GCM认证、数据库独立连接并发CAS、源与事件原子性、幂等原回执、未知不重派、认证后撤权、外部核查期间状态变化、运行角色不可修改及连接关闭。
- 9项实际结构检查，包括原结构、时区独立性及7种篡改拒绝后回滚。所有结构测试前后表指纹不变。
- 新仓储实例读回原字节已验证；没有把它称为实际主机崩溃/断电/存储故障恢复测试。
- 真实授权/未派发证明采用明确合成适配器，对象核查测试只认证已存的合成密文，不代表真实OSS对象读取、KMS、供应商回执或真实设备验证。上一切片的独立HTTP路径证据不与本次拼接成完整生产链路。

专项测试代码在BackupArchivePostgresTest和BackupArchiveSchemaPostgresTest，普通Maven默认跳过，只有显式MOP_BACKUP_ARCHIVE_TEST_ENVIRONMENT=dot-backup-archive-disposable才启用。临时数据库仅回环监听，测试结束已停止并清除临时库与凭据。PowerShell原生执行环境不可用，语法/入口通过源码契约测试，实际Windows执行仍NOT_RUN。
