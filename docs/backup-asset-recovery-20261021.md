# 备份草稿候选设备恢复与确认输入保护

## 本次可用性修复

- 候选设备查询失败或取消后，显式重试原查询与原游标，不悄悄回到第一页。修改查询立即作废旧重试；原页候选清空，不能误选旧结果。
- 候选读取有独立取消按钮，位于禁用字段集之外。取消仅中止该GET，保留计划名称、时间、凭据引用、启用意向、备注及明确目标顺序，不影响另一个草稿详情读取。
- 取消后DOM焦点回到查询按钮；加载、取消和成功分别说明状态，错误不冒充空结果。候选只表示登记身份，不证明在线、SSH授权或备份成功。
- 发出GET之前再次检查上下文、权限和取消信号；账户版本或资产能力变化使旧结果、旧重试和旧编辑范围失效。
- 替换、关闭、离开及归档/恢复确认均绑定原始输入快照。确认期间新编辑使旧确认失效，保留新输入；包含原始凭据引用大小写，不只比较规范化请求体。
- 未知写入仍保留原key/body和锁定状态。候选读取取消/重试不代替原写入核验，不解锁或新建命令。
