# 备份草稿原页恢复与取消读取

基线 main 8284eae902ff28e13107ab9295290d6375f1f791。依据 frontend-acceptance-standard.md 补齐只读流程，草稿仍未启用，不新增设备连接、备份任务、凭据配置或外部存储写入。

- 保留明确的列表游标、计划ID或历史before_version。失败后“重试原草稿读取”重放同一GET，不悄悄回到第一页或当前历史头。
- “取消读取草稿”中止网络并隔离迟到响应，解除只读忙状态；随后可重试原读取。取消状态获得键盘焦点，账号/范围变化或卸载后不会迟到抢焦点。
- 未保存表单、原写入请求、幂等键和已保存回执均不由取消/重读清除。POST/PATCH不能用读取取消入口取消；读取成功仍不能确认结果未知的写入。
- 新写入、开始新编辑、上下文重置或卸载清除旧读取恢复目标，不能复用另一租户的页游标。
- 草稿页与指定日期预览均直接监听账号版本；指定日期取消后的焦点恢复也受请求世代约束，不影响新账号上下文。
