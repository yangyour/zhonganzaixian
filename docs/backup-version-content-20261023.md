# B01.3 已登记版本下载、解密与脱敏差异

按用户停止开发要求收尾已有独立功能，不再扩展后续需求。本功能提交到备份分支，由集成会话统一决定主干集成；没有部署、真实对象访问或设备操作。

## 实际接口与页面

- `GET /api/v1/assets/{assetId}/backup-versions/{versionId}/content?format=envelope|plaintext`：默认密文信封，完整核对后作为附件返回。明文只作为文件下载，不进入页面或日志。
- `GET /api/v1/assets/{assetId}/backup-versions/diff?before_version_id=...&after_version_id=...`：两个版本必须明确、同租户同设备，查询仅接受这两个参数，拒绝重复字段及超过2048字符的查询。比较是只读计算，每次重新授权并追加访问审计，不创建业务写入回执。POST等写方法不支持，仍经过既有CSRF过滤。
- 现有资产详情的版本面板已接入 `BackupVersionAccessPanel`。下载格式需要明确选择，差异只显示行位置和数量；支持取消、原参数重试、上下文变化清空结果及拒绝迟到响应。可输入已知历史版本UUID以比较跨分页版本。

独立API契约源为 `tools/backup-version-content-contract.mjs`，已接入统一生成器，保留最新DEMO契约。版本列表运行绑定标记同步为明确私有授权配置要求，未改变“列表不授予下载”的语义。

## 授权、内容与审计

当前成员必须为内部 padmin/msp，并有资产读取权限；客户角色直接拒绝内容和差异。资产授权回读保证越界对象404，服务端从V49登记及父运行核对原版本，不接受对象URL、KMS引用或浏览器提供的存储路径。

`MOP_BACKUP_VERSION_CONTENT_BINDING` 与 `MOP_BACKUP_ACCESS_GRANTS_FILE` 配置独立授权：密文下载要求 VERSION_READ + VERSION_DOWNLOAD；明文另外要求 VERSION_DECRYPT；差异要求两个原版本READ + VERSION_DIFF + VERSION_DECRYPT，不继承下载或枚举权限。配置、身份、对象和密钥失败均拒绝，没有管理员草稿权限后备。

存储使用既有OSS备份通道。密文下载验证原登记摘要、信封结构和完整范围，不需要解密，也不声明当前AEAD/可恢复性验证。明文需要已配置的真实KMS适配器和完整JCE认证。未知KMS产品仍按Q28保留门禁。正文返回前重新检查独立授权和会话，并先写入“授权读取”审计；审计失败不返回正文。授权读取记录不等同浏览器下载完成。

内容响应使用 `no-store`、`no-referrer`、`nosniff` 及固定UUID文件名附件。拥有的密文/明文字节数组在完成、异常或取消后清理；比较输入副本也提供关闭清理。差异沿用成熟有界算法：超过字节上限拒绝，未知/取消/计算超限不归为一致；不支持的文本编码返回422，不猜测转码，不应用未批准噪声规则，不自动报备、批准变更或建单。
