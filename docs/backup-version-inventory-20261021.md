# 已登记备份版本的独立授权分页查询

## 交付范围

在既有PostgresBackupVersionRepository增加设备范围的inventory查询，复用V49登记、原信封、归档事件、父运行成功及命令摘要核对。没有新增DDL、HTTP接口、Spring自动装配、前端菜单或下载入口；V1–V49保持冻结。

查询必须提供独立InventoryAuthorizer，不能借用计划草稿读取权限。先检查设备级列表授权并锁定该设备，逐项复核既有READ授权与完整登记关联（包含仅用于has_more的额外一项），返回前再次核对列表授权；任一拒绝或损坏即整个页面失败，不返回部分数据。即使零行也要授权，设备不存在为404，而不是空列表。

单次查询在自己的数据库事务内，设备锁与注册事务保持既有顺序，序列化同设备登记。不把查询期间的锁描述为永久快照；下一次显式查询可以看到新登记，不能将有限页面拼成固定时点全量或总数。

## 返回与边界

- 按registered_at、version_id降序使用成对游标，游标绑定租户及设备；调用者明确页大小1–50，属于技术上限，不是客户配额。
- 游标时间保持现有数据库毫秒精度及0001–9999边界，不静默归一化超精度。
- 返回版本、设备、运行ID、尝试序号、完成版本、原对象观察时间、登记时间及加密对象摘要/大小。区分观察时间与对象真实创建时间。
- 不返回KMS密钥引用、对象位置、租约owner、内部证明/trace、登记账号或下载链接。
- 仅声明数据库登记与父运行完成关联已核对。当前对象健康、下载授权、设备执行、保留和恢复验证均false；查询不访问对象存储、不解密、不执行设备命令、不调用完成写入证明。
- 授权/游标范围错误清晰拒绝；存储或核验错误为503 BACKUP_VERSION_INVENTORY_UNAVAILABLE，不回显驱动细节，不把纯读取失败说成已经发布或下载。

## 待配置和后续

依赖模板新增backup_version_inventory_authorizer_reference=null；原执行开关保持false。还需当前资产范围列表权限与逐版本权限的真实适配、撤权锁协议及服务装配，然后才能做受保护HTTP/前端列表。下载/解密需要独立权限与安全交付实现，不能通过这个查询自动开放。真实对象健康、恢复演练、保留清理与执行消费者不因本次查询而完成。
