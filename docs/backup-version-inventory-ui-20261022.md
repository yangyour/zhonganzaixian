# 资产详情：已登记备份版本只读面板

## 交付与边界

接入既有资产详情“资产清单”分区（inventory），不新建空全局菜单。沿用 assets:read 作为可见性门禁，后端设备级枚举与逐版本 READ 独立授权仍必需；管理员角色不自动获得枚举权限。后端尚未显式装配真实授权时返回 503，不把示例 null 配置当作已启用。

只展示登记时间、对象观测时间、版本/运行 UUID、尝试及完成运行版本、密文字节数和 SHA-256。不会请求对象存储、下载、解密、触发运行或恢复；无外部对象地址或秘密引用。登记记录不证明当前对象健康、保留策略或可恢复性。

## 可用性与完整性

- 初始不自动请求，明确“尚未查询”；加载期间可取消。错误、未装配、独立授权不足与成功空页分别展示。
- 每页 15 条，下一页使用原登记时间/版本 UUID 成对边界；失败/取消后重试相同原页，可显式回首页。只显示本页条数，总数保持未知，各页不是全局固定快照。
- 全部载荷整次校验：精确字段集、身份/租户/资产/权限版本、固定未验证标志、唯一 UUID、时间毫秒 UTC/真实日历、登记不早于观测、倒序和游标严格前移、大小/版本范围、末行游标一致；异常不显示部分数据。
- 取消、资产替换、资产版本、账号/权限/能力/角色/模式/租户/上下文变化立即清除结果和恢复目标，AbortController 与 epoch 拒绝迟到结果。状态通知同步撤权时不再发送请求；旧 finally 不影响新读取。
- 原生按钮产品目标 44px；具名只读区域、caption、列/行 scope、UTC 完整值、独立可聚焦横向滚动；结果/错误/取消焦点返回，用户主动移开焦点不强抢。
- 组件入口位于既有资产详情，需要用户打开资产清单分区；与维保资料权限独立，不因无 metadata 权限隐藏备份面板。
