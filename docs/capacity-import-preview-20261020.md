# 容量运行参数替换预览

本批由 dot 在自己的云执行空间直接实施，不使用 Codex / Work 任务开发。

## 范围

- 显式导入前逐项展示当前值、替换值、保持 / 替换 / 清空状态。
- 七项配置映射到八个输入位置：每值空间分别列出主模型和 Proxy 缓冲的原值，避免混淆。
- 草稿继续编辑时预览同步更新；仅读取和预览不会修改输入或自动计算。
- 保留十进制原字符串及零值，不转换为 JavaScript Number。
- 未发布或禁用配置仍按原契约在显式导入时清空对应字段，但先明确列出清空数量。
- 租户 / 身份 / 权限变化清除旧快照及预览；同值会话刷新不清空。

没有更改 API、数据库、配置发布内容或测试站。未填写客户业务值，不解除生产验收门禁。
