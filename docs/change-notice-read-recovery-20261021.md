# 变更报备读取恢复与目标选择保护（2026-10-21）

本增量只完善既有草稿任务可用性，不批准变更，不执行设备命令，不启用告警抑制。

## 修复范围

- 草稿列表续页、精确详情、修订历史保存原读取参数；失败后手动重试原请求，不退回第一页，不丢失历史 before_version 及跨页时间/提案连续性核查边界。
- 读取允许取消，旧请求即使迟到也不能覆盖新结果。写入不提供此取消能力；未知写入仍须按原请求重试，GET 不确认写入成功。
- 已确认原收据、未知写入身份、未保存编辑输入都与读取结果分离，不因只读取消/重试丢失。
- 目标资产候选有独立取消/原页重试。原搜索与不透明 cursor 保留，不重新从首页选目标；取消和失败不移除已经明确添加的设备。
- 修改搜索、重新准备编辑、权限/账号版本变化、切租户、卸载会废弃旧读取目标及迟到响应。
- 取消后聚焦可被辅助技术识别的状态说明，恢复按钮采用 44px 产品触控目标。主工作区与目标候选区独立，不跨区取消；候选区域明确显示“取消候选设备读取 / 重试原候选设备读取”，避免同页控件重名。

## 验收映射

遵循 [前端验收标准](frontend-acceptance-standard.md) 的完整状态、安全恢复、账号范围、键盘语义及证据分层要求。新增 8 项工作区测试、6 项原生 Vue DOM 测试、1 项共享恢复组件命名测试，包含原续页、历史跨页错误拒绝、迟到响应、未知写入、原收据保留、单飞重试、候选游标、取消焦点及账号版本变化。

真实浏览器、CSS 视口回流、屏幕阅读器、axe、真实后端联合页面任务未在本增量执行。jsdom DOM、构建和 Vite 模块 HTTP 检查不替代这些验收。
