# 邮件与企业微信配置交互恢复

基线 main：b7eba400e0d286360d347669e9c443c3542037ec。范围仅现有页面的读取、编辑保护和可访问性，不新增通知派发 Worker。

## 修复

- 每次读取前清空旧连接、绑定、发送记录和账号选项；任一并行读取失败中止同批请求，不再保留旧的“连接正常”。错误提供重新读取入口。
- 租户、操作者、角色、模式、权限版本、读写能力变化立即清空私有事实和编辑内容；仍可读取时重新读取。旧响应无法覆盖新范围。
- 绑定字段接入脏数据保护、路由离开和关闭页面提示。刷新确认取消保留输入；旧范围的确认不能清除新范围编辑。无有效读取结果时不可执行写操作。
- 编辑绑定时停用无关连接检查、测试发送和停用操作，避免无关命令成功把未保存内容误标为已保存。保存绑定只清除原上下文对应的输入。
- 测试发送确认后再次核对当前发送开关、收件人、权限及脏数据状态，防止弹窗期间改变目标后误发。这里只执行合成 DOM 测试，未发送真实消息。
- 配置结果缺失 last_check、ready 类型错误、Email TLS/证书承诺不匹配时拒绝展示成功。不是新增完整 DTO JSON Schema 校验器。
- 表格有 caption、列标题 scope、可聚焦的横向滚动区域；按钮与表单控件最低44px。受理不等于送达的说明保留。
