# CMDB 预检问题清单导出

基线 main 38bd6048e6924c5b7e5b86fe1a16b8539ef48f41。为既有本地33列CSV预检和受保护来源校验增加问题清单导出，不增加导入许可、资产写入、上传或数据库查询。

## 用户操作

完成检查后，选择“导出全部预检问题 CSV”或“导出全部服务端问题 CSV”。导出全部已检查问题，不受当前错误/警告过滤或25项分页影响；文件含一条SUMMARY及全部FINDING记录。即使零问题，也保留“不是导入许可”及尚未执行检查的范围说明，不生成伪造正常记录。

- 本地范围为 LOCAL_CSV_DICTIONARY_ONLY，数据库检查 NOT_RUN；CSV逻辑记录不冒充物理源行，source_row为空。
- 服务端范围保留 SOURCE_DICTIONARY_ONLY 或 SOURCE_DICTIONARY_AND_ASSET_NAMES，绑定租户、来源ID、来源版本、parse_hash和相应数据库检查范围。导出前再次核对当前来源，不重新查询数据库或预留资产名称。
- 清单包括记录位置、列标签、级别、代码、说明及统计；不包括原始单元格、完整文件、文件名、凭据或附件。它不能作为导入模板或完整来源备份。

## 文件安全与恢复

UTF-8 BOM、CRLF、逐字段CSV引号转义。可能被表格软件解释为公式的文本显式加单引号；这是复核清单，不声称字节级原文恢复。拒绝不支持的控制字符、孤立代理字符、矛盾统计/范围/身份和超过8MiB的输出，不截断交付。

下载使用固定文件名和短期Blob URL，点击异常时也清理链接并回收URL。失败保留原检查结果，可手动重试；只提示“已发起下载”，不声称文件已保存或允许入库。来源版本/权限变化及清除结果后不能继续导出旧清单。无localStorage、外部传输或新HTTP请求。

补充本地记录定位与清除的异步焦点世代检查，避免旧读取/定位在清除、换目录或卸载后抢焦点。服务端取消同样不把焦点交还给已失效范围。

验证沿用 frontend-acceptance-standard.md，覆盖内容完整性、Unicode/引号/换行、公式中和、大小限制、下载清理、过滤分页、范围失效与失败重试。真实浏览器下载、视觉、axe及128项正式TC仍为NOT_RUN。

结果：新增22项，全量前端3226项/218文件，契约173项，类型检查、构建与静态发布/策略检查通过。[证据](evidence/cmdb-finding-export-20261021.json)。
