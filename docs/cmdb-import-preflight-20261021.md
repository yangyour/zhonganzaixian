# 客户 CMDB 33 列本地预检

基线 main 850e2cd。这是可实际操作的浏览器本地 CSV 检查，不是数据库导入：现有 15 列上传、解析、映射与资产接口不变。

## 已实现

- 由已核验原始 XLSX 生成 33 列最小元数据，不带原始客户行、联系人或计费章节。生成检查绑定目录版本/内容哈希；不允许新旧字典混用。
- 资产字典已读取且当前拥有 assets:write 时展示工具；下载带 UTF-8 BOM 的空 CSV 模板。选择文件只在浏览器内存解析，无上传、持久化、localStorage 或外部地址访问。
- 使用 Papa Parse 5.7.0 解析引号、逗号、跨行单元格、Unicode；保留前导零与原始字符串。非法 UTF-8、二进制/NUL、引号错误、错误表头、超过 1 MiB/500 记录拒绝，不能截断后称全部检查。
- 检查源模板三项必填、九类/十六子类及父子对应、单元格技术上限、ISO 日期有效性。未知日期格式、SSH 冲突、未提供子类、fw_adc 映射、首尾空白、类公式文本和文件内原文重复分别列警告，不自动改值。
- 错误/警告统计可重叠，问题按 25 项分页、按级别筛选；按记录查看全部原值并转移焦点。空结果、错误重试、清除、取消读取、迟到读回、卸载清理均有独立测试。编号指 CSV 逻辑记录，表头为 1，不把跨行单元格算成多条。

## 后续门禁

本地结果固定 canImport=false、databaseChecks=NOT_RUN；零错误绝不是入库许可。下一阶段必须有服务端同租户重新授权、可信站点/成员/业务引用、IP/域名规则、数据库唯一性/并发配额、完整行映射、事务幂等与审计，以及新 CMDB 字段持久化/旧分类迁移方案。客户端自报结果不能作为可信授权或验证证据。

四项来源差异仍未解决，不自行选择备注必填、SSH、L2 数量或负载均衡映射。未检查字段并不表示合法：UI 明示地址格式、数据库、关联、凭据与模板检查未执行。未配置真实凭据，不创建账户，不启动采集、计费或外部通知。

这是 CSV 切片，XLSX 直接读取尚未接入；可从源工作簿另存 UTF-8 CSV，不能只更改扩展名。既有原始文件解析 Worker 未被替代。技术上限不是“500 行完整导入≤60秒”的验收证明。
