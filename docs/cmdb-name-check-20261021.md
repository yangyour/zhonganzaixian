# CMDB 当前来源与库内精确重名检查

基线 main：8c6bd4da339596384efe4d118f7d17729e18e0b0。新增 API 0.74.0；不修改 V1–V45。

## 检查边界

- 原 GET /assets/import-sources/{id}/cmdb-preflight 保持 SOURCE_DICTIONARY_ONLY、database_checks=NOT_RUN，不悄悄改变其含义。
- 新 GET /assets/import-sources/{id}/cmdb-name-check 返回 SOURCE_DICTIONARY_AND_ASSET_NAMES、database_checks=EXACT_ASSET_NAMES_ONLY。
- 依据现有 mop_asset 的 UNIQUE(tenant_id,name)，检查当前租户是否已有与来源第 0 列原文相同的资产名称。使用参数化 PostgreSQL 数组查询，不裁剪空白、不转换大小写，不按 IP、联系人名称或资产标签猜测身份。
- 来源创建者、当前权限版本、assets:write、来源/解析结果及资产查询在同一只读 REPEATABLE READ 事务内核验。不是先读取来源，再另开事务拼接一份数据库结果。
- 当前源必须完成解析，且仍通过既有 33 列字典头部与解析身份核验。旧 15 列不能自动套用。客户端不得覆盖单元格、租户或检查规则。
- 响应只带源记录/行/列和固定问题说明，不返回库内资产 ID、名称、IP 或成员资料。重名为 EXISTING_ASSET_NAME 错误，按源记录去重统计错误行。
- 无冲突仍是 CONFIG_PENDING，can_import、asset_mutations、production_approved 始终 false。快照不锁定或预留名称；未来提交仍必须在事务中重验唯一约束与配额。

站点/负责人引用映射、IP 去重身份、业务配额、新旧类型转换、事务导入及正式发布仍未完成。尤其不能把 IP 相同直接解释为同一资产，不能把人员同名自动解释为同一个账号。

## 前端任务可用性

两个明确入口分别读取字典检查和字典加库内重名检查。无自动写入或导入按钮。状态文本准确说明本次检查范围及未执行项目。

加载期间禁止重复请求、提供取消；失败清空旧结果并保留重试入口。来源版本/解析 hash、操作者、租户、角色、权限/账号版本、模式或切换状态变化清理旧结果，中止请求，忽略迟到回调。仅 remote_test 授权上下文显示。

读取器校验返回来源版本/hash、精确字段、检查模式、问题位置、错误行统计及非导入承诺；不能用字典结果伪装数据库检查结果，也不能反向混用。重名错误只允许名称列和 ERROR 级别，每条源记录最多一项。

沿用 WCAG 2.2 AA 目标与项目 44px 操作区标准：表格标题及列头、可滚动键盘区域、状态播报、读完聚焦摘要、取消返回发起按钮。DOM 验证不等同真实浏览器/辅助技术验收。
