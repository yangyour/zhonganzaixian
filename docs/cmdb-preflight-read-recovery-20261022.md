# CMDB 来源检查：原目标恢复与返回前权限复核

继续完善已有来源检查，而非创建新空入口。只检查客户33列字典和当前租户库内精确重名；不导入、不预留名称，不把该检查当作引用解析、配额、IP策略或正式批准完成。

## 行为

- 字典与库内重名两种检查分别保留原来源ID、版本/解析摘要及检查类型；失败/取消后显式重试原检查，不误切回另一种检查。
- 取消立即中止GET、清除旧结果并返回原按钮焦点，保留恢复目标和可读取消状态。源版本/账号/角色/能力/上下文变化清除目标，旧响应与finally不影响新请求。
- 同步状态回调替换账号时，在发送前再次核查范围，不发旧来源GET。成功/失败聚焦摘要/具名错误组；用户主动移开焦点不强抢。
- 问题分页按25项并播报当前范围，翻页不重新GET，聚焦结果摘要；CSV仍导出全部已验证问题，不受当前页影响。
- 服务端在检查完成、返回结果前重读当前成员并比较完整身份/租户/角色/权限版本/能力/活跃状态，同时检查原请求principal和session租户未变化。发生变化即401，不返回旧诊断。安全整数上限提前拒绝。
- 返回前复核是额外读边界，不声称提供网络响应期间持续权限推送；仓储既有单快照查询及事务边界不改变。
