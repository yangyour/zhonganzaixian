# 服务端 CMDB 来源字典校验

基线 main 6301202；API 0.68.0 新增 GET /api/v1/assets/import-sources/{id}/cmdb-preflight。它不是客户端校验结果上传接口，也不是最终导入命令。

## 完成的可用链路

1. 沿用现有来源上传、显式 CSV/XLSX 解析和创建者隔离仓储。拥有当前 assets:write 的创建者在导入抽屉完成解析后，可以主动读取服务器校验结果，无需先把 33 列错误映射成旧 15 列。
2. 每次核验当前会话/成员/权限版本；仓储在只读一致性快照中再次授权并限定当前创建者。客户端不能通过查询参数提供租户、规则或单元格。
3. 服务端检查来源 ID/创建者/租户、版本、当前解析操作、artifact 身份、原始字节哈希和解析摘要的一致性；结构损坏返回 503，未完成解析返回 409，非客户 33 列表头返回 422。
4. 检查必填、类型/子类型对应、原始单元格错误、ISO 日期、文件内精确重复和来源冲突。Excel 数值日期保留警告，不在 1900/1904 日期体系及未定解析政策之间猜测。
5. 只返回问题代码、记录/源行/列定位和固定说明，不返回原始单元格值。前端再次核对来源版本/解析摘要、记录位置与统计数；来源变化、撤权和取消立即清除，迟到结果不回填。问题每页 25 项，表格可键盘滚动，取消后焦点回到读取按钮。

结果固定 SOURCE_DICTIONARY_ONLY、database_checks=NOT_RUN、can_import=false、asset_mutations=false。没有正式运行发布、资产创建、数据库重复/配额或站点/成员/业务引用核验。源文件是服务端可信解析产物，仍不等于经过完整业务验证。后续入库事务必须重新授权并重查这些事实，不能信任前端或过期预检。

## 真实服务验证

自有临时 PG17.11 从新库执行冻结 V1–V45，重复和只读检查均 0 迁移。14 项既有 PG 业务回归全部通过；29 项实际 HTTP 请求检查通过，其中 7 项为新增来源入口：所有者 200、非创建者 404、只读成员 403、匿名 401、查询覆盖 400、POST 405、跨租户 404。其余为目录回归与登录/切租户准备请求，不能称 29 个独立业务需求。

合成来源通过真实 PostgreSQL 仓储受理、存储作业与解析作业状态转换；使用实际 ImportFileParser 处理 CSV 原字节。对象存储适配器明确为隔离内存测试替身，解析器在同一测试 JVM 内运行，不冒充 MinIO/OSS 或独立无凭据 Worker 完整验收。成功来源预检前后全部表指纹相同；拒绝请求的安全审计正常保留。API/PG 停止，临时库/凭据删除，未操作原服务器或发送消息。

运行时 JAR 与候选源码哈希、脚本快照、逐请求结果见 evidence/cmdb-source-preflight-20261021/attempt-1。记录里的 UNCOMMITTED_CANDIDATE_BASED_ON 表示测试时尚未提交的候选，不把基线提交冒充包含新代码。

## 回归与失败记录

- 新增 6 项服务端核心、10 项控制器、5 项响应读取器、6 项组件交互及 1 项契约检查。
- 首次将核心测试放在不含 JUnit 的 adapters 模块导致编译失败，迁到既有 API 测试模块，没有增添无用运行依赖。
- 首次 wire fixture 比较被 Jackson 内存 LongNode/IntNode 区别拦截；改为比较实际序列化后 JSON，字段与数值断言不放宽。
- 前端类型检查发现只读来源 DTO 与 mutable 参数不匹配、unknown 收窄不足；改为 DeepReadonly 和明确的 never 函数。增加 reactive 来源测试，避免直接 structuredClone Vue 代理。
- 3 项旧契约版本断言按新增 API 升至 0.68.0，未改变其既有业务约束。
- 浏览器脚本已扩展并可发现 9 项，但 Chromium 套接字限制仍存在，视觉、axe 和真实浏览器 UI 验收 NOT_RUN；不因 HTTP 成功宣称浏览器通过。

最终回归数量和清理边界见 evidence/cmdb-source-preflight-20261021/validation.json。V1–V45 SQL 没有变动；未将 128 项合同状态改为完成。
