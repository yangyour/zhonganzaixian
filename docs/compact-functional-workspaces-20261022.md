# 全站功能优先布局清理（2026-10-22）

## 用户要求与实现

根据两张页面反馈图及“所有页面都要清理，把页面都留给功能”的补充要求，以 main e8f2090 为基线进行全站清理。

- 清除各功能页重复页头说明、环境徽章、顶部统计大卡、无数据指标框架及占位。保留语义 h1 和路由键盘焦点；焦点到达标题时使用紧凑标题，不再恢复大块页头。
- 运营总览删除六项未接入 KPI、六项空面板及其无效范围/刷新控件，不再请求只用于这些占位的 /dashboard 投影。真实设备监控、事件、报障和工单面板保持原能力门禁、读取与操作。
- 设备监控删除四块顶部计数卡及重复介绍，保留实际设备行、过期/未知状态、历史查询和运行配置刷新策略。无有效资源样本时不渲染空排行。
- 事件中心不再使用共享 workspace-grid 双列规则。事件表为第一块全宽内容，维护与隔离操作在其后；960px 宽表在独立、命名且可键盘聚焦的容器内横向滚动，不应推宽整个页面。原业务状态转换、根因校验、SLA 确认、原请求重试与离开锁定均保留。
- 管理页顶部重复计数卡同步删除。实际计算输出（SLA、导入预检）、档位当前值及本页工时合计移入/保留在对应结果区，以紧凑行呈现，不伪造未知为零。
- 大块静态提示改为必要的短提示；清除一般介绍。动态错误、提交未知、输入约束、证书未核验及“草稿不等于发布”等实际风险仍保留。空状态压缩为文本与可用操作，不用大图标或固定数百像素留白。
- 顶栏、侧栏和登录页不再展示“测试环境”宣传文字。显示租户名时仅剥除末尾“（测试环境）”或“(测试环境)”；原租户名称、ID、选项值、会话、数据库及鉴权均不变。不隐藏证书风险。

## 回归与证据边界

- 原生 DOM/单元、Vue 模板编译及源码回归覆盖页面精简、真实操作保留、独立滚动区域、权限撤销、刷新与租户显示。旧测试中专门要求已删除文案/统计卡存在的断言改为对应实际结果/控件；没有删除业务写入、隔离、取消、未知结果或恢复测试。
- DashboardPage 旧占位投影轮询用例替换为真实子面板能力门禁、身份变更卸载重挂和自动刷新开关传递；独立 dashboardWorkspace/Availability 领域测试保留。
- 检查所有功能页模板不再包含旧大卡类，所有 SFC 均可编译；对清理前后原生/Element 控件逐项比对，变化仅为占位投影控件、漏斗选择器（替换为刷新事件）和保留目的地的配置链接文案。
- 增加四视口（320/390/768/1440）真实事件组件的 Playwright 回流、独立键盘滚动、只读刷新及 axe 脚本。合成入口仅开发服务器使用，不打入产品构建。
- 当前浏览器运行限制未解除，未绕过已拒绝的浏览器启动方式。Playwright 仅发现，不记执行通过；视觉截图、真实浏览器布局及 axe 仍 NOT_RUN。DOM 和 CSS 断言不是截图验收。
- 本轮仅前端代码/测试/文档，没有迁移、后端改动、外部通知或原服务器部署。Git 合入 main 不等于用户当前打开的站点已升级。
- 正式合同 128 项 TC 保持 NOT_RUN，不由本次清理推导完成率。
