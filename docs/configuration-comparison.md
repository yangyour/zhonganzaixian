# 配置筛选与建议差异

2026-10-01 在云端实现 D04 第6步及 SET-D17 的前端查询部分。配置页可组合筛选配置键、准确 Q 编号、待客户确认状态及登记作用域；可回读登记和已保存修订，比较登记值与草稿或修订建议。

差异使用 JSON Pointer 标识字段，区分新增、移除和变化，以及字段不存在、null、0、false。读取失败或切换对象时清除旧比较结果，取消过期请求，防止迟到响应覆盖当前对象。

登记作用域、建议值和运行生效值分别展示。内部 APPROVED 不代表客户证据通过或正式生效；接口未提供生效值时显示未知，明确 null 时显示尚未生效。实际受影响对象清单及数量尚无实现，继续显示未知。

复用现有 `GET /api/v1/configurations` 和 `GET /api/v1/configurations/{key}/revisions`，没有新增接口、依赖、数据库迁移或发布动作。
