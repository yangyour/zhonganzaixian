# 客户联系人维护边界

## 2026-10-03 纯核心

来源M2-9、M2-D06；Q14通知优先级/联系人静音/停用/决策人必达冲突仍未确认，不能据联系资料生成正式通知路由。本功能当前只有CustomerContact纯核心，没有新表、仓储、API、UI、批量导入或实际派发。

- 姓名保留原文（技术上限200 Unicode code points），角色为REPORTER/DECISION_MAKER/TECHNICAL_CONTACT非空集合；复制为不可变集合，不绑定用户、岗位权限或客户真实性
- 手机可null，否则为显式+国际号码（最多15数字），不默认中国区号、不自动清洗；邮箱可null，否则受限ASCII dot-atom/local64/总254/domain标签格式；不声称支持全部RFC/EAI地址或核验所有权/可达性。企微userid为可null的256字符受限自述标识，不当真实身份验证
- P1–P4偏好null与明确空集合分开；静音窗口可未知、明确关闭或明确HH:mm起止，时区合同固定Asia/Shanghai，支持跨午夜。同起止不猜全天，部分/秒级/24:00拒绝。仅保存偏好定义，不选Q14冲突处理/渠道矩阵
- 停用deliveryEligible=false；启用仍null而非已可送达。所有联系和渠道为未核验，不创建身份绑定、不发送通知
- requireDecisionMakerAfterChange接收调用方已锁定当前租户统计数和修改前后事实；移除最后启用决策人、停用或去掉其决策角色均409/LAST_ENABLED_DECISION_MAKER。首个联系人必须建立启用决策人；已有其他启用决策人时允许修改。负计数、与before不一致、溢出拒绝

该计数守卫自身不查询数据库、不证明授权/租户绑定或并发安全。后续仓储必须在同租户序列化事务内重新计数并检查，不能先读后无锁写入。当前已存在测试租户不会被自动补假决策人；正式联系人与通知验收仍未完成。
