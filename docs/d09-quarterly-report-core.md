# D09 季度巡检报告汇总核心（2026-10-19）

本切片新增 `InspectionQuarterlyReport`，直接消费 V23 已有不可变 `InspectionSourceManifest`，不重复创建模板、执行单或来源集合。它是纯计算草稿生成器，不是正式季度报告发布，也不代表数据库、对象存储、HTTP 或浏览器验收。

## 输入与输出

- `generate(authorizedTenant, manifest, period, configuration, completeness)`：调用方必须先验证真实会话与当前权限，再传入已授权租户和经现有仓储完整校验的冻结来源文档。租户不匹配先返回 404，不输出来源诊断。
- 期次明确传入年份和季度；时区必须明确配置，以当地季度开始（包含）和下季度开始（不包含）计算时间边界。仅使用 `reportedPerformedAt`，绝不使用记录时间代替执行时间。
- 每个捕获设备一行，按 UUID 字符串排序；原始候选修订全部保留，单项沿冻结模板顺序显示。没有被选中的行 `selected/summary/assetName` 为 null，`items` 为空，必须显示其 `status`，不能当作零项正常。
- 选中行直接保留冻结执行单、模板修订、结果、备注和证据 UUID。`findings` 从选中行中自动提取建议关注及需处理项，每项绑定执行单 ID、修订版本、来源摘要、内容摘要；证据 UUID 不代表文件可下载或已经扫描。
- `summary` 只计入已选中修订，另列捕获设备数、选中设备数、未决设备数和未填检查项数。它不是租户设备总量、巡检覆盖率、健康率、合同指标或已完成巡检数。未填项保持 null；不会补正常或 SKIP。

## 可配置选择，而非批准业务默认值

以下是已实现的可选择算法，不是客户已批准的配置。缺失项保留 null 并列入 `pendingReasons`：

- `duplicateRule=REQUIRE_SINGLE_SOURCE`：多个同设备候选不自动选择。
- `duplicateRule=LATEST_REPORTED_PERFORMED_AT`：只在明确传入此规则时选择自述执行时间最新的一份；最大时间相同仍未决，不能以 UUID、修订号或记录时间暗中打破平局。
- `archivedRule=INCLUDE/EXCLUDE`：仅针对被捕获修订的归档事实，不读取现在的可变头。未配置且可能进入本季度的归档来源阻止该设备选择。
- 时间未知的潜在候选阻止同设备选择，包括已经存在另一份已知时间的执行单；明确归档排除或明确不在本季度的来源可以排除，不会污染其他候选。
- 配置修订标识、时区、规则、指标版本、报告模板版本全部进入版本化摘要。配置对象不自带授权或审批效力，后续必须从可信的已发布运行配置解析，不接收未经授权客户端伪造的规则。
- `Completeness.COMPLETE_EXPLICIT_SELECTION` 只说明调用方提供的明确来源集合已完整读入，不说明租户所有执行单已枚举。`UNKNOWN/INCOMPLETE` 独立保留，即使行内填满也不能消失。

所有结果固定 `DRAFT`、`reportPublishable=false`、`reportPublished=false`。当前来源都是自述未核验、模板未正式批准；发布管线未接通始终列为门禁。不得把内部规则配置齐全等同于客户批准。

## 冻结与可重复性

`canonicalBytes()` 是版本化、长度分隔的 UTF-8 输入信封，绑定来源清单 SHA-256（间接绑定完整冻结模板、内容和元数据）、期次、全部配置以及完整性状态。无当前时钟、随机 ID 或可变头查询。`manifest()` 保留完整来源体；只保存摘要不能代替保存冻结文档。输出集合不可修改，返回字节数组为新副本。

`FORMAT` 的版本必须随汇总算法或规范编码变化升级。持久化层应同时保存格式版本、规范输入、完整来源文档及生成后的输出，避免以后算法或时区数据库升级重新渲染旧报告时变化。本切片没有冒充该持久化已实现。

## 后续接线（本切片未修改）
