# M1-8：当前租户未确认告警铃铛

顶部新增真实告警入口：当前内部角色可查看本租户 `monitor_state=PROBLEM` 且 `handling_state=NEW` 的准确数量和最近五条，点击进入现有事件详情。数量不从搜索结果或一页事件反推；抑制事件按合同保留，并单独显示抑制状态、重复次数。读取不确认事件、不派发通知。

`GET /api/v1/dashboard/alert-bell` 使用受限 PostgreSQL 账号，在同一只读 REPEATABLE READ 事务里读取数量和列表。排序为 `last_occurred_at DESC,id DESC`，响应带租户、用户、权限版本、时间和固定指标版本 `MOP_UNACKNOWLEDGED_PROBLEM_EVENTS_V1`。只允许当前有效 padmin/msp 且同时拥有 dashboard:read、tickets:read；读取前后复核成员，客户403、失效成员401、参数覆盖400、依赖失败503。没有迁移或运行配置开关。

客户端核对范围、状态、数量、完整前五条、唯一ID及精确时间顺序。真实0显示0；读取失败或取消清空旧列表和数量。切租户、用户、角色、账号版本或权限立即使旧响应失效。可手动刷新、重试、取消、Escape关闭；取消恢复刷新按钮焦点，关闭返回入口焦点。可见页面每30秒读取，重新可见时刷新。数字大于99时视觉徽标显示99+，可访问名称保留准确数量。

API版本增至0.85，生成器包含新增接口并保持既有DEMO契约。全局搜索的旧 `notification_bell_status=NOT_IMPLEMENTED` 保留以兼容严格客户端，并标为废弃的“搜索内嵌提示”；顶部铃铛以独立接口为准。DEMO目录只更新离线契约版本/哈希及准备期golden，没有重新初始化账号或样例。
