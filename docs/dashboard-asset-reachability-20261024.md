# 首页资产在线统计与明细

对应 UI02 / M1-1。本批实现完整授权台账与现有显式 Zabbix ICMP 绑定的只读聚合，首页卡片和展开明细使用同一快照。ICMP可达性不代表厂商设备健康、业务可用率或正式客户验收。

## 读取与范围

`GET /api/v1/dashboard/asset-reachability` 禁止查询参数，租户/账号/权限版本来自当前会话。独立要求 dashboard:read 与 assets:read，不以全局角色绕过租户成员关系。回应 no-store；返回前再次核验完整成员、会话和账号版本。

`PostgresAssetReachabilityReader` 在重复读授权快照中读取全部登记资产（最多10000，超过返回422，不截断）。调用现有 `NetworkMonitoringService` 只读取已配置目标，不新建采集绑定、不对用户输入地址发请求、不写数据库。采样前后重新读取整个台账，ID、名称、地址、版本或成员变化即拒绝旧结果。供应商读取错误返回失败，不降级成正常或伪完整成功。单SQL10秒、整体30秒检查；无新迁移。

未配置监控来源时，仍可读取真实台账，但每个资产明确记为 SOURCE_NOT_CONFIGURED。已配置来源却未绑定的资产记为 NO_EXPLICIT_BINDING。这两者不是“没有资产”，也不是采样成功。

## 计算边界

- 正常仅表示ICMP原始值1；原始值0为无响应。
- 样本时间不得在未来，且必须严格小于60秒；达到60秒立即未知。来源更宽的180秒标签不能绕过首页门槛。
- 未绑定、无数据、停采、采集异常、时钟异常及过期都独立计为未知，不与正常合并。
- 分母是完整登记资产数。只有资产非空且未知为0时才展示正常数/全部资产数；其余比例null。该保守完整率不替代可选的“已知资产子集比例”。
- 未来支持不同来源/新鲜度须明确扩展版本及来源证明，不通过放宽数字校验假成功。

## 页面与交互

首页自动/手动刷新读取同一来源；未授权不请求。卡片分别显示正常、无响应、未知。点击“资产在线明细”显示同一完整快照，支持状态筛选、每页20条、资产入口、停止等待与重试。关闭明细不等于停止首页采样，单独提供停止等待。

前端用服务端 observed_at 加本地单调时钟经过时长（保守包含完整请求往返时间，不因慢响应延长样本寿命）使过期样本转为未知；即使关闭自动刷新，也不会永久保留正常。这里仅对既有证据降级，不推定新样本或恢复。租户、账号版本、权限、角色、上下文代次和卸载清除旧值，忽略迟到响应。卡片与列表随过期一同更新。

## 验证

最终结果见 `docs/evidence/dashboard-asset-reachability-20261024/validation.json`。覆盖无绑定、采样0/1、60秒边界、未知不计正常、零资产、跨范围、台账变更、撤权、取消、重复读取、筛选与分页，以及关闭自动刷新后的本地过期。

新增3项指定PG测试只使用既有明确隔离身份/资产，不创建身份/数据库，不写客户记录；开关 `MOP_RUN_ASSET_REACHABILITY_PG_TESTS=true`，复用 `MOP_REPORT_CAPTURE_*` 及受控连接。当前缺配置，NOT_RUN。

新增2项桌面真实浏览器规格，全部195项/30文件仅发现；现有浏览器启动限制未绕过，DOM交互不是实际浏览器/无障碍验收。没有部署、迁移、修改设备、发通知、演示初始化或新增采集配置。其余KPI和页面缺口继续IN_PROGRESS。
