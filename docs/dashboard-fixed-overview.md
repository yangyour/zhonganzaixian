# 固定运营首页：可用性与授权基础

## 合同范围

依据 doc/development/02 与合同 M1-1、M1-11，首页版面固定，不实现拖拽、隐藏、自定义布局或个人布局保存。顺序为六 KPI、告警趋势、服务健康、故障时间轴、近期事件、待处理工单、资源 Top5。趋势仅有24小时/7天/30天预设；月可用率从上海时区当月1日零点至数据库观察时刻，MTTA/送达率与故障时间轴独立固定最近24小时。月初同一瞬间允许明确的零长度区间，不据此给出0%或100%。

## 已实现边界

DashboardAvailabilitySnapshot 固定六 KPI/六面板、UTC毫秒精度及上海业务日期，集合不可变。全部指标值、采样量、采样时刻、指标版本、阈值判断、下钻路径保持null，未知列表是null而非暗示无事件的空列表。接收与送达分开，技术台账和人工登记不能替代监控样本或正式待处理工单。

PostgresDashboardAvailabilityReader 仅从真实PG读取当前active用户/成员、权限版本、角色与数据库时钟。四个既有技术角色均可读取本人当前授权租户；独立只读REPEATABLE_READ，禁止嵌入写事务，无业务/审计/回执写入。成员失效401、角色无权限403、非法参数400、实际SQL或时钟错误503，不在数据库故障时回退UNKNOWN成功。数据库时钟不代表已验证NTP精度。

本次没有HTTP端点、前端页面、新迁移或监控适配器。API契约仍0.43.0；不能把领域方法当作已上线接口。后续需实现只读API/严格响应校验/固定页面，并分别验证授权、刷新竞争与真实组件。

## 只读HTTP边界（API 0.44.0，代码验证阶段）

GET /api/v1/dashboard?window=HOURS_24 提供上述固定可用性投影，window可选HOURS_24/DAYS_7/DAYS_30，省略时24小时；拒绝重复键、任意额外参数与超过2048字节query。设计文档的任意from/to尚未实现，明确400拒绝，不能当已完成任意时间查询。租户/身份/PV由会话当前成员重新授权，reader再次核对真实PG；返回值也须匹配actor/tenant/PV/window，空或错位投影503。

响应包含精确六KPI/六面板、各自时间区间与缺失原因。所有指标样本、计数、列表、真实指标版本仍null。接口可返回授权/时钟可用性，不代表监控数据已可用；PG不可用不返回替代200。既有安全过滤器no-store、匿名401、CSRF保护保持；无POST/PATCH/保存布局或请求回执，正常GET不产生业务审计/写入（拒绝事件仍按统一安全审计）。

21项新增隔离HTTP边界测试（15controller、6真实MVC/filter+mock仓储）通过；包括当前成员、跨范围损坏投影、未知角色、参数覆盖、null语义、无CSRF只读、带CSRF也不提供写入、503传播。隔离依赖不代表真实PG/OIDC/HTTP联调。OpenAPI新增1路径/2schema，旧105路径/233schema完全不变；正式部署、当前组件、真实HTTP与浏览器仍NOT_RUN。
