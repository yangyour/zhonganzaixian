# 首页近期监控事件

基于 main fec92f5。复用现有受保护 GET /events?window=24h&page_size=7，不新增授权、DDL、后端接口或外部依赖。

## 已接通任务

具有 dashboard:read 和 tickets:read 的 remote_test padmin/msp，在首页查看当前租户最多 7 条近期事件，点击规范 UUID 深链接进入事件中心明确详情。采用仓储既有 last_occurred_at DESC, id DESC 排序；同时间使用 UUID 倒序。window 仅控制同响应中的噪声漏斗，不把事件列表误标为最近24小时。

分别展示严重程度、监控状态、人工处理状态、抑制状态、合并次数、最近发生时间及未送达边界。包含恢复和关闭事件。局部列表数不代替全租户当前问题数、SLA、MTTA、趋势或通知送达率。固定指标接口的未接入状态仍保留，相关文案指向已接入授权列表。

## 交互验收

- 初始读取、已读取、明确空、加载失败分别展示；失败清空旧列表，手动重试同一请求。
- 在途刷新禁用；不额外自动轮询，不声称实时推送。
- 当前身份、租户、权限版本、角色、权限、切租户和卸载重置与取消；迟到响应不泄露旧数据。
- 客户 viewer/tadmin 即使携带能力字符串也不能调用此运营事件面板。
- 复用完整严格 DTO 读取器；超出7条、重复、跨租户、无效状态、时间顺序错误拒绝，不静默截断或重排服务端输出。
- 原生链接及按钮44px，语义有序列表和定义列表，状态提示，文本转义，窄屏单列，无 v-html。
- 现有 API 后端授权仍是安全边界；前端能力判断不替代授权。

## 证据边界

13项新增 Vue/jsdom 测试，包含从生产控制器生成的 DTO 合成夹具。该控制器夹具原用于状态枚举，等时 UUID 为正序；测试输入按实际 PostgreSQL 仓储合同调整为倒序，不改动生产排序校验。初轮3项因此拒绝，修正夹具后复测通过。另调整旧首页文案断言，保留未接入指标不补零的测试要求。

本批未启动新增真实 HTTP 联调；复用已有 GET 实现，无后端改动。真实浏览器、axe、视觉、键盘实际浏览器和客户验收因当前环境限制仍 NOT_RUN，不冒充 WCAG 已合规或 TC-M1-5 完整验收。详见同名 evidence 目录 validation.json。
