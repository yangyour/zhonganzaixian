- 当前GET可取消，保留已选择输入；失败/取消后按原条件、创建时间/UUID/基准日三段游标重试，不重设基准日。
- DATE_REFERENCE_CHANGED的409不能重试失效的原页；要求用户明确点击“重置到第1页”。该门禁使用内部状态，不受外露诊断错误对象被修改影响。

- 日期筛选权限不等于资产详情读取权限；查看详情还需assets:read，并仅接受当前完整已核对行。失败、关闭、读取中、过时行或撤权不能导航。
