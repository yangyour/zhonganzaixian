# 独立演示账号与数据准备，2026-10-22

## 当前交付不是账号开通

用户要求在监控批次后增加一个具有全部功能权限、带各功能演示数据的账号。本批只交付离线准备工具、功能/权限覆盖清单和基础请求夹具。没有创建账号、生成密码、授予权限、写业务数据或部署演示站；全部功能交互验收仍未执行。部署目的地、账号授权和角色场景方案尚待确认。

现有业务租户 `55000000-0000-4000-8000-000000000001` 保持真实数据边界；旧Fixture租户 `55000000-0000-4000-8000-000000000002` 也不复用。不能恢复旧测试身份或把演示数据写入这些命名空间。

## 权限审计的实质限制

当前代码声明48项权限：padmin为44项，msp为20项，tadmin为13项，viewer为10项。padmin不包含工程师工时读写及客户报障/确认的4项专属权限。Membership还校验角色类别上限，不能靠添加一个自定义角色就绕过。

准备方案提出同一账号在三个全新演示租户分别使用padmin/msp/tadmin，利用已有租户切换覆盖页面与角色专属场景，未新增超级角色，也未修改前端或真实授权逻辑。该方案仍待用户确认，而且“48项权限的集合覆盖”不等于全局操作都可执行。

特别是 `setProjectIdentityPolicy` 必须在数据库每个租户都具备 `roles:write`。工程师/客户场景身份不满足这个条件；同站点演示租户也不应因此获得真实租户权限。独立演示部署更合适，但全局设置与角色切换之间的管理员身份方案仍须确认，不宣称已经解决。若采用辅助管理员/工程师/客户账号，实际创建每个身份与授权仍须明确批准。

[离线黄金样例](../fixtures/demo-preparation-golden.json)含40份符合当前API请求结构的基础夹具：

- 管理/客户场景的6份联系人请求，只有example.invalid邮箱，没有真实手机号或企微身份。
- 三份内部/客户报障请求、三份仅保存草稿的通知偏好。
- 巡检模板、停用备份草稿、变更草稿、工程师工时请求。

资产名称、联系人、工单说明等明确带DEMO/演示标记。备份凭据为空且 requested_enabled=false；通知不连接真实供应商，不声称送达。工时和测算不用于真实结算。

所有ID仅为计划内引用。站点尚未创建，API返回对象ID与当前版本尚未绑定；工时还需要工单实际分派等前置条件。`references_verified:false` 不是装饰字段，后续执行器必须解析并核对同租户引用，不能把这些请求直接批量提交到任意地址。

监控历史/事件、工单完整阶段链、导入/导出作业、报表来源、值班和运行配置等高级场景目前只有覆盖清单，尚未完成初始化。不能据此宣布“每个功能都有演示数据”。

## 使用与防误操作

工具为 [tools/demo_plan.py](../tools/demo_plan.py)，没有网络、数据库连接、账号生成、SQL或apply入口。输入示例 [demo-plan.example.json](../deploy/examples/demo-plan.example.json) 的namespace、时间和部署模式故意留空；未补齐则拒绝，不猜部署位置。

在明确新的UUID命名空间、候选用户名、UTC演示时间锚点及部署模式后，可用：

```sh
python tools/demo_plan.py --input /path/to/reviewed-demo-input.json --output /path/to/new-preview-directory
```

输出 request-fixtures.json、feature-coverage.json，最后写 plan.json。目录必须全新，不覆盖已有文件，也不允许符号链接路径。输入只接受五个明确字段，拒绝密码、token、地址、现有tenant覆盖、approved和active等额外字段；拒绝重复JSON键、受保护命名空间及已知真实/旧Fixture用户名。

相同命名空间和时间锚点产生同一计划与引用，避免每次预览生成不一致数据。写出时重新编译整个计划并对照摘要，修改后重新算hash也不能将任意字段塞入可信预览。源码锁覆盖当前路由、角色声明和API契约；变化必须重新审阅覆盖，不能拿过期计划授予新权限。

`account_created/credentials_created/permissions_granted/business_data_written/outbound_enabled` 始终false，`all_functions_ready:false`，42项页面均NOT_RUN。计划内所有候选成员关系 inactive，输出不包含密码或实际登录凭据。
