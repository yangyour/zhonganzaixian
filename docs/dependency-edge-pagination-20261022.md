# 资产依赖明细分段浏览（2026-10-22）

## 可用性与无障碍约束

将既有依赖面板一次渲染全部关联边改为原生语义表格，每页最多25条。本次完整图仍保留并用于版本/保存校验，不把分页数组传回写入器，不静默截断图。

- 清楚区分当前资产关联条数和租户完整图总数；本地分页不请求后端、不保存、不启用Q20策略。
- 首页、上一页、下一页、末页及整数页码跳转。最多10000条关联边时能直接到第400页，不要求反复点击数百次。
- 表格caption、列标题scope、可聚焦且命名的横向滚动区域；上游/下游完整UUID始终显示，名称只是辅助。同名设备不只靠名称区分。
- 类型和范围完整换行显示，不用悬停标题代替原值；null/建议启用/建议停用保持区分。
- 页码错误与输入通过aria-describedby关联，同时提供可聚焦role=alert；状态区域播报范围/页数/版本。分页后仅在焦点未被用户主动移走时聚焦状态，不抢其他控件焦点。
- 控件最小44px、小屏只让表格区域横向滚动、分页按钮可换行、焦点轮廓可见。新的图、资产或上下文重置分页与错误，旧异步焦点动作失效。
