# 会话复核与离页时的输入保护

逐功能页面验收发现，部分编辑器通过 `watch(() => [会话字段...])` 或直接监听会话对象清理状态。路由正常复核 `/session` 后，即使用户、租户、权限没有变化，新对象/新数组也会触发清理：关闭报障详情或打开资产详情就可能丢失工时、照片、导入文件及未确认请求。工时、报障、导入和配置修订还缺少部分普通离页保护。

## 修复范围

- 改为逐个实际上下文字段监听。同值会话复核保留本页输入、File、预览、上传尝试、原幂等键/body、已受理operation；真正的用户、租户、权限、账号版本或授权失效仍清理旧状态并中止请求。
- 工时未保存输入在切工单、离页、切租户、退出、清空/替换时确认；收起保留，取消保留，保存确认后清除脏态。防止晚到确认或旧保存结果覆盖新上下文。
- 报障、照片追加、资产来源和配置修订共用路由/上下文检查，并补浏览器关闭提醒。未知结果、已受理待回读及未处理照片不能通过普通导航丢弃。
- 对纯未保存输入，确认只表示同意离开，不立即清理。后续任一守卫取消导航时，原输入仍在。

接口、数据库、幂等语义和业务规则不变。没有将草稿保存、图片存储、导入源解析当作正式工单闭环或资产纳管。

## 验证

新增直接组件及真实Vue Router回归，先复现再修复。最终137个前端测试文件、2030项测试通过，类型与生产构建通过。首次全量有1项旧源码字符串断言只接受内联回调，已适配具名离开检查并保留真实行为回归；失败与后续通过分别记录，没有改变安全预期。

真实测试API浏览器已验证：工时关闭详情仍保留、切工单取消/批准、390px恢复；资产文件经同页详情及会话复核保留、模块离开取消/批准；配置提案应用内后退取消保留；390px报障部分输入收起、取消离开及明确舍弃。上述浏览器检查没有提交业务写入。另有56个页面/视口组合真实读取初检。
