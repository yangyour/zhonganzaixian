# 前端验收基线与 CMDB 交互修正

基线：main 3017f584fbad2047e54a76a3a24cfec37d7dfb7b。采用 [统一验收标准](frontend-acceptance-standard.md)，不宣称全站 WCAG 合规。

本轮补齐 CMDB 参考面板的显式取消、在途重复读取抑制、取消后迟到响应丢弃、收起后返回读取按钮焦点、主类型筛选、去除搜索首尾空白、无匹配说明和清空搜索。表格增加可聚焦滚动区域、名称、caption 和列头作用域，原生控件/操作按钮以 44px 产品目标改进触控。权限上下文变化仍同步清除，不自动发布或写资产。

加入精确版本 Playwright 1.64.1 / axe-playwright 4.14.0，独立 npm run test:browser。本次组件浏览器夹具明确使用合成会话和模拟网络响应，且不在生产构建入口；7 项浏览器脚本覆盖 4 个视口、键盘/焦点/回流/扫描、失败重试、取消及撤权。脚本写出不等于实际通过。

## 如实记录的执行限制

- 首次 npm 查询未指定可写缓存目录失败；随后使用既有临时缓存安装成功，未改变系统软件或项目运行依赖版本。
- 浏览器套件首次发现 Node ESM JSON 缺少 import attribute，改为测试中显式 fs 读取。
- 修正后 7 项全部在 Chromium 启动阶段失败：环境禁止 process singleton socket；没有进入页面，axe 和视觉/键盘真实浏览器验证均 NOT_RUN。
- 请求获准的提升执行尝试在环境构建阶段失败，未启动浏览器。没有绕过权限、修改系统安全设置或转用用户电脑。
- 一次从仓库根误调用 Playwright 列表而未加载 Web 配置，错误扫描 Vitest 文件；从 apps/web 运行项目脚本后正确发现 7 项，未执行浏览器。
- 组件 DOM/逻辑测试不代替上述浏览器验证；真实数据库/API 上一批证据亦不代替本批 UI 验收。

实际测试总数及构建结果见同目录 evidence/frontend-acceptance-20261021.json。后续每模块继续补功能与相同门禁，不能因浏览器不可启动就把所有业务暂停，也不能标记 UI 全验收通过。
