## 本轮实施与 QA 清单

本轮聚焦 FE08/FE09 与 FE15 两个独立功能，其他条目作为持续发布检查基线，不自动标为通过。

1. 全局搜索：Ctrl+K / Command+K，移除裸 `/` 的全局监听；不抢编辑区、IME或其他模态窗口；按钮显示提示和键盘语义；取消后回到入口。验证正常打开、Tab循环、Escape、输入框斜杠、已有弹窗及无权限。
2. 原生表单错误摘要：列出字段名和对应错误，可逐项定位，按DOM顺序呈现，修改/重置后同步清理；不复制用户输入、不改约束、不触发额外提交。验证多错误、字段修正、禁用/删除及原有描述保留。
3. 视觉：桌面1440、手机390和320；分别检查搜索弹窗、资产草稿错误、长标签和焦点位置，正常表格作相邻回归。截图遮盖身份。
4. 异常探索：编辑区/确认弹窗按搜索快捷键；表单多错误后移除或禁用字段；网络读取失败保持原错误边界。单元替身只验证控件，不算组件联调。

实际浏览器使用本地生产构建、回环预览和指定 `lan-test-20261008` 真实API。复用既有组件，不安装/升级基础服务，不提交业务数据。API路径、DTO、授权、数据库和客户规则不变。运行：`apps/web` 下 `npm test -- --maxWorkers=4`、`npm run build`；根目录 `npm test`、`npm run contract:check`。本轮结果随独立功能完成补充；不把源码推送视为测试站部署。
