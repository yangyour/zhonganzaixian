## 本轮实施与 QA 清单

本轮聚焦 FE08/FE09 与 FE15 两个独立功能，其他条目作为持续发布检查基线，不自动标为通过。

1. 全局搜索：Ctrl+K / Command+K，移除裸 `/` 的全局监听；不抢编辑区、IME或其他模态窗口；按钮显示提示和键盘语义；取消后回到入口。验证正常打开、Tab循环、Escape、输入框斜杠、已有弹窗及无权限。
2. 原生表单错误摘要：列出字段名和对应错误，可逐项定位，按DOM顺序呈现，修改/重置后同步清理；不复制用户输入、不改约束、不触发额外提交。验证多错误、字段修正、禁用/删除及原有描述保留。
3. 视觉：桌面1440、手机390和320；分别检查搜索弹窗、资产草稿错误、长标签和焦点位置，正常表格作相邻回归。截图遮盖身份。
4. 异常探索：编辑区/确认弹窗按搜索快捷键；表单多错误后移除或禁用字段；网络读取失败保持原错误边界。单元替身只验证控件，不算组件联调。
5. 关键文字对比：测量选中侧栏渐变两端、搜索入口、主按钮正常/悬停/键盘焦点及搜索辅助信息；普通文字≥4.5:1，按钮焦点指示对相邻白底≥3:1。只签署实测配对，不据此推断全站颜色通过。

实际浏览器使用本地生产构建、回环预览和指定 `lan-test-20261008` 真实API。复用既有组件，不安装/升级基础服务，不提交业务数据。API路径、DTO、授权、数据库和客户规则不变。运行：`apps/web` 下 `npm test -- --maxWorkers=4`、`npm run build`；根目录 `npm test`、`npm run contract:check`。本轮结果随独立功能完成补充；不把源码推送视为测试站部署。

## 第一项结果：搜索键盘与弹窗

27项针对性测试和生产构建门禁通过。真实Edge检查了组合键、编辑区、已打开弹窗、焦点循环、关闭回焦及API空结果；四种视口验证完整标题和关闭按钮。实测发现页头叠层拦截点击、旧手机margin覆盖两处问题，修复后完整重跑，未强制点击或关闭浏览器安全机制。最终构建 `f34e50f681d8ca0634d4264afe533cef22fc005dc251b40d30d3f1ff81625d14`；证据见[search.json](evidence/frontend-acceptance-20261015/search.json)。物理Mac快捷键、物理输入法、读屏和无权限页面此次没有新增现场验证，不宣称全站通过。

## 第二项结果：可定位的表单错误

所有使用 `v-form-feedback` 的原生表单共用错误摘要：无效提交后聚焦摘要，按字段顺序列出中文错误，点击或Tab/Enter定位对应字段并滚动到可见位置。字段名来自已有可访问名称/标签，不复制输入值；字段原ID、已有帮助说明及校验约束保留。逐项修正、重置、字段移除/禁用时清理对应提示；不触发提交，不改变已有离开保护。样式保留错误色，同时增加文字、下划线和焦点提示。

共享工作区出现其他监控功能改动后，本项在 `2304e7d` 的独立源码工作区仅叠加三个本轮文件验证；未把其他功能混入测试结论。默认fork工作进程首次启动超时，没有执行任何断言；改用 `--pool=threads --maxWorkers=2` 后，同一套10项针对性测试、完整141文件2071项前端测试、134项契约及生成一致性检查、类型/正式构建/发布策略门禁全部通过，没有放宽断言或产品超时。

真实指定API的资产草稿页面验证：三个空字段拦截且业务写入0、错误链接定位、Tab/Enter、逐项修正、取消离开保留输入。桌面1440、手机390/320截图和边界检查通过。`站点 ID` 同时存在筛选框和表单字段，首次选择器歧义后限定在目标弹窗重验，没有修改产品名称规避测试。证据：[forms.json](evidence/frontend-acceptance-20261015/forms.json)、[桌面摘要](evidence/frontend-acceptance-20261015/form-desktop.png)、[320px摘要](evidence/frontend-acceptance-20261015/form-320.png)。构建 `6d43d8fe377077485313c196ac2572d20b1d40d91077b0ca6446d5dd3667aac2`。

这些结果仅覆盖本轮范围。其他验收条目仍需在对应发布逐项执行；真实读屏、物理手机、原生浏览器200%缩放、现场Web Vitals p75、业务写入闭环和128项合同验收均不由本次结果替代。服务器Web没有切换到本轮版本。

## 第三项结果：关键文字与按钮焦点对比度

保留蓝色界面，调深全局主色、侧栏选中渐变、搜索入口及分组说明文字。主按钮悬停样式覆盖挂在body下的弹窗，避免原先只有壳层内按钮受保护；键盘焦点框改用已有深蓝焦点色及3px声明宽度。禁用态和业务状态语义保留。

真实Edge读取最终计算样式并用sRGB相对亮度公式测量：侧栏浅端白字从2.63:1提升至5.44:1；搜索按钮正常4.12:1→5.63:1，悬停2.66:1→6.96:1。七组实测文字配对均≥4.5:1；按钮键盘焦点为可见深蓝实线，对白底≥3:1。浏览器将声明的3px轮廓量化为2.66667px，证据保留实测值，未虚报渲染尺寸。

类型、生产构建、静态产物/策略门禁通过；最终构建 `4c47e9cdb2e600cab3989d8d11f1c1c024b84a582cb334c7998dd9cb7aa51d96`。桌面台账、搜索正常/悬停/键盘状态和320px弹窗重新检查，未见横向页面溢出、标题/关闭按钮遮挡或页面脚本异常，业务写入0。见[颜色证据](evidence/frontend-acceptance-20261015/contrast.json)、[最终台账](evidence/frontend-acceptance-20261015/final-assets-desktop.png)、[最终手机搜索](evidence/frontend-acceptance-20261015/final-search-320.png)。这不是全站对比度扫描或WCAG认证。

本机隔离预览 `http://127.0.0.1:15175` 使用上述生产构建和既有指定测试API，需有效项目测试账号。本次预览只包含本轮已验证范围，没有把同期其他监控开发改动混入构建。服务器 `10010` 入口未由本轮切换。

最终颜色修正后，对受影响导航、搜索及表单再次运行4文件60项测试，全部通过。最终6个产品源码文件与隔离验证副本SHA256一致，构建/机器结果汇总见[validation.json](evidence/frontend-acceptance-20261015/validation.json)。完整2071项回归在第二项完成时执行，最后仅颜色与焦点样式调整采用上述针对性复验；不是把不同批次结果冒充同一次全量运行。验收浏览器已关闭，本机隔离预览保留供查看。
