# 前端功能与交互验收标准

适用：2026-10-21 起新增或修改的功能。目标为 WCAG 2.2 AA 可访问性基线，加上本项目业务、授权、数据一致性和恢复门禁。不是声称全站已经符合 WCAG。

## 依据

- W3C WCAG 2.2：https://www.w3.org/TR/WCAG22/
- WAI ARIA 模式：https://www.w3.org/WAI/ARIA/apg/patterns/
- Playwright 可访问性验证：https://playwright.dev/docs/accessibility-testing

自动扫描只能发现部分问题；必须结合真实浏览器键盘操作、视觉检查及适用的人工辅助技术验证。接口模拟、真实 API、真实外部供应商三层证据分别记录。

## 每功能必过门禁

1. **任务可完成**：从入口到业务结果及回读都有实际操作，不以按钮存在、HTTP 200 或静态截图代替完成。草稿、受理、运行生效、送达和正式批准使用不同状态。
2. **状态完整**：初始、加载、成功、无数据、筛选无匹配、错误、未配置、无权限分别展示。错误必须有可执行恢复方式；未知不补零或假成功。
3. **表单易用**：持久可见标签、输入格式与必填说明；提交后字段错误可定位，原输入保留；合法零值不误判为空；中文输入法与快速连续输入不丢内容。
4. **安全恢复**：重复提交被抑制；写入未知结果保留同一请求身份，不凭 GET 宣称成功；冲突/超时/断链/重试均有测试。离开、刷新及会话失效不静默损失待提交内容。
5. **租户隔离**：切租户、退出、撤权、权限版本变更立即清空旧范围；取消在途读取，迟到响应不能覆盖新范围。前端隐藏不是后端授权的替代。
6. **键盘与语义**：所有功能可键盘完成；焦点可见且不被遮挡，顺序合理；弹窗按 APG 管理焦点/关闭/返回；控件名称和状态可被辅助技术识别；加载和结果使用适度的状态通知。
7. **可读性**：普通文本对比度至少 4.5:1，大文本至少 3:1；必要控件边界/状态至少 3:1；信息不只靠颜色。缩放和文本放大不损失操作。
8. **响应式**：320、390、768、1440 CSS 像素检查；内容回流，页面无意外横向溢出。确需二维布局的表格使用独立可键盘滚动区域，不压缩到无法辨认。
9. **触控**：采用产品目标 44×44 CSS 像素；WCAG 2.2 AA 的 24×24 或符合其间距/例外条件是最低门槛，不混淆两者。
10. **可靠性**：无新增未捕获页面错误；控制台、网络失败与重复请求检查；大列表使用已定义分页/上限，不静默截断。性能预算按代表性数据和环境留证，不编造普遍达标时间。
11. **浏览器**：每批用可用真实 Chromium 验证；Firefox/WebKit、合同 Edge/Chrome/Firefox/360 和实际移动端分别登记 PASS/FAIL/NOT_RUN，不能用 Chromium 或手机视口模拟冒充全部兼容。
12. **可交付证据**：固定源码/工件标识、测试命令、执行数与跳过数、视口、浏览器版本、数据来源、缺陷及复测记录。失败不覆盖，截图不包含客户秘密。

## 测试层次与完成定义

- Vitest：纯逻辑、组件事件、异常/竞态、权限变化。
- 浏览器自动化：真实渲染、按角色/标签定位、键盘、焦点、回流、axe 扫描。模拟 API 仅证明 UI 状态和协议行为。
- 真实服务联调：可丢弃数据库和合成身份，API/前端联合正向、越权、故障恢复验证；不能替代生产供应商验收。
- 人工/客户验收：屏幕阅读器、真实设备、业务口径、合同 TC。未执行明确记录 NOT_RUN。

任一修改功能有未解决的阻断性错误、越权、数据丢失或假成功，不标完成。依赖缺失可以先交付受控的可配置实现，但不得将配置清单或禁用按钮视为功能全部完成。每独立切片验证后记录并提交 main，不恢复已停用的云端验证。
