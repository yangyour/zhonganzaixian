## 官方依据

- [W3C WCAG 2.2 当前 Recommendation](https://www.w3.org/TR/WCAG22/)：截至查阅日为 2024-12-12 版本。以 AA 中的可见焦点、焦点不被遮挡、重排、标签、错误建议、状态播报为检查基线；不是无障碍认证声明。
- [WAI-ARIA 模态对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：对话框名称、键盘焦点约束、关闭后焦点归还。
- [Element Plus Message](https://element-plus.org/en-US/component/message.html)、[Config Provider](https://element-plus.org/en-US/component/config-provider.html)：遵循当前组件 API，集中配置中文、反馈行为及尺寸。
- [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457)：参考 HTTP 状态与可诊断错误的原则。已有 `{data, trace_id}` / `{error, trace_id}` 公共契约保持不变，不声称已迁移为 Problem Details。

## 已实施：响应与提示

普通 JSON 请求默认 30 秒，上载及图片默认 120 秒；超时覆盖 fetch 与响应体读取。取消/切换租户立即丢弃旧响应；超时不自动重发写请求，不推断写入失败或成功。保留原幂等键、CSRF 和原请求恢复机制。

非 JSON 的 HTTP 401/403/429/5xx 保留真实状态；401 仍执行失效处理。错误信封的 message/details 做类型检查，成功信封同时携带错误时拒绝确认。错误提示分为用户说明、下一步及折叠排查信息。只有调用方明确绑定读取动作才出现“重新读取”。

27 处使用统一反馈入口：成功提示 5 秒，警告/错误/信息主动关闭，重复文字合并，禁止 HTML 提示。业务成功文案保持原先证据强度（草稿/已受理/未生效不改为完成）。

## 已实施：全站基础体验

统一字号、文本对比度、表单与按钮高度、反馈、卡片、表格、弹层和窄屏排版；移动端触控目标提高到44px，减少动态效果偏好受尊重。加载失败与空列表分别呈现，宽表格可键盘滚动。提供跳过导航、路由加载反馈、页面焦点、导航读取失败说明、未知地址页面和断网状态；断网恢复不会重发业务写入。
