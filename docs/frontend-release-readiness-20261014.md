本轮基于第一轮前端提交e22db7f，按现有Vue 3、Vue Router 4、Vite 7继续打磨；不升级框架、不改变客户待确认规则、密码策略或正式验收状态。与同工作区的导出功能修改分开提交，复核使用隔离源码快照及指定测试站真实API。

## 依据与检查清单

- [Vite 7生产构建与资源加载失败](https://v7.vite.dev/guide/build#load-error-handling)：换版后的旧资源可能不可用，HTML需要重新验证缓存。本项目保留显式恢复，不自动刷新持有未确认写入的页面。
- [Vue Router导航结果](https://router.vuejs.org/guide/advanced/navigation-failures.html)：取消、失败、成功必须区分，保留当前页面并解释失败。
- [Web.dev页面生命周期与bfcache](https://web.dev/articles/bfcache)：浏览器恢复旧页面不能代表授权仍然有效；不将beforeunload视为可靠保存机制。
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)：错误说明、可操作恢复、焦点与状态语义；不声称认证。

|检查项|通过标准与证据|
|---|---|
|首屏加载失败|主应用资源失败/JavaScript禁用时仍有中文说明与显式恢复入口；真实构建浏览器验证|
|懒加载与换版|阻断真实路由资源后可见错误；不自动跳页/刷新；正常资源恢复后显式重新加载|
|未确认写入保护|恢复前检查已有离开守卫；拒绝、并发和授权代数变化不刷新；隔离单测与真实表单取消|
|会话失效|解释退出原因、清除保护数据、重新登录后只回到当前有权访问的页面；不存储密码、cookie或原查询|
|静态发布产物|入口与资源依赖完整，文件摘要可核对，缺失资源返回404；构建校验|
|真实环境|固定主机信任SSH连接现有API，失败明确记录，无fixture或本地数据库替代|

每个独立功能验证后更新本记录并提交推送。测试站部署、生产批准和全合同业务验收分别登记，不以构建成功代替。

## 运行恢复与会话体验

已增加独立启动面板与小型引导入口；主应用文件不可用时仍能显示中文错误并手动重新加载。路由资源错误使用Vite事件与Router失败状态，当前页面、标题及编辑器保持；显式重载受原有离开守卫、并发锁及上下文代数复核保护。Vue运行异常只呈现通用恢复信息，不回显异常堆栈或发送外部遥测。

当前会话收到401时先清除受保护数据和在途请求，再显示登录失效原因。只在内存保留已知页面路径，去除查询和片段；重新登录后按最新角色/权限选择返回页，密码修改要求优先，未授权或外部路径不可恢复。常规退出清除失效提示和返回路径；无密码/token/cookie持久化。

123文件/1880项前端测试通过，类型及生产构建通过。初次路由测试有5秒冷编译超时，授权单测改用不渲染业务页的明确组件替身（保持全部授权断言与原超时），未放宽产品或请求超时。另修复旧App单测缺失matched字段。真实Edge/指定API已验证主文件阻断后恢复、路由文件阻断时保留资产页与标题、重新加载取消保留输入、明确放弃后恢复，以及注销自己的测试会话→401说明→重新登录回到审计页。除登录和结束自身测试会话外，未为这些UI检查创建业务数据。

## 静态发布门禁与缓存

`npm run build`现在串联类型检查、Vite构建和`tools/verify-web-release.mjs`。门禁检查HTML引用、所有同步/懒加载引用及文件存在性、目录边界、私有文件/源码映射混入；首屏必需入口（含main，不只计算引导小文件）的gzip技术回归预算为256KiB。本次169446字节，预算是工程回归保护，不是客户SLA或实测首屏时间。

生成`dist/release-manifest.json`，记录83个文件的SHA256与整包build_id。上传后使用`--check --expected-build-id <已记录的build_id>`只读核对，不重新生成清单，能够识别文件缺失/改字节/版本不符。该摘要用于一致性检查，不宣称具备签名供应链认证。9个独立故障门禁测试通过，已接入现有GitHub工作流；本次只记录本地通过，未声称远端CI已运行。

构建实测发现Vite把共享main记录为生成key而非固定src/main.ts，校验器已沿入口真实依赖图核对，并新增对应回归。最终完整构建门禁通过；不是跳过失败。

缓存候选见`deploy/lan-test/web-static-locations.conf`：HTML/startup.css/发布清单使用no-cache；成功的哈希资源长期缓存，缺资源保持404；保留上层安全头。需要Nginx≥1.29.3。本轮在既有项目Nginx1.31.6内，以临时文件执行nginx -t通过后移除；未修改运行配置、reload或启动新服务。初次stdin和只读镜像默认临时目录检查失败，改用项目容器/tmp候选文件与已有/tmp路径完成验证。

当前站只读HTTP观测：HTML200未设置Cache-Control，哈希JS200为max-age=3600，缺失资源404。候选策略尚未应用，列为下一次发布检查项。
