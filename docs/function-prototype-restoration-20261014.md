# 逐功能页面原型还原（2026-10-14）

用户指出上轮主要恢复了菜单，页面内部仍沿用旧结构。本轮以仓库 `zabbix-msp-prototype` 的页面、`app.css` 和 `enterprise.css` 实际渲染为依据，重排29个业务页面及登录页，同时重做资产详情和蜂巢状态。

## 对照原则

每页核对页头、统计卡、工具栏、表格/卡片、详情、编辑区、空状态和移动端。真实接口与原型数据分开：原型数字、曲线、审批成功和演示设备动作不作为业务数据；缺少来源的指标保持未知，现有草稿、权限、幂等与原请求保护保持。原型没有完全同名业务页的功能采用同类页面结构，字段仍以真实API为准。

逐页映射见 [page-reference-map.json](evidence/function-prototype-20261014/page-reference-map.json)，可直接打开[原型与实现对照](evidence/function-prototype-20261014/comparison.html)。

## 核心资源与登录

- 资产：六块本页统计、状态快捷筛选、列表/蜂巢切换、导出与导入入口、独立资料筛选。统计明确仅覆盖当前已加载页，不冒充租户全量。
- 资产详情：从窄抽屉改为全页工作区；设备摘要、六项事实、八个详情分区、未知指标区域、资料/维保/关联/接入操作分别组织。
- 总览：紧凑六KPI、2:1趋势与严重级别区域、通栏服务健康、故障时间线/资源排行、事件/工单分区；缺失来源用对应空态承接。
- 网络监控：绑定设备统计、默认列表、卡片切换、本页搜索、资源来源/错误/TLS说明和实际采样历史；图表仅使用真实采样。
- 登录：原型左右分栏、蓝色品牌区、四项功能介绍与白色表单卡；默认项目账号和实际SSO能力仍由服务端决定。

候选真实浏览器已验证资产蜂巢/筛选/空结果/重置/八分区、网络列表/卡片/搜索和CPU历史。相关42项测试通过；整合候选2040项前端测试通过，类型及正式构建通过。后续分组提交与发布结果继续追加。

## 工单与服务：7页

报障页改为统计、登记列表和分组详情；手工事件改列表/右侧事实；工时改紧凑记录表；通知偏好按渠道卡和当前请求/历史组织；导出以作业列表为主、新请求按需展开；消息采用真实全部/未读筛选与文件表格；SLA采用场景主区和结果对照表。正式工单、SLA与送达数据仍按真实范围显示。

此组217项针对性测试通过，新增折叠导出表单保留输入、未读切换只发GET的验证；整合浏览器桌面/手机页面已回读，无API错误。原提交、恢复和离页保护不变。

## 身份、客户与审计：10页

用户/角色由卡片改为统计、工具栏、成员表/角色矩阵及按需编辑；身份设置与账号采用分组侧栏和事实表；租户/联系人采用紧凑列表和详情；导入页首屏只读取得本人作业、表头与加载/空/错误状态常驻，新批次编辑折叠；导入预览采用阶段、输入和逐行结果；审计常用/高级筛选分层；能力目录提供名称与维度过滤。

原117项针对性检查通过，导入首屏/手机号与长值/编辑关闭补验70项通过；手机用户与角色编辑面板已实际打开和关闭，关闭入口始终可见。没有自动创建联系人或导入作业，也不新增权限规则。

备份、报备、模板、执行单和来源集合改为固定列宽的列表工作区；长名称/UUID在列内换行，操作按钮保持可读，仅表格内部横向滚动。备份/报备默认显示“搜索本页记录”，按UUID回查收进精确查询；编辑与详情在独立区域呈现。

容量页改参数/结果并排、计算依据和Proxy缓冲分区；经营页改统计、指标对照表与侧边样本输入；配置采用状态标签与紧凑列表；阈值采用条件/结果与候选输入双栏。输入未知值、未发布状态和恢复原请求入口保持。

此组251项针对性检查通过，列宽和本页搜索补验123项通过；实际备份记录的本页搜索、清除与读取已验证，不将本页筛选说成全库搜索。
