# 顶部横向模块导航

2026-10-14，按用户“菜单排版，模块要横排，同步修改”实施。原左侧长菜单改为顶部横排模块，下拉进入模块功能，内容区使用完整页面宽度。

已部署到[指定测试站](http://192.168.1.215:10010)，代码基线 `fd1e8f1`；真实公开入口重新登录，六个模块同一横排、无侧栏、下拉进入导出页通过。见[已部署截图](evidence/export-publication-ui-20261014/deployed-horizontal-menu-desktop.png)及[部署后UI记录](evidence/export-navigation-deployed-ui-20261014.json)。

模块为：资源与监控、工单与服务、备份与巡检、客户与租户、经营与容量、系统管理。原有模块入口全部保留；我的账号、租户切换、搜索和退出仍在页头。台账导出入口放在“工单与服务”。

桌面与手机共用一个导航组件，窄屏在菜单行内部横向滚动，页面本身不横向溢出。下拉通过点击/触控展开；当前功能所在模块高亮，导航被未确认操作拦截后仍以真实路由恢复高亮。菜单与路由共用 `routeAllowed` 判定，不因排版变更扩大角色或能力；权限/租户变化销毁旧菜单和已展开内容。

验证包括：最终1851项Web回归、类型/生产构建；10项现有动态菜单权限检查迁移至共用导航，覆盖独立能力、空能力、撤权和错误基础角色。旧断言曾硬编码桌面/抽屉两份菜单，现改为统一入口及动态权限验证；首轮路径断言使用了浏览器URL而非文件路径，修正后全量重验，未降低权限要求。

真实Edge桌面1440px六个模块纵坐标均为72px、无侧栏；手机390px仍为同一横排，文档宽度=390px，末端模块可通过菜单行滚动和触控展开，下拉位于视口内。实际从模块下拉进入导出页，并验证未知下载授权不能通过菜单导航丢弃；响应丢失后原请求恢复。截图已核对布局、菜单层级、触控区域、溢出及弹层遮挡，未见页面横向溢出或页面脚本错误。使用真实登录/后端，但手机为浏览器视口模拟。

实际观察者登录后，导出、用户授权和系统管理菜单项在包含隐藏节点的DOM查询中均为0；没有仅以CSS隐藏代替权限过滤。
