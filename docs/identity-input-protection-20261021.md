# 成员、本人账号及安全设置：输入保护与本地请求准备

基线 main 90b0dcac4fb4246607246d41d088a56e252d19e2。延续[角色编辑保护](role-editor-confirmation-20261021.md)，依据[前端验收标准](frontend-acceptance-standard.md)接入三个身份管理页面；本批只修改程序并使用合成测试，没有实际创建账号、修改密码或扩大权限。

## 完整输入与原请求

- 成员页快照包含原成员、打开状态、全部表单、搜索/分页、标签页以及额外租户/角色/启用选择。本人账号包含原账号版本及三个原始密码输入，安全设置包含当前策略和提供方状态。
- 快照仅用于短期内存比较，不写日志、导出、浏览器存储或服务器；真实敏感值不得用作验收样本。会话失效仍同步清理旧范围和敏感输入。
- 刷新、关闭、替换及导航确认比较完整原输入，clean检查后的首个新输入也受到保护。未知提交保留原命令，不通过放弃确认静默删除恢复凭据。
- 成员候选必须是当前列表的原行；确认期间候选变更不沿用旧批准。分页处理器独立拒绝非正负一、第一页向前以及无后续页的事件，不只依赖按钮禁用。
- 密码重置操作被确认锁定拒绝、结果未知或保存返回时输入已改变，不再无条件清空可见新输入。原命令的私有载荷仍只用于原key重试，不通过通知状态暴露。

## 本地准备失败

共享身份命令在首次状态通知和请求key生成之前复制原载荷，并检查复制期间generation是否变化。通知/生成器回调不能悄悄改写已经选择的请求事实；嵌套命令和销毁优先，旧失败不覆盖新状态。

无法复制载荷、key生成失败、空key或超长key均明确为REQUEST_PREPARATION_FAILED：请求尚未发送、不是网络未知提交，可修正后重新提交。错误不包含原异常文本、载荷或密码；不生成虚假的可重试在途命令。
