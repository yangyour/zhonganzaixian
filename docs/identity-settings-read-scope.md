# 身份设置读取范围防护

2026-10-06，基于7d3e4b4/API0.45。身份设置页现在独立核对账号、角色、租户、权限/账号版本、能力集合、上下文代次及租户切换状态。变化时同步取消读取并清空策略、统一认证状态、未保存输入与命令展示；恢复权限后需明确重新读取，不恢复旧缓存。

每次读取独立使用取消信号和代次，旧响应即使忽略取消也不能重新显示或触发后续接入状态读取。只有具备roles:read才读取策略，users:read才读取认证接入状态。完整读取成功后才显示可写策略，任一阶段失败保持隐藏；刷新须先确认放弃未保存输入，并在确认返回后复查范围。写入口再次检查读取、写入能力、当前策略及加载状态。

新增10项Vue/Element Plus-jsdom隔离测试，覆盖无读取权限、撤权清理、旧策略/接入响应、切换、恢复后重读、确认中范围变化、刷新竞争、接入读取失败和保留提交事件。最初8项在旧实现上7失败、1通过，另有旧异步接入响应造成的渲染错误；修复后最终10项及完整1791项Web测试通过，110文件，类型检查、生产构建及127契约测试通过。失败与成功日志均保留摘要。正常App原本按范围重挂载，本次为页面独立防护，不代表发现真实线上数据泄露。

API/SQL均未改变，密码策略未实际设置，没有真实HTTP或账号操作。真实浏览器/部署验收仍待；正式128项保持NOT_RUN。见[验证证据](evidence/niko-identity-settings-read-scope-20261006.json)。
