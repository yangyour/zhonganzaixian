# 用户管理详情选择与过时回读

2026-10-05，基于e9b550c/API0.45。Vue/Element Plus的jsdom挂载测试复现：选择已有用户后，在详情响应到达前点击“新建用户”，旧详情可覆盖空白新建表单；过时详情失败也会污染新选择的错误提示。未把此模拟复现记成真实服务器故障。

所有编辑选择（含新建）现在都推进读取代次，旧详情/旧错误不能回写。已有用户详情读取中仅显示等待说明，不展示上一用户的可编辑表单；当前详情失败关闭未确认表单。旧列表后续角色回读需核对代次，不能给新选择再发起一条不属于当前意图的详情链路。

新增6项挂载测试覆盖：旧详情不覆盖新建、旧错误不污染新建、两个已有用户乱序回读、详情未到不展示旧表单、当前详情失败无可写表单、过时角色列表不能启动新详情。前3项旧实现2失败留存，最终6项通过。实际组件和Element Plus参与，HTTP为延迟隔离替身，路由离开钩子在此测试中模拟；不是浏览器、网络或授权端到端证明。

本切片不改变API字段、0.45版本、写入收据、SQL或授权规则；所有管理页的即时权限收回清理、表单编辑后手动刷新冲突等仍需独立覆盖。未创建真实账号或写服务器数据。见[检查证据](evidence/niko-identity-user-selection-20261005.json)。
