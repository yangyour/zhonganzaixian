# 重新打开已有导入来源

基线 main：d9eaa106e847a01fce3ab1f19caabb640f511183。API 0.75.0 新增来源列表 GET；原上传 POST 不变，V1–V45 不变。

## 来源列表

GET /assets/import-sources?limit=20&cursor=来源编号。limit 默认20、范围1–50；只接受单个 limit/cursor，禁止未知参数、重复参数、客户端租户或创建者覆盖。

- 数据库当前成员/PV/assets:write、游标归属和查询在同一只读 REPEATABLE READ 快照内核验。
- 只返回当前租户、当前创建者自己的来源；即使平台管理员也不能以列表接口查看别人创建的来源。
- 按不可变受理时间和来源 UUID 倒序 keyset 分页，读取 limit+1 决定下一页；游标必须属于当前创建者。新插入的较新记录不会重复进入后续旧游标页。
- 只返回文件名、格式、大小、来源版本、阶段、是否有映射及时间；不返回原始单元格、SHA、对象存储路径、凭据或全租户总数。缓存与引用策略为 no-store/no-referrer。
- can_import 始终 false，暂存来源列表不是已入库资产列表。

## 前端恢复

“查看我的暂存来源”是显式只读操作。当前页与下一页错误分开，失败清除旧行，原游标重试；上一页保留游标栈，重新查看回首页。取消可返回发起按钮，读取后聚焦摘要；来源列表有标题、列头、行头、可滚动区域与44px操作区。

“重新打开”只能在没有本地文件、没有当前来源、没有未确认请求且技术政策已读回时操作。不能借恢复入口跳过原上传/解析/映射的不确定状态。

重新打开调用既有 owner-only 来源 GET，重新核验身份、版本、摘要、解析指针和政策版本，恢复存储格式、已持久化解析选择及映射预览。没有选择本地 File，不上传、不解析、不保存映射，也不重建或猜测旧请求的幂等 key。读取后再由用户明确发起下一步。

后台解析仍 PENDING 的来源只能刷新状态，不能重新发起解析；已有映射只读恢复。关闭恢复视图不取消后台任务、不删除服务端来源。恢复的未保存映射/解析输入同样受页面离开、上下文切换和关闭页面保护。

若重新打开失败、取消或权限范围改变，不留下部分来源事实；迟到结果不能复活。恢复结果不按文件同名推断原未知请求是否成功。
