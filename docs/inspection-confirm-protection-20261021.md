# 巡检模板与人工执行单的确认保护

## 修复行为

遵循[前端验收标准](frontend-acceptance-standard.md)的输入保护、明确来源和范围隔离门禁：

- 模板新建/编辑/恢复/关闭/离开确认绑定原始表单及有序检查项，不只绑定提交摘要。确认期间改检查项文字、说明或顺序，旧确认失效并保留新内容。
- 人工执行单同样绑定原始结果、备注、时间、原基线、创建来源和候选选择。结果未填写仍不算正常，时间未声明仍不自动补当前时间。
- 归档第二次确认后再次核对原快照，不能清空确认期间的新备注或重排后的模板项。
- 按所选来源准备执行单，既在确认后检查候选选择，又在资产/模板重读完成后检查原表单。异步重读期间的新输入不能被新单初始化覆盖。
- 重读模板必须匹配明确选中的ID、版本和内容SHA256。即使版本号相同，也不接受不同但自洽的新内容，不静默换源。
- 来源读取在发出请求前检查范围、权限、取消和卸载；列表结果返回后也核对原范围与读取代次。卸载后的确认不能授权离开或再初始化。

未修改API、模板发布、设备扫描、证据上传或季度报告；人工结果仍为未核验自述。
