## 冻结内容与追溯

`InspectionSourceSnapshot`绑定租户、执行单ID、选定修订版本、原创建人/时间、该修订记录人/时间、动作与该修订归档标记，保留完整冻结模板及`InspectionWorksheetContent`。已选修订的记录事实有别于可继续推进的头更新时间；fromEntry验证头时间不早于修订，但不把可变updated_at算进旧修订摘要。记录人并非报告审核或发布人。

源快照编码MOP_INSPECTION_SOURCE_SNAPSHOT_V1使用UTF-8长度、64位版本/毫秒、明确归档位、完整模板编码及完整执行单编码。null时间和备注、空备注、未填项、人工结果及未核验证据引用保持原样；不会把记录时间当巡检时间或把未填当正常。指纹用于一致性比较，不是授权签名或真实性证明，证据引用不授予文件访问。

`InspectionSourceManifest`仅收集明确输入的来源快照：按执行单ID和修订版本作技术稳定排序；同一ID+版本重复明确拒绝，不去重后假报成功。不同版本/不同执行单属于同设备时全部保留并给出冲突分组，不自动挑最新、最差或未归档项。未知自述时间、未完整填写和选定归档修订各有来源引用诊断。每个引用同时带来源元数据摘要和执行单内容摘要，可继续追溯具体版本。

所有集合、嵌套模板/答案及诊断映射不可修改；返回字节独立。输入顺序变化不改清单摘要；新修订或外部输入列表变化不回写已有值模型。1000来源与16MiB累计完整模板/内容是技术保护，不是客户业务配额；超过则413，不截断。资源预算包含即使没有答案也很大的模板正文，不能只计一个64字节摘要而漏算其真实体积。

selectedSourceCount和distinctSelectedAssets是已明确选择的集合事实，不是租户总资产、季度完成数或健康率；空选择也不把租户资产总量设0。无论全部结果填写NORMAL还是自述时间已填写，generationStatus仍CONFIG_PENDING，不宣称可以生成正式报告。
