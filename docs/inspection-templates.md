# 巡检模板和人工执行单基础

## 范围及依据

M9-7要求季度巡检由执行单汇总、每台设备一行；路由器/交换机/防火墙/AP分别维护模板，新增设备类型无需改代码。检查内容包括弱口令、固件、证书、配置变更、超期服役、备份状态/验证、线路质量和遗留隐患闭环。结果仅正常/建议关注/需处理，工程师可填备注。M9-9要求报表数字由原记录自动统计，不提供手工改数入口。

Q23实际巡检模板、Q24发布节点和客户展示边界仍待确认。本次先实现纯核心定义及填写快照；不把合成模板作为批准模板，不生成正式季度报告，不执行弱口令扫描或设备命令。

## 数据定义与冻结语义

- `InspectionTemplate`的设备类型标识是1–64位小写字母/数字/下划线/连字符数据，首位字母；不是固定Java枚举。模板名称、分组、检查项标签和说明均为数据；模板项目顺序保留，项标识不能重复
- 每模板1–100项是技术输入上限，不是合同授权配额。名称/标签最多200 Unicode码点、分组100、说明2000；拒绝空必填、非法控制与未配对代理字符；多行说明可保留换行/制表。原文不静默trim或归一
- 不自动生成四种已生效模板。测试向同一个模型传入四种合同设备标识以及第五种自定义类型，仅证明数据驱动结构可扩展；实际内容与批准另行落实
- 定义按版本标签、字段UTF-8字节长度、原文、项数及项顺序形成SHA256；null说明与空说明不同。`Snapshot`绑定租户、模板ID、明确版本和完整不可变定义，并校验摘要。不依赖Map序列化顺序，也不把摘要当授权/客户签字
- 模板版本1..9007199254740990为未来客户端安全版本边界。现有快照不会引用“最新模板”回算，创建下一版本不修改历史模型

## 执行单与来源

`InspectionWorksheet`捕获模板快照、资产ID/显示名称及该模板项的显式填写。模板租户不匹配404，未知检查项400；此纯比较不查询资产/人员/成员，也不证明实际租户授权。未来仓储必须重新核验当前成员、资产范围、模板版本、写权限，并把修订/审计/幂等结果同事务保存。

未填写项的Observation为null，不能视为正常。已填只允许NORMAL/ATTENTION/REQUIRES_ACTION；备注可null或明确空，最多3000 Unicode码点。最多10个唯一证据UUID为技术输入界限，始终`REFERENCES_NOT_VERIFIED`，不签发文件授权、不声称上传/所有权/内容已核验。人工结果为`MANUAL_OBSERVATION`/`SELF_REPORTED_UNVERIFIED`。

record/clear纯函数返回新模型，旧模型不变；这里没有数据库删除。行顺序取冻结模板，不取答案Map顺序。summary只从当前实际答案计算总项/已填/正常/关注/需处理/未填，没有传入报告统计数的操作。`allResultsEntered`仅表示填写完整；即使全部填写，模板仍UNVERIFIED、reportPublishable=false、activeScanPerformed=false。没有风险评分、正式健康结论或自动修复。
