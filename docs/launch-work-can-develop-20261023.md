# ① 无需等待客户，可先开发的功能

2026-10-23｜用于安排开发工作。

**这些功能的通用代码、页面和流程可以继续做。** 客户未确认的数值做成配置项，保持未填写；真实设备、外部发送和生产启用按第二份清单处理。

| 功能 | 现在可以补齐的内容 |
| --- | --- |
| 资产导入 | 字段映射、关联数据校验、去重、配额检查、批量入库、失败回滚和错误提示。客户有争议的映射规则留作配置。 |
| 监控接入 | 接入任务保存、采集任务调度、模板版本管理、分批发布与回退、恢复观察窗处理。缺设备参数时明确显示未接通。 |
| 工单与 SLA | 告警转正式工单、流转与计时衔接、重复请求处理、失败重试、故障复发关联、对账审批流程。 |
| 通知 | 后台发送队列、接收人路由、回执处理、发送结果不明时的核对、失败重试与人工处理页面。 |
| 配置备份 | 任务调度、版本查询及下载权限、恢复申请、失败转工单、保留清理流程、演练记录；实际设备操作与删除暂不启用。 |
| 报告 | 数据快照、月报／体检模板框架、审核发布流程、网页与 PDF 内容一致、版本和阅读记录。未确认评分规则保留配置。 |
| 首页与经营看板 | 已有真实数据的汇总、趋势、待办工单、成本与人效计算框架。缺数据或口径时显示未知，不补造指标。 |
| 租户与权限 | 租户开通流程、配额预留、账号授权、审批审计、保留与删除流程；生产数据库隔离方案先保留可替换设计。 |
| 生产运行与安全 | 生产配置框架、证书检查、安全会话、发布回退、凭据轮换及附件扫描接口、备份恢复脚本。 |
| 测试与验收准备 | 接口、页面、权限、并发与故障恢复测试；完善合同用例、压测脚本和验收记录。已有指定组件可继续用于联调。 |

**优先顺序：资产导入 → 监控接入 → 工单／SLA → 通知，再补备份、报告和经营数据。** 生产运行、安全和测试同步推进。

远程处置目前只可准备接口、权限、审计设计和模拟验证；合同要求客户先确认路线，不能将整个模块列为可立即正式排期。

开发完成、真实接入和正式上线分别验收。涉及外部组件的测试继续复用指定环境；有写入的测试使用已核验隔离范围，不向实际业务租户写虚构数据。
