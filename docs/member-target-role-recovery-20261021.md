# 成员目标租户角色：独立读取恢复

基线 main 3989a3c6710b1e009b9b736d22da772bf6b6f76c。按[前端验收标准](frontend-acceptance-standard.md)落实可达取消、原请求恢复、焦点可预测及表单不丢失。未变更API、权限或数据库。

- 目标角色读取独立AbortController、generation和错误区域。固定账号、目标租户及当前权限上下文；失败/取消可重试原GET，不重发授权写入。主读取或选择/账号/权限变化使旧请求失效。
- 更换目标租户立即清理旧目录和旧角色选择，不让旧响应覆盖新目录；原读取失败不清主表单、成员关系、身份绑定或其他输入。
- 同目标刷新保留明确选择和启用状态。原选择被删除或停用时保留原值、明确提示并禁止提交，绝不自动替换成另一角色。首次空选择仍沿用已有viewer默认，不代表批准生产安全策略。
- 读取中禁用页面写操作，处理器也再次检查，不能只靠按钮disabled。目标租户和启用状态仍可调整。结果按固定租户、唯一角色ID等现有协议校验。
- 成功返回原生角色选择器，失败返回命名错误区域；用户主动移动焦点则不抢回。取消由共享恢复组件显示状态。所有操作仍受后端重新授权和CAS约束，分开GET不是原子角色版本快照。

新增18项完整页面DOM/处理器回归：独立错误、固定目标、取消、旧响应、明确选择、焦点、所有写入口、账号/权限/租户变化、无效目标、重复重试、非法目录、主读取覆盖和卸载。HTTP及模态框为测试替身，不是实际授权或浏览器验收。

首次焦点回归误选了禁用fieldset里的select，未能真正移动焦点；改为目标租户的可用原生select并先断言焦点确已移动。原失败结果保留在验证记录，不将测试驱动修正描述为产品缺陷。
