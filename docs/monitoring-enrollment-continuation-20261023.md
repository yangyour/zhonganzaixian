本批接在既有服务器预设计划与严格单次探测器后，不重写234项客户目录、不把预设覆盖当成已采集。已实现持久申请、明确审批、停用登记、取消和单次只读探测日志，并接上实际API、页面、契约和原请求恢复；整体M02仍未完成。

## 行为边界

- 服务端重新生成明确资产/场景计划，冻结资产版本和管理地址、目录 SHA256、配置 SHA256。请求不接收任意 URL、凭据、扫描 verdict 或 enabled 覆盖。
- REGISTERED_DISABLED 只表示持久登记，所有目标 enabled=false，不代表外部监控已应用、持续采集、设备身份或业务健康。单次核验也不提升为 ACTIVE。
- 缺审批名单/自审规则保持未配置，旧批准与精确策略内容绑定；登记和探测前重查审批者当前成员/权限。
- 资产或目录变化，拒绝沿用旧任务继续登记/探测；历史目录可只读查看并取消，不因旧目录不兼容而隐藏整个任务。
- 现有静态目标目录保留。新增任务页面嵌入原接入页，不新增主导航或大块统计。原命令先存最小会话日志，结果未知时恢复同一请求，不能据当前 GET 或拒绝重放伪造已确认。

## 配置

- MOP_MONITORING_ENROLLMENT_ENABLED 默认 false，新结构未就绪时不替换旧目录。
- MOP_MONITORING_ENROLLMENT_APPROVAL_POLICY 按租户UUID映射 reference、reviewers、self_approval_allowed；缺值保持 null。
- MOP_MONITORING_ENROLLMENT_TEST_ENABLED 默认 false。
- MOP_MONITORING_ENROLLMENT_ALLOWED_ENDPOINTS / ALLOWED_TARGETS 为精确已有端点与下游允许列表，默认空；未配置不调用网络。
- 采集器名称继续由 MOP_MONITORING_ONBOARDING_COLLECTORS 提供，不从页面接受凭据。
