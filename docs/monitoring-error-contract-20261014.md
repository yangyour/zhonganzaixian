# 监控错误信封契约补齐

2026-10-14 逐功能验收中，跨租户监控历史请求实际正确返回404和统一错误信封，但基础监控及防火墙资源的OpenAPI错误状态只有说明文字，没有JSON响应Schema，导致当前严格契约验证失败。

已补齐4个监控GET接口的400/401/403/404/422/503错误信封声明，全部引用既有 `Error` Schema，并更新契约生成器和生成结果。运行时响应、权限和接口版本0.49.0不变，无后端部署或数据库迁移。

134项契约检查、生成一致性检查通过。当前测试站复验包括4设备基础历史、CPU/内存历史、跨租户404、未知参数400；共45次真实HTTP（包含环境登录和其他只读模型）通过。首次失败保留在验收记录中。

证据：[首次严格契约失败](evidence/feature-acceptance-20261014/http-a92a73a7-21e0-472e-b60b-1dda9ef4a348.json)、[契约补齐后的真实HTTP](evidence/feature-acceptance-20261014/http-7b741526-2c0d-4d35-92ed-4b53e62217b6.json)。这不代表真实供应商故障注入或全部监控业务验收完成。
