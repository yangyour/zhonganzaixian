# 监控历史曲线的采样数值表

基于 main 2271944，在现有网络/防火墙历史曲线旁增加原生可展开的采样明细。不增加接口、不导出文件、不改变查询范围或采集数据。

## 交互与事实

- 用户从原设备“查看历史”或资源指标入口取得历史后，可展开“查看采样数值”。显示明确设备引用、指标、时间来源、北京时间、原始UTC、原始十进制字符串和单位。
- 网络指标使用Zabbix记录时刻，防火墙资源使用采集端接收时刻；不把接收时间冒充设备采样时间。
- 数值不转浮点、不四舍五入；0是真实值而非空值。状态指标没有物理单位时明确为状态值0/1。
- 每页20条，本地首页/上一页/下一页/末页，完整保留接口已返回点，非截断。分页不发额外请求。
- 采样缺口按接口阈值提示，包括跨分页边界；不插入零点、不声明查询窗口完整。空返回明确不证明设备健康或一直无采样。
- 读取新历史或变更身份后重置分页/清除旧详情。可结合前一批“暂停自动刷新”稳定阅读。

## 前端验收

按frontend-acceptance-standard.md提供曲线的文字/数值替代：原生details/summary、caption、列/行表头scope、独立可聚焦横向滚动区、44px分页控件及可见焦点。分页后聚焦新页表格区域，状态提示当前页和总条数。

新增7个表格组件测试及1个整页入口/身份清理测试，覆盖精度、分页全量、跨页缺口、时间来源、零值、空态、数据切换、语义与焦点。完整结果见evidence/monitoring-history-table-20261021.json。

本批是合成DTO和原生DOM测试，不声称真实浏览器、屏幕阅读器、视觉回流或供应商联调通过。浏览器执行仍受已记录环境限制，NOT_RUN；后端/API0.71.0/V1–V45不变，正式128项TC不变。
