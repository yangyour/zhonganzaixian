# 监控接入配置工作区（2026-10-22）

## 可操作范围

入口“资源与监控 / 监控接入配置”，同时要求 assets:read 和 configurations:read；页面与导航使用一致能力门禁，且限真实会话模式。沿用 main 74396c 合并的工作区/控件样式，未回滚既有页面改版。

1. 从13种预设选择服务器、网络、HTTP/TCP/ICMP、数据库或容器场景。
2. 输入资产ID，可明确点击读取现有授权资产名称/IP；不会自动创建资产，也不会在输入时触发网络请求。“使用资产IP”是独立明确动作，代理采集场景只填写下游地址，不误覆盖Exporter地址。
3. 填写IP、端口、协议、超时及所需下游参数。Exporter与HTTP下游分别选择协议；SNMP只接收采集侧命名配置，不接收密码。
4. 本地校验配置并下载同一接入ID的JSON。默认disabled、周期空；启用输出必须显式填写周期。下载不是部署，不写服务器，也不会对浏览器输入的任意目标直接发请求。
5. 页面生成精确端点/下游授权的CLI单次测试命令。在实际采集侧运行后，可导入至多64KiB报告；核对目标ID及完整配置SHA256，修改任何配置后清除旧报告。

CLI说明、配置生成与现有Zabbix交接限制见 [前一切片](monitoring-presets-20261022.md)。本页面尚不提供服务器端一键网络探测、持久化注册、自动应用、持续采集、历史入库或告警发布；这些不是“外部参数未提供”就可以略过的内部接线工作，须后续继续实现。

## 一致性与交互

- 13份跨Python/TypeScript黄金配置与摘要逐项一致；共享预设目录，不维护另一套场景名单。
- 复用项目HTTP IP环境的安全随机UUID/SHA256兼容层，不依赖仅安全上下文可用的 randomUUID/subtle。
- 资产读取可取消；输入资产ID、切租户、身份/权限/账号版本变化或卸载时取消在途请求，迟到响应不回填。
- 草稿离开/清空及上下文主动切换先确认；取消保留原输入，确认期间新增输入或换身份使旧确认失效。强制撤权清除私有输入和报告。
- 导入报告是用户提供的材料，只核对结构和与配置的一致性，不能独立验证来源真实性；报告不能宣称健康、设备身份或持续采集已验证。TCP连通与样本格式通过分别显示。
- 报告读取/摘要计算过程中改配置或换身份，迟到报告被丢弃。错误报告不沿用旧成功结果。
- 表单持久标签、44px交互目标、手机单列、可取消读取、可定位标题及下载反馈；不恢复大统计占位和说明卡。
