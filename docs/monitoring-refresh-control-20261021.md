# 监控自动刷新：可暂停与授权上下文隔离

基于 main 653edc7。遵循 frontend-acceptance-standard.md 的可控制自动更新、状态恢复、键盘焦点和租户/身份隔离要求；不声称整个页面已通过WCAG或真实浏览器验收。

## 用户可用功能

- 新增“暂停自动刷新 / 恢复自动刷新”。暂停停止本页监控数据的定时及可见性触发读取，取消当时在途的概览、资源与历史请求，忽略迟到响应。
- 已取得的概览和历史保留供阅读；没有取得的历史明确标为尚未取得，不冒充没有采样。未取得资源说明自动刷新已暂停。
- 暂停时仍可明确点击“刷新监控”或选择设备/指标查询历史；手动操作不会偷偷恢复定时刷新。
- 恢复仅在当前有效刷新配置允许时触发一次读取，随后遵循配置周期；不能覆盖被禁用、失效或尚未取得的配置。
- 页面时效计时继续，暂停超过有效期照常标过期，不把旧样本长期显示健康。暂停不停止后台采集，授权/刷新配置独立核对仍继续。
- 按钮44px目标、焦点可见，切换后保留按钮焦点；状态用文字说明，不只靠颜色。

## 隔离修正

原监控数据watch只包含租户、权限版本、全局代次与读取许可。补用户ID、角色和运行模式，避免同租户/同版本/同能力的账号变化仍保留旧数据。重置同时清除设备搜索文本、选中设备、历史及资源值。用户的列表/卡片偏好、时间窗口和暂停选择不含业务事实，可以保留；切新授权上下文仍首次读取其独立数据，之后遵守暂停选择。
