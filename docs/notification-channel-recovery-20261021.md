# 站内通知外部发送：原请求、回执与父列表保护

基线 main 626ae2d8d75d9bfc91e2148b6bc1470f471e50a1。按[前端验收标准](frontend-acceptance-standard.md)补齐“发送到我的邮箱/企业微信”独立组件及其父通知页，不触发真实供应商或自动派发。

## 发送与回执

两个入口复用同一组件：明确确认、重复点击抑制、当前账号版本/能力/通知ID校验、原key未知提交恢复，以及已受理后的独立GET取消/重试。无效通知ID或父列表正在变更时不进入发送确认。确认期间账号、通知或父页面状态改变，旧确认不提交。

原POST回执在身份命令标为accepted之前进行完整范围校验。错误来源、租户、账号、状态、额外字段或非法时间仍为结果待确认，不能冒充成功。私有命令结果和对外通知快照相互分离，避免回执被传输对象或订阅者改写。

读取严格对应V38/V39既有返回字段及状态约束：QUEUED/v0、PROCESSING/v1、终态/v2，起止时间顺序、供应商受理标识/代码、精确通知来源、收件地址及邮件发送方。固定原回执ID与不可变事实，保留最高已观察版本；刷新失败/取消不允许回退，同版本不同事实拒绝。等价UTC毫秒表示不误判。

“服务器已受理请求”“通道已受理”和“收件人已收到/已读”明确分开，不增加DELIVERED/READ推断。已接受写入后GET失败，只恢复GET，不重新POST。读取成功聚焦结果，读取失败聚焦受理但未核验说明，取消聚焦恢复状态；44px控件与可见焦点进入源码/DOM检查。

## 父子组合保护

通知页按范围、通道和通知ID分别记录子操作。确认、发送未知或回读期间，刷新、筛选、翻页、派发台账切换、标记已读及自愿离开不能卸载原请求组件。两个通道可各自恢复，一个完成不解除另一个的保护。

反向也设门禁：父页标记已读/读取开始后，子组件不能新建发送。强制账号/权限变化仍同步清理旧数据；旧子组件事件不得删除新范围的阻塞记录。

组合回归发现共享busy函数读取了非响应式私有命令状态，导致父级computed未感知未知提交（2失败/100通过）。已改为读取响应式command状态，保留[修复前输出](evidence/notification-channel-recovery-20261021/parent-blocker-before-fix.log)。这不是仅给按钮添加disabled，事件处理器和父子运行状态也独立检查。

## 验证与限制

新增73项：36项回执协议/读取器、28项真实发送组件DOM、6项完整父子DOM，以及3项身份命令回执校验/隔离回归。定向106项通过。模态框与传输均为明确替身，不声称真实浏览器或供应商通过。

初轮类型检查发现包装组件import语法、异步状态静态缩窄及测试Mock泛型问题；分别改为独立类型导入、状态谓词和精确Mock类型。未修改依赖库声明、放宽生产类型检查或恢复云CI。
