# M8-10 静音时间纯核心

`QuietHours`按明确时区的本地日历判定静音窗口，供未来真实通知计划器调用，不是发送许可，也不执行发送、写库或记录供应商回执。来源为开发文档02 M8-D07及TC-M8-10。

输入为可信优先级映射给出的`isP1`、带版本的策略及明确Instant。P1只绕过静音过滤，仍必须满足租户授权、联系人启用、合同渠道、已确认严重级映射等其他门禁。不得直接使用客户请求中的P1声明。

窗口为[start,end)，起点包含、终点排除；start>end表示跨午夜。明确使用ZoneId，不读取服务器默认时区。夏令时秋季重复的两个本地时刻均按窗口判断；春季跳过的本地时刻不凭空补造。起止相同拒绝，不能猜成全天或关闭。

非P1缺策略版本、启用值、已启用窗口的时区/起止或时间，返回UNRESOLVED并附原因；优先级未知也不默认为非P1。明确关闭的版本化策略不要求窗口或时钟。未知政策与明确不静音分开。该纯过滤结果不计算下次发送、不修改重试预算、不把静音当已送达。

20项隔离JUnit覆盖同日/跨日纳秒边界、时区、P1绕过、缺值、明确关闭、歧义起止以及DST跳时和重叠。测试策略版本和时间均为合成输入。尚无偏好页面/真实仓储、派发队列、原始通知记录、六渠道、电话30秒或真实回执；Q14/Q15/Q18等未解除。API V0.8不变，TC-M8-10保持NOT_RUN。见[证据](evidence/dot-quiet-hours-20261002.json)。
