# 值班看板读取恢复与输入保护

按 frontend-acceptance-standard.md 的任务完成、状态完整、安全恢复、上下文隔离及键盘语义门禁修复，不将组件测试等同真实浏览器或正式业务验收。

## 已修复

- 增加明确的暂停/恢复自动刷新控制。填写表单、有未知写入、读取失败、页面隐藏，以及焦点位于表单、表格或视图切换按钮时，不自动刷新移除用户正在操作的内容。恢复按钮只恢复周期，不隐式提交或立即请求。
- 在途GET可取消；取消后自动刷新暂停，迟到响应不能重新填入页面。取消按钮不能取消POST/PATCH或清除未知提交；焦点回到刷新按钮。
- 初始/加载/失败/取消不显示“队列为空”；只有成功返回的当前快照为空时才显示空状态。读失败显示明确重试入口，写入校验错误不误标为读取失败。
- 显示快照观察时间、队列最多25条及倒计时为快照值的边界，不伪装为持续计时或全部工单。交接台账18:00口径与实际显式登记分开描述，不声称前端自动交接。
- 账号account_version与原租户/账号/权限版本一起作为失效边界。变化时清除旧输入、回执和载荷并丢弃迟到响应；在changed或幂等键生成回调撤权后，不再派发旧GET/POST/PATCH。
- 离开与清除策略弹窗记录原输入快照。弹窗期间再次编辑，旧确认不能丢弃新输入。
- 已核验保存回执与后续GET结果独立。取消回读仍保留已确认保存事实，不允许把同一操作误当成未保存再次重试；异步完成只清理仍匹配原快照的输入，不清除新编辑。
- 五类表格都有caption、列标题scope、可聚焦命名滚动区域和可见焦点；保持44px控件产品目标与窄屏单列布局。

未改变现有排班、交接、升级、策略、幂等或权限API协议，也未启用短信网关、真实呼叫、自动交接或待确认Q15规则。队列仍使用既有/oncall/board?page_size=25，失败重试仅GET，不重放已确认写入。
