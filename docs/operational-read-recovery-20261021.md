# 经营显式测算输入保护与取消

本次修复既有经营样本与人力测算页，不增加成本账单、真实工时聚合、FTE来源或正式经营指标。

- 只读测算可取消，保留原始样本、问号未知项、合法零值和人力输入；取消后回到测算按钮。错误允许以当前输入重新测算，不自动重发。
- 取消、编辑、撤权/账号版本变化后的迟到响应不显示；忙碌回调中改输入或范围时阻止旧POST派发，不把新输入混入旧请求。
- 重置、离开、自愿切租户和关页保护内存输入。明确“无样本”也是用户输入，不当成空白未编辑。确认弹窗期间有编辑或范围变化则拒绝旧确认；强制失权立即清理旧范围。
- 去掉会静默截断的 textarea maxlength。430000字符的合法输入技术边界仍在读取器验证，超限保留原文、显示错误、零请求；不截取子集计算。
- 结果表增加caption、列标题scope、可键盘滚动region；页面控件44px目标、焦点轮廓、状态通知和说明文字对比度进入源码。公式、DECIMAL128、未知/空样本/零分母及Q23/Q27/Q30边界不变。

新增3项工作区和11项DOM测试，前端3452项/230文件、契约173项通过；构建、发布工件与候选安全策略通过。4项本地Vite HTTP200且内容检查通过，服务已停止；不代表执行真实API或浏览器。
