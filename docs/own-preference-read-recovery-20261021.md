# 本人通知偏好读取取消与原历史边界恢复

## 可用性修正

本人偏好当前快照和历史分页增加独立读取取消、原读取重试及可聚焦状态提示。取消读取保留未保存的等级、渠道、静音输入、原编辑基线和写入身份，不把当前读取失败显示成没有偏好，也不把读取成功当作保存结果已确认。

历史续页失败会清除不可靠的显示数据，但恢复目标独立保存原偏好ID、before_version和跨页时间边界。重试仍校验连续版本、摘要、原记录事实及时间不倒退；不能为了恢复而跳过边界，或自动退回第一页。新的明确读取替换旧目标，成功读取、开始新编辑、失效范围或卸载清除旧恢复入口。

页面把账号account_version纳入范围标识，账号版本变化立即清理旧私有编辑和恢复状态。命令key生成回调抛错时也复核原代际，避免旧异常覆盖新范围。

## 业务边界不变

仅保存本人偏好请求草稿，仍是CONFIG_PENDING、effective=false、notification_dispatched=false；未知渠道与明确空集合、未知静音与明确关闭不混同。P1突破静音的合同声明不代表实际发出通知，Q14/Q18未确认策略不补默认值。

取消只结束前端等待，不能取消已提交的保存；写入进行中不可使用读取取消。未知保存继续锁定原key/body重试，不能借刷新或取消生成新请求。
