# 本人工时列表、详情和历史读取恢复

## 用户可见行为

列表、当前记录及历史读取支持独立取消和原请求重试，取消后焦点返回状态说明。保留原始筛选文本，不改写带时区输入；列表恢复成功后才将条件标为已应用。取消详情保留列表，不把未完成详情当作零工时或无历史。

- 列表续页失败后保留原已应用筛选和created_at/id成对游标，重试不退回第一页。
- 详情与历史为两阶段GET：恢复仍重新核验同一工单/工时、当前版本和事实，再读取匹配历史；不会跳过第一阶段校验。
- 历史续页原版本未变化则保持原before_version。若已核验到更高版本，沿用既有规则从新版本历史开始，并明确提示边界重置；即使随后的历史请求失败，重试也不能退回已见过的旧版本。
- 新筛选输入立即清除旧结果和旧恢复目标，不隐式读取；显式关闭详情放弃该详情恢复。账号account_version、租户或权限变化清理旧私有筛选与读取状态。
