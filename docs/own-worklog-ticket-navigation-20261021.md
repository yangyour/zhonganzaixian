# 本人工时到关联登记工单的读取入口

## 功能

本人工时列表和当前记录详情增加明确的关联工单链接，指向既有/tickets?ticket_id=对应ID的登记详情。工时依附于登记工单，因此不把该ID擅自解释为已激活六态工作流，也不自动接单、激活、审批或打开工时编辑。

只有当前用户同时拥有worklogs:read_own及tickets:read，且仍为本页允许的内部工程师身份时显示入口；只有工时读取权限时保留原关联ID，不展示无权入口。目的页及服务端仍须重新检查权限，链接不是授权。

点击必须来自当前已验证列表或当前详情对象；新查询、刷新替换、读取中、身份/账号版本变化、撤权及卸载后的旧事件都拒绝。合法链接保留原生修饰键/新标签页操作，不强制用脚本接管所有点击。

列表补充有名称且可聚焦的横向滚动区域、说明本页人工填报范围的caption、列标题scope及44px链接触点；焦点有可见轮廓。跳转不写工时或保存筛选，普通返回仍按页面既有读取行为，不宣称跨页持久化筛选。

## 验证

新增12项真实Vue Router与DOM合成测试，连同既有工时页面共37项定向通过。其中1项实际装载既有TicketsPage、读取准确目标并核对ticket.id、worklogOpen=false和worklogTarget=null；其余入口、权限撤销、原行身份、读取忙碌、卸载、修饰键和表格语义分别验证。全部请求仅GET。

修饰键测试在确认产品没有拦截事件后，由测试专用监听器阻止jsdom不支持的整页导航；这只验证事件语义，不宣称已实际打开新标签页。

本地Vite验证两条路由和两个页面模块，共4项HTTP检查后停止。后端/API/DDL未改，不重复Java/数据库。真实浏览器、键盘/读屏/视觉与axe仍NOT_RUN，不把DOM焦点和源码尺寸当作WCAG符合；74项浏览器规格和128项正式TC状态不变。
