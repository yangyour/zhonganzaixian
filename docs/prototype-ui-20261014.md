# 按本地原型完善应用样式（2026-10-14）

## 设计与实现

用户要求依照本地原型优化现有样式。本轮依据 `zabbix-msp-prototype/assets/css/app.css`、后加载的 `enterprise.css` 和实际原型页面，修改 `apps/web` 的 Vue 应用。父目录与仓库内原型的同名文件摘要一致。

- 恢复 56px 顶部模块导航、200px 左侧功能菜单和 52px 上下文栏；左栏可折叠至 64px。六个一级模块仍只列出实际获准的路由，手机使用可横向滚动的模块栏及功能抽屉。
- 采用原型的亮蓝主色、浅蓝背景、细边框和小圆角，统一页标题、筛选、表格、分页、表单及空状态；台账增加设备图标与未知/待接入标识。
- 总览保留六指标和六面板固定顺序，调整为独立指标卡、首排 2:1 及后续双列布局。未接入状态始终可见，技术说明可展开，没有复制演示数字或模拟趋势。
- 网络监控沿用真实设备与 CPU/内存历史，统一卡片和标题风格。
- 修复账号页返回首模块、联系人导入预览的菜单归属，以及断网提示被固定顶栏遮挡的问题。路由守卫拒绝后保留当前页和菜单；权限、角色、版本或租户切换变化时关闭手机菜单。

桌面密度参考原型；手机保留至少 44px 的主要操作目标，明细表格在自身区域横向滚动，整页不横向溢出。

## 接口与组件边界

`contracts/local-api.openapi.json` 和 HTTP 行为未修改；仍使用既有登录、会话、资产、总览、搜索和监控读取接口。原有租户授权、CSRF、幂等、乐观锁、审计、保存结果恢复及离页守卫保持。

浏览器候选页面使用本地正式构建及回环 HTTP 代理，接口请求转发到指定 LAN 测试站。没有本地数据库、缓存、监控替代品或业务 fixture。测试只执行登录和只读操作，不提交资产、工单或配置写入。连接与账号信息从 Git 忽略的私有配置读取，截图遮盖身份信息。

本轮没有新增组件、后端发布、迁移、采集器或其他服务生命周期变化。实际监控读取不等于首页监控指标接入或全部合同验收；生产就绪与待客户确认项保持原边界。
