# 共享测试环境QA清单

当前计划针对 `remote_test`，本地应用及涉及外部组件的集成测试连接指定服务器的PostgreSQL/Keycloak。纯计算与策略单元可以隔离替身；历史fixture默认跳过，不作本轮联调证据。执行结果单独维护于 [验证记录](verification.md)，本清单不自动声明全部通过。

|行为|应验证的服务端边界|界面与证据|
|---|---|---|
|真实OIDC登录、退出、重新登录|授权码、PKCE S256、state/nonce、标准token验证与issuer+sub映射；同名重建不得继承权限|密码仅在Keycloak输入；API不返回bearer token；真实RP退出清除SSO|
|伪造注销/非法回调|GET注销无pending、invalid-state请求不得改变既有授权会话|随后session仍有效；错误不展示协议token或秘密|
|可信租户上下文|每请求成员复核；事务内权限版本复核；跨租户对象统一404|平台切换清除旧数据/抽屉；客户只见所属租户|
|撤权与角色降级|旧Cookie及已提交写重放不能绕过当前成员/角色；恢复时权限版本单调增加|viewer无创建、配置、审计及租户切换入口；直接HTTP同样拒绝|
|资产查询与游标|白名单参数、分页选项、稳定created_at/id排序；游标绑定tenant/actor/筛选/权限版本|加载、空、失败、未知分开；刷新保留有效URL筛选|
|资产持久草稿|同租户名称唯一、IP字面量格式、站点归属；幂等同异体、双连接并发与整事务回滚|source=test_seed/manual，状态未知、sampled_at=null；IP冲突域仍待Q31|
|接入与发布门禁|422 CONFIG_PENDING；不生成operation或虚构外部完成|显示关联Q编号及trace_id，不显示已纳管或已批准|
|配置登记与独立草稿|185项原value/pending null不改；类型检查、固定约束拒改、CAS仅一胜者|registered/draft分列，effective_value不激活；未知值不转0/false|
|耐久幂等与审计|业务/成功审计/重放结果同事务；审计序号/hash可重算；运行角色不可改删审计/登记正文|只展示授权租户的脱敏审计；外部链头及保留策略另行开发|
|真实依赖就绪|PG实际数据库/运行角色及Keycloak探测；断SSH连接ready/write503且不回退|UI明确共享测试模式；恢复后仍remote_test/durable，生产就绪false|
|重启持久性|停止/启动真实API后重新OIDC登录；资产、旧key重放及配置草稿/版本不丢|保存进程身份变化证据，不把新仓储实例当作进程重启|
|工程与客户端复现|远程PG集成、纯单元、契约一致性、前端test/typecheck/build、可审计启停|1440×900及390×844；真实tadmin移动页无水平overflow；截图不含凭据|

后续专项仍需补：生产Q02租户物理隔离、客户正式身份/岗位、OIDC异常签名/轮换/过期、Worker撤权与租约、outbox崩溃恢复、真实监控/ITSM/堡垒机/通知、第二机器与云端复现、容量/性能/灾备及合同逐项验收。发现缺失组件先登记用途、证据、影响、替代候选及状态，不安装本机替代服务。

测试证据只记录环境、组件版本、脱敏trace和结果；私有原始连接文件、密码、Cookie、CSRF/OIDC token及含密连接串不得进入源码、Git、公共日志、截图或报告。成员变更测试仅作用于本项目虚构身份，并在finally恢复原关系、增加权限版本。
