# P01：返回前全局账号版本复核

## 问题与修复

项目身份过滤器原先只在请求进入时检查全局securityVersion；共享读取返回守卫再次核对租户Membership，但该记录不含全局账号revision。因此，长读取期间重置密码、撤销会话或撤销外部身份绑定，如果成员权限版本未变，返回检查可能遗漏账号状态变化。

过滤器现在只在初始项目身份检查成功后安装请求内的返回复核器。共享 DashboardReadAuthorization 在完整成员复核之后，再验证原Authentication、会话ID、当前全局账号revision和强制改密要求。账号变化返回401，改密门禁返回403，账号存储失败/异常空响应或项目身份缺少该守卫返回503；私有异常内容不进入响应。

复核失败只拒绝本次读取，不主动销毁可能已并发刷新为新身份的会话。原请求进入时的旧会话失效处理保持。用于完成改密的既有账户端点白名单保持；没有放宽登录、CSRF、租户权限或数据库权限，也没有创建凭据/授权。

## 生效范围与边界

适用于已调用共享返回守卫的项目身份读取，包括主干的待办投影、事件中心三个GET和角色矩阵等；本地接续树中的资产事实、诊断、报告、附件安全、事件指标和运行历史也复用它。尚未远端合入的功能不因本次小补丁而自动出现在main。

复用当前项目身份模式及其绑定身份的securityVersion，不为没有项目身份权威的隔离测试上下文编造版本。真正的ProjectSessionIdentity若缺少请求内守卫会失败关闭。检查位于控制器返回边界，不是全局响应缓冲器，不声称已覆盖所有其他独立读取器、流式输出每个字节或任何读取后的账号变更。其他返回边界、真实登录/并发数据库/浏览器验证仍需继续核销，P01不标整项完成。

## 验证

在独立origin/main ae5142c1上运行最初新增10项用例，全部失败，证实旧守卫未复核全局账号；修复后连同原身份、成员撤权、事件和角色矩阵回归通过。另补空账号存储结果的失败关闭用例。精确数量见 `docs/evidence/dot-continuation-20261023/p01-account-read-return.json`。

测试使用合成账号/仓储/过滤器调用，没有更改真实密码或会话，也没有真实PG/OIDC/浏览器联调。无API成功DTO变化、无迁移或部署。
