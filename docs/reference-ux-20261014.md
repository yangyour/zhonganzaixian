范围：现有 MOP Vue 应用。参考 `E:\work\wxw08\yinjuxiangli` 当前源码中的 `ListSearch.tsx`、`AutoTextarea.tsx`、`ModalForm.tsx` 及其列表简化、文本框和界面验收记录，迁移操作方式；参考项目未修改。

## 实施与接口边界

- 资产台账、报障登记：输入草稿和已应用条件分开，点击状态不顺带提交其他输入；查询、Enter、清空和重复查询行为一致，中文输入法选词不触发查询。已应用条件可逐项移除，空结果提供恢复入口。显示的是本页条数；读取中、失败、尚未读取分别呈现。
- 报障描述、工时备注：复用 Element Plus 文本框自动增高和缩回，宽度变化重新计算，超过上限内部滚动。保持原字段校验、未确认请求与上下文保护。
- 共用宽表：仅实际溢出时显示左右入口，操作内层表体；区域聚焦后支持左右、Home、End，表内按钮和输入仍处理自身按键。容器和内容改变时重新判断边界。
- 页面阅读：沿用当前蓝色导航与原型布局，提高表格正文、辅助说明和链接的可读性，保留未知、草稿、待接入及当前页范围。
- 窄屏修正：资产与配置摘要不再继承旧布局的第三项整行跨度；配置卡片保持等高。身份成员表为姓名、账号及其他列保留合理宽度，长内容在列内换行，表格自身横向滚动，避免名称被压成竖条。

API 路径、DTO、租户授权、CSRF、幂等、乐观锁、审计、数据库均未修改。未新增服务或运行依赖。真实浏览器使用本地生产构建和既有回环预览，转发至指定 `lan-test-20261008` 的真实 API；未替换响应、创建本地基础组件或提交业务数据。
