# 剩余开发推进清单

执行原则：一个 dot 直接开发；缺少业务值和外部依赖做成显式配置，不编造生产默认值。每独立功能同步测试、文档和 main。按 frontend-acceptance-standard.md 验证任务可用性，不只检查页面存在。

|顺序|模块|已接续|后续可开发链路|需要独立真实验收|
|---|---|---|---|---|
|1|资产/CMDB|来源字典、33列本地预检、受保护服务端来源检查|可信引用/地址策略、配额与去重、事务入库、新字段持久化与旧类型转换|真实源文件/存储/并发配额/客户映射|
|2|设备监控|基础监控、AF资源、事件中心与适配器|统一接入、发布模板/OID消费、恢复采样观察窗|各厂商权限/设备/采集覆盖|
|3|工单/SLA|流转、客户动作、耐久任务及模型互斥|登记重试已补；继续正式激活/外部建单补偿、复发关联、通知派发、对账审批|生产口径与真实供应商|
|4|通知|站内消息、部分渠道、路由核心|持久路由/Worker、回执认证、未知结果查询/死信|渠道端点、凭据、额度和发送许可|
|5|备份|计划草稿/状态/差异核心|计划执行、版本归档、失败工单、演练|设备、存储、KMS与执行许可|
|6|远程处置|尚无完整堡垒机业务链|受控连接申请、设备授权、审批/会话/审计关联|堡垒机接口、录屏与命令拦截|
|7|报告|巡检和季度报告草稿|统一数据源、月报/体检、PDF发布、阅读记录|报告口径及客户交付|
|8|经营分析|显式试算和容量估算|真实数据聚合、成本毛利、人效/指标与导出|费用、人员与经营定义|
|9|租户治理|账号/角色/成员/审计|开通、配额、隔离档位、保留清理|物理隔离及删除政策|
|10|首页与验收|部分真实监控/报障展示|告警/工单/SLA统一聚合、整体回归|浏览器矩阵、规模/故障/部署及128项TC|

上述不是完成百分比。当前仍为 128 项正式验收 NOT_RUN；功能切片、HTTP 请求和测试数量不能替代整项验收。
