# 剩余开发推进清单

执行原则：一个 dot 直接开发；缺少业务值和外部依赖做成显式配置，不编造生产默认值。每独立功能同步测试、文档和 main。按 frontend-acceptance-standard.md 验证任务可用性，不只检查页面存在。
