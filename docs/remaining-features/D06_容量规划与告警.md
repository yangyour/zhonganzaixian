```java
@Transactional
public void approve(UUID scenarioId, UUID approver, UUID tenantId) {
    CapacityScenario sc = repo.findByIdAndTenantId(scenarioId, tenantId).orElseThrow();
    if (sc.getStatus() != ScenarioStatus.PENDING_APPROVAL)
        throw new IllegalStateException("只有待审批状态可批准");
    sc.setStatus(ScenarioStatus.APPROVED);
    sc.setApprovedBy(approver);
    sc.setApprovedAt(Instant.now());
    repo.save(sc);
}
```

## 三、容量告警 Worker

**文件**：`src/main/java/com/mop/capacity/CapacityAlertWorker.java`
```java
@Component @Slf4j
public class CapacityAlertWorker {

    // 每分钟检查一次
    @Scheduled(fixedRate = 60_000)
    public void check() {
        List<CapacityAlertRule> rules = ruleRepo.findAllActive();
        for (CapacityAlertRule rule : rules) {
            try {
                // 查询该指标近 N 分钟的平均值
                double avg = metricRepo.avgRecent(
                    rule.getDeviceId(), rule.getMetricName(),
                    Duration.ofMinutes(rule.getDurationM())
                );

                AlertSeverity severity = null;
                if (avg >= rule.getCritThreshold())
                    severity = AlertSeverity.CRITICAL;
                else if (avg >= rule.getWarnThreshold())
                    severity = AlertSeverity.WARNING;

                if (severity != null) {
                    // 检查是否已有未恢复的相同告警（避免重复）
                    if (!alertRepo.existsUnresolved(rule)) {
                        Alert alert = Alert.of(rule, severity, avg);
                        alertRepo.save(alert);
                        outboxService.publish("alert.capacity",
                            alert.getId(), rule.getTenantId());
                        log.warn("Capacity alert: rule={} severity={} avg={}",
                            rule.getId(), severity, avg);
                    }
                } else {
                    // 指标恢复：关闭未恢复告警
                    alertRepo.resolveAll(rule);
                }
            } catch (Exception e) {
                log.error("容量告警检查失败 rule={}", rule.getId(), e);
            }
        }
    }
}
```
