## 二、工单状态机（Domain 层）

允许的状态转换规则：
```javascript
OPEN         → ACCEPTED    （运维员接单）
ACCEPTED     → IN_PROGRESS （开始处理）
IN_PROGRESS  → RESOLVED    （标记解决）
RESOLVED     → CLOSED      （客户确认）
RESOLVED     → IN_PROGRESS （客户拒绝，重开）
ACCEPTED/IN_PROGRESS → ACCEPTED （转派）
任意已接单 → CANCELLED   （管理员撤销）
```
**文件**：`src/main/java/com/mop/ticket/domain/TicketStateMachine.java`
```java
@Component
public class TicketStateMachine {

    private final SlaRepository slaRepo;

    /** 运维员接单 */
    public void accept(Ticket t, UUID actorId) {
        require(t, OPEN);
        t.setStatus(ACCEPTED);
        t.setAssigneeId(actorId);
        t.setAcceptedAt(Instant.now());
        t.setSlaDeadline(calcDeadline(t));
    }

    /** 转派给其他运维员 */
    public void reassign(Ticket t, UUID newAssignee, UUID actorId) {
        require(t, ACCEPTED, IN_PROGRESS);
        t.setAssigneeId(newAssignee);
    }

    /** 开始处理 */
    public void startProgress(Ticket t) {
        require(t, ACCEPTED);
        t.setStatus(IN_PROGRESS);
    }

    /** 标记已解决，待客户确认 */
    public void resolve(Ticket t, String note, UUID actorId) {
        require(t, IN_PROGRESS);
        t.setStatus(RESOLVED);
        t.setResolvedAt(Instant.now());
        t.setResolutionNote(note);
    }

    /** 客户确认关闭 */
    public void close(Ticket t, String customerNote, UUID actorId) {
        require(t, RESOLVED);
        t.setStatus(CLOSED);
        t.setClosedAt(Instant.now());
        t.setCustomerNote(customerNote);
    }

    /** 客户拒绝，重开处理 */
    public void reopen(Ticket t, String customerNote, UUID actorId) {
        require(t, RESOLVED);
        t.setStatus(IN_PROGRESS);
        t.setCustomerNote(customerNote);
    }

    private void require(Ticket t, TicketStatus... allowed) {
        for (TicketStatus s : allowed) if (t.getStatus() == s) return;
        throw new IllegalStateTransitionException(t.getStatus(), List.of(allowed));
    }

    private Instant calcDeadline(Ticket t) {
        SlaPolicy policy = slaRepo
            .findByTenantIdAndPriority(t.getTenantId(), t.getPriority())
            .orElseThrow();
        return Instant.now().plus(Duration.ofHours(policy.getResolveHours()));
    }
}
```

### 3.3 Service 实现（含并发锁）

> **并发问题**：两名运维员同时接同一张工单，必须用 `SELECT FOR UPDATE` 防止双重接单。
**文件**：`src/main/java/com/mop/ticket/repository/TicketRepository.java`
```java
public interface TicketRepository extends JpaRepository<Ticket, UUID> {

    /** 带悲观锁查询（防止并发接单/状态竞争） */
    @Lock(LockModeType.PESSIMISTIC_WRITE)
    @Query("SELECT t FROM Ticket t WHERE t.id = :id AND t.tenantId = :tenantId")
    Optional<Ticket> findByIdAndTenantIdForUpdate(
        @Param("id") UUID id,
        @Param("tenantId") UUID tenantId
    );

    /** 普通读（列表/详情） */
    Optional<Ticket> findByIdAndTenantId(UUID id, UUID tenantId);

    /** SLA Watchdog 用：已到期且未标记的工单 */
    @Query("""
        SELECT t FROM Ticket t
        WHERE t.status NOT IN ('CLOSED','CANCELLED')
          AND t.slaDeadline < :now
          AND t.slaBreached = false
        """)
    List<Ticket> findBreached(@Param("now") Instant now);

    /** 列表+多条件筛选（支持 null 参数即忽略该条件） */
    @Query("""
        SELECT t FROM Ticket t
        WHERE t.tenantId = :tenantId
          AND (:status   IS NULL OR t.status   = :status)
          AND (:priority IS NULL OR t.priority = :priority)
          AND (:assignee IS NULL OR t.assigneeId = :assignee)
        ORDER BY t.createdAt DESC
        """)
    Page<Ticket> findFiltered(
        @Param("tenantId") UUID tenantId,
        @Param("status")   String status,
        @Param("priority") String priority,
        @Param("assignee") UUID assignee,
        Pageable pageable
    );
}
```
**文件**：`src/main/java/com/mop/ticket/service/TicketService.java`
```java
@Service @Slf4j @RequiredArgsConstructor
public class TicketService {

    private final TicketRepository      ticketRepo;
    private final TicketEventRepository eventRepo;
    private final TicketStateMachine    stateMachine;
    private final OutboxService         outboxService;

    /**
     * 接单 — 使用悲观锁防止并发双重接单。
     * 如果同一工单已被其他人接走，SELECT FOR UPDATE
     * 会等待上一个事务提交后再读，此时 status!=OPEN，
     * stateMachine.accept() 抛出 IllegalStateTransitionException → 422。
     */
    @Transactional
    public void accept(UUID ticketId, UUID actorId, UUID tenantId) {
        Ticket ticket = ticketRepo
            .findByIdAndTenantIdForUpdate(ticketId, tenantId)   // FOR UPDATE
            .orElseThrow(TicketNotFoundException::new);
        stateMachine.accept(ticket, actorId);
        ticketRepo.save(ticket);
        eventRepo.save(TicketEvent.of(ticket, actorId, ACCEPTED, Map.of()));
        outboxService.publish("ticket.accepted", ticket.getId(), tenantId);
        log.info("Ticket accepted id={} by actor={}", ticketId, actorId);
    }

    @Transactional
    public void reassign(UUID ticketId, UUID newAssignee, UUID actorId, UUID tenantId) {
        Ticket ticket = ticketRepo
            .findByIdAndTenantIdForUpdate(ticketId, tenantId)
            .orElseThrow(TicketNotFoundException::new);
        stateMachine.reassign(ticket, newAssignee, actorId);
        ticketRepo.save(ticket);
        eventRepo.save(TicketEvent.of(ticket, actorId, REASSIGNED,
            Map.of("newAssignee", newAssignee)));
        outboxService.publish("ticket.reassigned", ticket.getId(), tenantId);
    }

    @Transactional
    public void resolve(UUID ticketId, String note, UUID actorId, UUID tenantId) {
        Ticket ticket = ticketRepo
            .findByIdAndTenantIdForUpdate(ticketId, tenantId)
            .orElseThrow(TicketNotFoundException::new);
        stateMachine.resolve(ticket, note, actorId);
        ticketRepo.save(ticket);
        eventRepo.save(TicketEvent.of(ticket, actorId, RESOLVED, Map.of("note", note)));
        outboxService.publish("ticket.resolved", ticket.getId(), tenantId);
    }

    @Transactional
    public void close(UUID ticketId, String note, UUID actorId, UUID tenantId) {
        Ticket ticket = ticketRepo
            .findByIdAndTenantIdForUpdate(ticketId, tenantId)
            .orElseThrow(TicketNotFoundException::new);
        stateMachine.close(ticket, note, actorId);
        ticketRepo.save(ticket);
        eventRepo.save(TicketEvent.of(ticket, actorId, CLOSED, Map.of()));
        outboxService.publish("ticket.closed", ticket.getId(), tenantId);
    }

    @Transactional
    public void reopen(UUID ticketId, String note, UUID actorId, UUID tenantId) {
        Ticket ticket = ticketRepo
            .findByIdAndTenantIdForUpdate(ticketId, tenantId)
            .orElseThrow(TicketNotFoundException::new);
        stateMachine.reopen(ticket, note, actorId);
        ticketRepo.save(ticket);
        eventRepo.save(TicketEvent.of(ticket, actorId, IN_PROGRESS,
            Map.of("customerNote", note == null ? "" : note)));
        outboxService.publish("ticket.reopened", ticket.getId(), tenantId);
    }

    /** 列表查询，支持分页和多字段筛选 */
    @Transactional(readOnly = true)
    public Page<TicketSummary> list(UUID tenantId, String status, String priority,
                                    UUID assignee, Pageable pageable) {
        return ticketRepo
            .findFiltered(tenantId, status, priority, assignee, pageable)
            .map(TicketMapper::toSummary);
    }
}
```

## 四、SLA Watchdog Worker

**文件**：`src/main/java/com/mop/ticket/worker/SlaWatchdogWorker.java`
```java
@Component
@Slf4j
public class SlaWatchdogWorker {

    @Scheduled(fixedRate = 60_000)  // 每分钟扫描
    @Transactional
    public void checkBreaches() {
        // 查找所有未关闭且 SLA 已过期的工单
        List<Ticket> overdue = ticketRepo.findBreached(Instant.now());
        for (Ticket t : overdue) {
            if (t.isSlaBreached()) continue; // 避免重复标记
            t.setSlaBreached(true);
            ticketRepo.save(t);
            eventRepo.save(TicketEvent.of(t, SYSTEM_ACTOR_ID, SLA_BREACHED, Map.of()));
            outboxService.publish("ticket.sla_breached", t.getId(), t.getTenantId());
            log.warn("SLA breached: ticket={} tenant={}", t.getId(), t.getTenantId());
        }
    }
}
```

```javascript
  ([
    { label: '接单',   key: 'accept',   show: props.ticket.status === 'OPEN' },

    { label: '拒绝重开', key: 'reopen',  show: props.ticket.status === 'RESOLVED' },

async function execute(key: string) {
  if (key === 'reassign') { showReassignDialog.value = true; return }
  if (['resolve','close','reopen'].includes(key)) {
    currentAction.value = key; showNoteDialog.value = true; return
  }
  await ticketApi[key](props.ticket.id)
  emit('refresh')
}

    <el-button
      v-for="a in actions" :key="a.key"
      size="small" @click="execute(a.key)">
      {{ a.label }}
    </el-button>
  </el-space>

  <!-- 转派对话框 -->
  <ReassignDialog
    v-model="showReassignDialog"
    :ticket-id="ticket.id"
    @done="emit('refresh')" />
```

```javascript
<script setup lang="ts">
const props = defineProps<{ deadline: string | null; breached: boolean }>()
const label = ref('')
let timer: ReturnType<typeof setInterval>

function update() {
  if (!props.deadline) { label.value = '-'; return }
  const diff = new Date(props.deadline).getTime() - Date.now()
  if (diff <= 0) { label.value = '已超期'; return }
  const h = Math.floor(diff / 3_600_000)
  const m = Math.floor((diff % 3_600_000) / 60_000)
  label.value = `${h}h ${m}m`
}

onMounted(() => { update(); timer = setInterval(update, 60_000) })
onUnmounted(() => clearInterval(timer))
</script>

<template>
  <span
    :class="[
      props.breached ? 'text-red-600 font-semibold' : '',
      !props.breached && label.startsWith('0h') ? 'text-yellow-500' : ''
    ]">
    {{ label }}
  </span>
</template>
```

```typescript
import { request } from '@/utils/request'

export interface TicketSummary {
  id:          string
  title:       string
  status:      'OPEN'|'ACCEPTED'|'IN_PROGRESS'|'RESOLVED'|'CLOSED'|'CANCELLED'

  assigneeName: string | null
  slaDeadline: string | null   // ISO-8601
  slaBreached: boolean
  createdAt:   string
}

export interface PageResult<T> {
  content:       T[]
  totalElements: number
  totalPages:    number
  number:        number   // 当前页码（从 0 开始）
}

export interface TicketListParams {
  status?:   string
  priority?: string
  assignee?: string
  page?:     number
  size?:     number
}

const BASE = '/api/v1/tickets'

export const ticketApi = {

  /** 分页列表 */
  list(params: TicketListParams) {
    return request.get<PageResult<TicketSummary>>(BASE, { params })
  },

  /** 接单 */
  accept(id: string) {
    return request.post<void>(`${BASE}/${id}/accept`)
  },

  /** 转派 */
  reassign(id: string, assigneeId: string, reason?: string) {
    return request.post<void>(`${BASE}/${id}/reassign`, { assigneeId, reason })
  },

  /** 开始处理 */
  start(id: string) {
    return request.post<void>(`${BASE}/${id}/start`)
  },

  /** 标记已解决 */
  resolve(id: string, note: string) {
    return request.post<void>(`${BASE}/${id}/resolve`, { note })
  },

  /** 客户确认关闭 */
  close(id: string, note?: string) {
    return request.post<void>(`${BASE}/${id}/close`, { note })
  },

  /** 客户拒绝重开 */
  reopen(id: string, note?: string) {
    return request.post<void>(`${BASE}/${id}/reopen`, { note })
  },

  /** 操作日志 */
  events(id: string) {
    return request.get<TicketEvent[]>(`${BASE}/${id}/events`)
  },

  /** 读取 SLA 规则 */
  getSlaPolicy() {
    return request.get<SlaPolicy[]>('/api/v1/settings/sla')
  },

  /** 更新 SLA 规则 */
  updateSlaPolicy(policies: SlaPolicy[]) {
    return request.put<void>('/api/v1/settings/sla', policies)
  },
}

export interface SlaPolicy {
  priority:           'P1'|'P2'|'P3'
  firstResponseHours: number
  resolveHours:       number
  escalationHours?:   number
}

export interface TicketEvent {
  id:        string
  actorName: string
  eventType: string
  payload:   Record<string, unknown>
  createdAt: string
}
```

## 六再补、SLA 计算边界说明

> [!WARNING]
> 当前 `calcDeadline` 使用公历时铟，即 P2 = 现在 + 24h。如果客户宣称仅工作日内计算 SLA，需要在 V1.1 升级时手动抗议追加工作日日历计算逻辑。当前不先实现，需客户确认。

| 场景 | 处理方式 |
|---|---|
| 连续公历日计算 | 当前实现，直接加小时 |
| 仅工作时间（周一至周五 9-18） | 需升级，将 `calcDeadline` 替换为工作日日历生成器 |
| P1（紧急） | 建议不屏蔽周末，直接加 4h |
| 内部系统下线暂停计时 | 暂不实现，需手动调整 |

### 8.4 修订后的迁移方案（V33 起，按合入顺序分配）

两种做法二选一，推荐 ①：
1. **扩展表（推荐）**：保留 V4 报障登记为不可变事实，新增
	- `mop_ticket_lifecycle`：ticket_id（一对一）、tenant_id、state、priority、assignee_id、collaborator_ids、close_mode、reopen_count、resolved_at、closed_at、resolution_snapshot_sha256、version

	- `mop_ticket_assignment`：from、to、reason、keep_as_collaborator、batch_id
	- `mop_ticket_confirmation`：CONFIRM / NOT_RESOLVED / TIMEOUT_AUTO、说明、快照 hash、actor
