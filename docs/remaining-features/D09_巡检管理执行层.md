## 二、巡检模板发布 API

**接口**：`POST /api/v1/inspection-templates/{id}/publish`
```java
@PostMapping("/inspection-templates/{id}/publish")
@PreAuthorize("hasAnyRole('MSP','PADMIN')")
public ResponseEntity<Void> publish(
        @PathVariable UUID id,
        @AuthenticationPrincipal MopUser actor) {

    inspectionService.publishTemplate(id, actor.getId(), actor.getTenantId());
    return ResponseEntity.ok().build();
}

// InspectionService.java
@Transactional
public void publishTemplate(UUID templateId, UUID actorId, UUID tenantId) {
    InspectionTemplateRevision rev = templateRepo
        .findLatestByTemplateIdAndTenantId(templateId, tenantId)
        .orElseThrow();

    if (rev.getStatus() != TemplateStatus.DRAFT)
        throw new IllegalStateException("只有草稿状态的模板可发布");

    rev.setStatus(TemplateStatus.PUBLISHED);
    rev.setPublishedAt(Instant.now());
    rev.setPublishedBy(actorId);
    templateRepo.save(rev);
}
```

```java
// 实现
@Transactional
public void submitItemResult(UUID worksheetId, int seq, ItemResultRequest req, UUID tenantId) {
    InspectionWorksheet ws = worksheetRepo
        .findByIdAndTenantId(worksheetId, tenantId)
        .orElseThrow();
    if (ws.getStatus() != WorksheetStatus.IN_PROGRESS)
        throw new IllegalStateException("工单未开始，无法提交结果");

    InspectionItemResult result = InspectionItemResult.builder()
        .tenantId(tenantId)
        .worksheetId(worksheetId)
        .itemSeq(seq)
        .itemName(req.getItemName())
        .result(req.getResult())
        .actualValue(req.getActualValue())
        .remark(req.getRemark())
        .build();
    itemResultRepo.save(result);
}
```

### 3.3 证据图片上传

```java
@PostMapping("/inspection-worksheets/{id}/items/{seq}/evidence")
@PreAuthorize("hasRole('MSP')")
public ResponseEntity<Map<String, String>> uploadEvidence(
        @PathVariable UUID id,
        @PathVariable int seq,
        @RequestParam MultipartFile file,
        @AuthenticationPrincipal MopUser actor) {

    // 限制：单张 ≤10MB，格式 JPEG/PNG/PDF
    validateFile(file);
    String url = storageService.upload(
        "mop-inspection-evidence",
        buildKey(id, seq, file.getOriginalFilename()),
        file
    );
    // 将 URL 追加到对应 item_result 的 evidence_urls 数组
    itemResultRepo.appendEvidence(id, seq, url);
    return ResponseEntity.ok(Map.of("url", url));
}
```
**文件校验实现**：
```java
private void validateFile(MultipartFile file) {
    if (file.getSize() > 10 * 1024 * 1024)
        throw new ResponseStatusException(HttpStatus.PAYLOAD_TOO_LARGE,
            "单张文件不得超过 10MB");

    String ct = file.getContentType();
    if (ct == null || !(ct.startsWith("image/") || ct.equals("application/pdf")))
        throw new ResponseStatusException(HttpStatus.UNSUPPORTED_MEDIA_TYPE,
            "仅支持 JPEG/PNG/PDF 格式");
}

private String buildKey(UUID worksheetId, int seq, String filename) {
    String ext = filename != null && filename.contains(".")
        ? filename.substring(filename.lastIndexOf('.'))
        : "";
    return String.format("evidence/%s/%d/%s%s",
        worksheetId, seq, UUID.randomUUID(), ext);
}
```

### 3.4 完成工单（未提交项自动 SKIP）

```java
@PostMapping("/inspection-worksheets/{id}/complete")
@PreAuthorize("hasRole('MSP')")
public ResponseEntity<Void> complete(
        @PathVariable UUID id,
        @RequestBody @Valid CompleteWorksheetRequest req,
        @AuthenticationPrincipal MopUser actor) {
    inspectionService.completeWorksheet(id, req, actor.getTenantId());
    return ResponseEntity.ok().build();
}

// InspectionService.java
@Transactional
public void completeWorksheet(UUID worksheetId, CompleteWorksheetRequest req, UUID tenantId) {
    InspectionWorksheet ws = worksheetRepo
        .findByIdAndTenantId(worksheetId, tenantId)
        .orElseThrow();
    if (ws.getStatus() != WorksheetStatus.IN_PROGRESS)
        throw new IllegalStateException("只有进行中的工单可标记完成");

    // 自动把所有未提交项补充为 SKIP
    List<InspectionItem> allItems = templateItemRepo
        .findAllByRevisionId(ws.getRevisionId());
    Set<Integer> submitted = itemResultRepo
        .findSeqsByWorksheetId(worksheetId);
    for (InspectionItem item : allItems) {
        if (!submitted.contains(item.getSeq())) {
            itemResultRepo.save(InspectionItemResult.builder()
                .tenantId(tenantId)
                .worksheetId(worksheetId)
                .itemSeq(item.getSeq())
                .itemName(item.getName())  // 快照
                .result(InspectionResult.SKIP)
                .remark("未提交，自动标记 SKIP")
                .build());
        }
    }

    ws.setStatus(WorksheetStatus.COMPLETED);
    ws.setCompletedAt(Instant.now());
    ws.setSummaryNote(req.getSummaryNote());
    worksheetRepo.save(ws);
    outboxService.publish("inspection.completed", worksheetId, tenantId);
}

public record CompleteWorksheetRequest(
    @Size(max = 2000) String summaryNote
) {}
```

## 四、季度报告生成

**文件**：`src/main/java/com/mop/inspection/report/QuarterlyReportWorker.java`
```java
@Component
public class QuarterlyReportWorker {

    // 每季度最后一天运行
    @Scheduled(cron = "0 0 8 L 3,6,9,12 ?")
    public void generate() {
        List<UUID> tenants = tenantRepo.findAll();
        for (UUID tid : tenants) {
            try {
                QuarterlyReport report = reportBuilder.build(tid, lastQuarter());
                byte[] xlsx = excelExporter.export(report);
                String url  = storageService.upload(
                    "mop-reports", reportKey(tid), xlsx);
                // 发送下载通知
                outboxService.publish("report.quarterly_ready",
                    UUID.randomUUID(), tid);
            } catch (Exception e) {
                log.error("季度报告生成失败 tenant={}", tid, e);
            }
        }
    }
}
```
