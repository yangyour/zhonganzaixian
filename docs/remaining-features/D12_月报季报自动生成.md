## 一补、ReportData 数据收集器

**文件**：`src/main/java/com/mop/report/ReportDataCollector.java`
```java
@Service
public class ReportDataCollector {

    public ReportData collect(UUID tenantId, LocalDate start, LocalDate end) {
        Instant from = start.atStartOfDay(ZoneId.of("Asia/Shanghai")).toInstant();
        Instant to   = end.atTime(23, 59, 59).atZone(ZoneId.of("Asia/Shanghai")).toInstant();

        // 1. 工单数据
        TicketStats tickets = ticketRepo.statsByPeriod(tenantId, from, to);

        // 2. 巡检数据
        InspectionStats inspections = inspectionRepo.statsByPeriod(tenantId, from, to);

        // 3. 设备健康指标平均值（前 10 设备）
        List<DeviceHealthSummary> metrics = metricRepo
            .summarizeByPeriod(tenantId, from, to);

        // 4. 容量告警统计
        int alertCount = alertRepo.countByPeriod(tenantId, from, to);

        return ReportData.builder()
            .tenantId(tenantId)
            .periodStart(start).periodEnd(end)
            .periodLabel(start + " ~ " + end)
            .totalTickets(tickets.total())
            .closedTickets(tickets.closed())
            .slaComplianceRate(tickets.slaRate())
            .inspectionCount(inspections.total())
            .abnormalItems(inspections.failCount())
            .metrics(metrics)
            .alertCount(alertCount)
            .build();
    }
}

/** 工单统计快照 */
public record TicketStats(int total, int closed, double slaRate) {}

/** 巡检统计快照 */
public record InspectionStats(int total, int failCount) {}
```

## 二、月报/季报定时任务

**文件**：`src/main/java/com/mop/report/ReportScheduler.java`
```java
@Component @Slf4j
public class ReportScheduler {

    // 每月 1 日早上 8 点生成月报
    @Scheduled(cron = "0 0 8 1 * ?")
    public void generateMonthly() {
        YearMonth lastMonth = YearMonth.now().minusMonths(1);
        generateForAll(ReportType.MONTHLY, lastMonth.atDay(1),
            lastMonth.atEndOfMonth());
    }

    // 每季度第一天生成季报
    @Scheduled(cron = "0 0 8 1 1,4,7,10 ?")
    public void generateQuarterly() {
        LocalDate today = LocalDate.now();
        LocalDate qStart = today.minusMonths(3).withDayOfMonth(1);
        LocalDate qEnd   = today.minusDays(1);
        generateForAll(ReportType.QUARTERLY, qStart, qEnd);
    }

    private void generateForAll(ReportType type, LocalDate start, LocalDate end) {
        tenantRepo.findAll().forEach(tenantId -> {
            try {
                generateReport(tenantId, type, start, end);
            } catch (Exception e) {
                log.error("报告生成失败 tenant={} type={}", tenantId, type, e);
            }
        });
    }

    @Transactional
    public void generateReport(UUID tenantId, ReportType type,
                               LocalDate start, LocalDate end) {
        // 1. 收集报告数据
        ReportData data = dataCollector.collect(tenantId, start, end);

        // 2. 生成 XLSX
        byte[] xlsx = excelBuilder.build(type, data);

        // 3. 上传到 MinIO
        String key = String.format("%s/%s/%s_%s.xlsx",
            tenantId, type.name().toLowerCase(),
            start.toString(), end.toString());
        storageService.upload("mop-reports", key, xlsx);

        // 4. 生成预签名下载 URL（7天有效）
        String downloadUrl = storageService.presignedUrl(
            "mop-reports", key, Duration.ofDays(7));

        // 5. 将报告元数据存入数据库
        reportRepo.save(GeneratedReport.builder()
            .tenantId(tenantId)
            .reportType(type)
            .periodStart(start)
            .periodEnd(end)
            .fileUrl("mop-reports/" + key)
            .downloadUrl(downloadUrl)
            .expiresAt(Instant.now().plus(7, ChronoUnit.DAYS))
            .build());

        // 6. 发送 outbox 通知
        outboxService.publish("report.ready", UUID.randomUUID(), tenantId);

        log.info("报告生成完成 tenant={} type={} period={}/{}",
            tenantId, type, start, end);
    }
}
```

## 三、Excel 报告构建器

**文件**：`src/main/java/com/mop/report/ExcelReportBuilder.java`
```java
@Component
public class ExcelReportBuilder {

    public byte[] build(ReportType type, ReportData data) throws IOException {
        try (Workbook wb = new XSSFWorkbook();
             ByteArrayOutputStream out = new ByteArrayOutputStream()) {

            // Sheet 1：概要
            buildSummarySheet(wb, data);
            // Sheet 2：工单统计
            buildTicketSheet(wb, data.getTickets());
            // Sheet 3：巡检结果
            buildInspectionSheet(wb, data.getInspections());
            // Sheet 4：设备健康趋势
            buildDeviceHealthSheet(wb, data.getMetrics());

            wb.write(out);
            return out.toByteArray();
        }
    }

    private void buildSummarySheet(Workbook wb, ReportData data) {
        Sheet sheet = wb.createSheet("报告概要");
        CellStyle headerStyle = createHeaderStyle(wb);

        // 标题行
        Row titleRow = sheet.createRow(0);
        Cell titleCell = titleRow.createCell(0);
        titleCell.setCellValue("运维服务报告 " + data.getPeriodLabel());
        titleCell.setCellStyle(headerStyle);

        // 数据行
        String[][] summary = {
            {"报告周期", data.getPeriodLabel()},
            {"工单总数", String.valueOf(data.getTotalTickets())},
            {"已关闭工单", String.valueOf(data.getClosedTickets())},
            {"SLA 达标率", data.getSlaComplianceRate() + "%"},
            {"巡检执行次数", String.valueOf(data.getInspectionCount())},
            {"异常项数", String.valueOf(data.getAbnormalItems())},
        };
        for (int i = 0; i < summary.length; i++) {
            Row row = sheet.createRow(i + 2);
            row.createCell(0).setCellValue(summary[i][0]);
            row.createCell(1).setCellValue(summary[i][1]);
        }
        sheet.autoSizeColumn(0);
        sheet.autoSizeColumn(1);
    }
}
```

### 合同要求但前文未覆盖

- **M9-1 统一口径**：所有报告共用一个数据源与口径版本；未知区间按 Q05 处理。
- **M9-2 快照冻结**：月报快照合同期内永久保留（`report.contract_retention`，Q10）；M5-10 快照命名如 `sla-2026-09-draft`，与 SLA 对账同源。
- **M9-3 老板版 1 页**：可用率 + 环比 + 30 天热力条；工单总数 / P1 次数 / MTTR 中位数 / SLA 达成率；隐患处置数 + 典型案例；服务费 vs 参照值；下月建议 ≤ 3 条（`report.advice_max_count=3`）；页脚口径版本号。生成 ≤ 10 秒，PDF 与 H5 逐字一致，任意数字可下钻。
- **M9-4 完整版 6 章**：服务总览、事件明细、告警统计（Top10）、容量趋势（70% 预警线）、隐患清单、关单质量。
- **M9-5 推送与阅读**：企微推送决策人与报障人，推送记录区分受理 / 送达；记录 `read_at_first`；未读 \> 7 天（`report.unread_remind_days=7`）提示服务经理电话跟进。
- **M9-6 健康体检报告**：五维加权评分（权重 Q23）、风险清单、断网代价（标注「客户口径」）、套餐建议；同一清单两次生成结果一致。
- **M9-7 季度巡检报告**：见 D09。**M9-8 年度复盘**：可二期（Q11），数据复用月报 payload。
- **M9-9 通用硬约束**：全系统无报表手工填数入口；修改口径后历史报表保持原值。

### 修订后的实施步骤

1. 先完成 M9-1 统一口径服务（依赖 D15 事件、D16 SLA、D07 工单），再做报告。
2. V33+ 报告快照与版本表；生成 Worker 按期次幂等生成 draft 快照。
3. 渲染：一套 Vue / HTML 模板，服务端无头浏览器（仓库根 `package.json` 已有 Playwright 1.62.1，但仅用于验证脚本；作为生产渲染组件需 Q03 评审）输出 PDF，H5 读同一快照。
4. 审核流：服务经理发布 / 退回重生成（新版本号）；发布后经 D11 推送，记录送达与 `read_at_first`。
5. 未读提醒 Worker：发布后 7 天无 `read_at_first` → 站内提示服务经理。
6. 体检报告与年度报告在月报管线稳定后接入。
