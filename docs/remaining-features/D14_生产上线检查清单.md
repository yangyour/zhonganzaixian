## 一、TLS 安全检查

- [ ] **所有 HTTP 接口已禁用**，所有流量必须经过 HTTPS/TLS 1.2+
- [ ] **证书有效**：`ssl_expiry_days > 30`
	```bash
echo | openssl s_client -connect mop.yourdomain.com:443 2>/dev/null \
  | openssl x509 -noout -dates
	```
- [ ] **HSTS 头已配置**：`Strict-Transport-Security: max-age=31536000`
- [ ] **Cookie 安全属性**：`Secure; HttpOnly; SameSite=Strict`
- [ ] **单向证书配置**： Nginx/Gateway 不得配置 `ssl_verify_client off`，后端必须验证客户端证书
- [ ] **内网 MinIO 连接**：使用 TLS，`MINIO_SECURE=true`
- [ ] **数据库连接**：`spring.datasource.url` 包含 `ssl=true&sslmode=require`
---

## 二、行级安全策略 (RLS) 检查

- [ ] **全部特权升级已删除**：所有表必须有 RLS 策略或 `SET SESSION` 租户隔离
	```sql
-- 检查是否有表缺少 RLS
SELECT tablename
FROM pg_tables
WHERE schemaname = 'public'
  AND tablename NOT IN (
    SELECT DISTINCT tablename FROM pg_policies
  );
-- 结果应为空，否则需为这些表添加策略
	```
- [ ] **租户 ID 过滤验证**：每个 API 层过滤条件必须包含 `tenant_id = :currentTenant`
- [ ] **跨租户隔离测试**：用租户 A 的 token 访问租户 B 的数据必须返回 403/404
- [ ] **管理员账号隔离**：`super_admin` 角色能读全局，但必须包含审计日志
---

## 三、OSS/MinIO 备份检查

- [ ] **MinIO 备份策略已开启**
	```bash
# 检查 bucket replication 状态
mc admin replicate info myminio mop-reports
# 或检查备份战略
mc ilm ls myminio/mop-reports
	```
- [ ] **文件加密存储**： MinIO `KMS` 已配置，上传对象自动加密
- [ ] **预签名 URL 有效期 ≤90 天**：`application.yml` 中 `mop.storage.presigned-ttl-days: 7`
- [ ] **数据库定期备份**： PG `pg_dump` cron 已配置并备份到独立存储
	```bash
# 验证最新一次备份
mc ls myminio/mop-pg-backup/ --recursive | tail -5
	```
- [ ] **备份恢复演练**：在测试环境验证备份可恢复

## 四、租户初始化检查

- [ ] **内置角色已预设**：每个新租户自动创建 `MSP`、`PADMIN`、`CUST` 三个角色
	```sql
SELECT DISTINCT role_name FROM tenant_roles WHERE tenant_id = :tid
-- 应返回: MSP, PADMIN, CUST
	```
- [ ] **默认管理员账号已禁用**：租户初始化后必须立即修改默认密码
- [ ] **工单编号序列已预置**：每租户有独立的 ticket 序列
	```sql
SELECT last_value FROM ticket_seq_<tenant_id>;
	```
- [ ] **SLA 默认配置已导入**： P1=4h, P2=8h, P3=24h, P4=72h
- [ ] **通知渠道已默认开启**：新租户自动开启站内推送
