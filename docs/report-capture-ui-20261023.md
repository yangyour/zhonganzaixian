# R01：季度原子捕获页面与恢复

本增量把已有 `POST /api/v1/inspection-quarterly-reports/capture` 接入实际季度报告页。它只核销 R01 的原子捕获调用方与恢复子项，不代表跨业务统一快照或正式报告交付完成。

## 用户流程

新建季度草稿可选择“使用已保存来源集合”或“选择执行单修订并原子捕获”。原入口保持兼容；后者复用执行单候选分页、明确历史修订、完整来源摘要核对及读取取消/重试。只有已核对的修订进入提交列表，可移除、拒绝重复，最多1000项；空选择必须另行勾选，不能将没有候选误当零资产。

标签、期次与六项配置仍由用户明确填写，未决值为 null。一次提交同时保存来源集合与 DRAFT，前端不会另发来源集合创建请求。回执绑定当前租户/创建者、明确来源清单摘要、期次及配置指纹；capture 标识验证后转换成既有严格元数据，继续复用列表/正文比较及完整冻结正文校验。

结果未知时固定原路径、原输入与原幂等键。列表/详情读取不能消除未知状态，重试403/409也不能证明此前未写入。首次明确拒绝才允许保留输入并解锁。已接受回执与正文核验分开；HTML/PDF 仍明确为 DRAFT，前者新读取并核对冻结摘要，后者仍携带 If-Match 并由服务端再次授权。

权限变化（包含同版本能力撤销）、租户/账号切换及迟到响应沿用现有清理机制。离开确认绑定原始输入及来源选择器暂存输入。补充独立展开状态，避免移除最后一个来源时编辑区意外折叠。来源ID、版本与摘要分行显示，样式只限本页。
