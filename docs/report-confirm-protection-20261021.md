# 来源集合与季度报告草稿的确认快照保护

## 输入保护

- 来源集合的新建清空与离开确认固定标签、有序来源ID/版本/摘要、明确空选择意向以及候选选择子组件的原始输入。
- 子组件暴露只读输入快照。父页面不再只看dirty布尔值：同样“已有未保存输入”期间再次编辑执行单ID或版本文本，旧确认会失效；规范化后仍相同的版本文字也保留原文。
- 来源正在核对加入时不能用旧清空确认丢弃进行中的选择；增删来源或修改空选择意向之后必须重新明确确认。
- 季度报告固定标签、年/季度原文、配置值、来源集合ID及已读取来源文档/清单摘要。确认期间改期次或配置、重新读取来源，都不会被旧清空确认覆盖。
- 所有确认检查卸载、当前范围与未知写入状态；保持原输入时仍可正常清空或离开，不自动保存，不替换原未知命令。

遵循[前端验收标准](frontend-acceptance-standard.md)。待确认配置继续保持null，不因界面保护补默认值；集合不是正式报告，季度草稿不是已发布/已送达结果。
