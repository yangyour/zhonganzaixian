# 季度报告 HTML 草稿预览

基于 main c25ee32；无后端、数据库迁移、生产配置或外部服务变更。

## 用户任务

季度草稿列表 → 读取冻结报告 → 下载 HTML 草稿预览。按钮触发新的受保护 GET，复用完整生产读取器核对租户、角色、权限上下文、来源与报告摘要及派生输出；失败不回退到缓存。下载只发起本地浏览器下载，不声称保存成功、正式发布、客户批准或交付。

文件包含所有资产输出、所有选定检查项（含未填写）、所有待解决事项、配置 null、候选修订与来源摘要。它不是完整冻结来源备份，不附源文件或证据，也不重算历史。正式 PDF、批准、发布、客户阅读记录仍未完成。

## 交互与安全门禁

- 重复点击不重复请求；可取消只读请求。原表单、未知写入身份不改变。
- 租户/用户/权限版本/角色/权限/记录选择变更及卸载都会中止下载，忽略迟到结果。
- 失败保持原详情并显示错误，用户可手动重试，不自动重试。
- 取消后焦点返回下载按钮；状态通知使用 status/alert；原生按钮沿用 44px 目标。
- 明示离线文件含租户数据且权限撤销不能收回副本。
- 所有动态文本 HTML 转义；无脚本、外链、图片、表单、附件链接或远程字体；CSP default-src none、base-uri none、form-action none。不能将 CSP 当作替代转义的保证。
- UTF-8 预览最大 8 MiB，超过拒绝而非截断。输入原有受保护报告读取上限仍有效。
- Blob URL 仅短时用于下载，元素立即移除，1秒后撤销 URL；不写 localStorage。
- 离线 HTML 使用语义标题/定义列表、中文语言声明、可回流文本、静态打印样式。打印/PDF输出未做真实浏览器验收。
