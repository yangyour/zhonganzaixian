## 脚本与证据边界

开发专用入口 qa/quarterly-pdf.fixture.html 使用真实季度报告页面、读取器和下载工具。身份为合成只读管理员，网络在 Playwright 中拦截为本轮真实回环 HTTP 捕获的合成 JSON/PDF，不启动生产登录、不授予真实权限、不执行 POST。入口含 DEV 保护，不加入正式应用入口。

7项脚本位于 apps/web/qa/browser/quarterly-pdf.pw.ts：

- 320、390、768、1440 px 四种宽度：键盘 Enter 下载、文件名和下载字节 SHA256、If-Match、单次 GET/零 POST、状态通知、页面不横向溢出、axe规则和整页截图。
- 字体未配置503：保留详情、展示可恢复错误、无下载/无自动重试；明确再次点击才重试。
- 取消恢复 PDF 按钮焦点、HTML/PDF共享忙状态、迟到响应不下载；撤权清除入口及迟到数据。
- 内容被篡改：摘要校验失败，不生成下载。

这些是可执行验收规格，不是执行结果。浏览器沙箱此前阻止本地 Chromium 启动，云浏览器无法访问执行器回环地址；本轮不绕过拒绝、不把脚本发现或类型检查算成浏览器通过。
