# 季度报告 PDF 草稿预览

基线 main：c6d052714af0cafa67712539e18774c352b6746b。以下为已实现并完成本地回归的切片，不是正式发布或合同验收。

## 功能与授权边界

- 增加受保护的 GET /inspection-quarterly-reports/{id}/preview.pdf。必须携带当前冻结文档 SHA256 的单一强 If-Match 值；没有、错误或已变化时拒绝。
- 渲染前和释放完整字节前分别复用原报告的授权与冻结内容完整性验证。没有新增报告、持久附件、批准、发布、阅读回执或外部发送。
- 渲染器只接收输出与配置投影，不接收完整 source_document。输出全部选定检查项、未填写项、来源/报告摘要及待解决事项；不导出附件、证据访问或完整来源原文。
- 报告明确 DRAFT、未批准、不可发布；完整性只指明确选定来源，租户资产总量仍未知，不能视为覆盖率。

## 可配置依赖与限制

示例 deploy/examples/report-pdf-preview.env.example 默认禁用。需要明确配置有权嵌入的独立 OTF/TTF 文件及其 SHA256，可再配置匹配摘要的回退字体；不扫描系统字体、不猜 TTC 子字体、不访问字体 URL、不持久化渲染文件。

本地验证从已安装的 Noto CJK 字体集合提取独立 SC OTF，另显式使用 DejaVu Sans 作回退。字体文件不随项目提交，不替生产选择品牌或许可。CFF 字体集合 TTC 的本地试验不兼容，未以跳过错误或系统替代字体掩盖。

技术上限：200,000 个 UTF-16 文字单元、200 页、PDF 8 MiB，单个字体32 MiB，单进程一次渲染，不排无限队列。超过上限、字符无法覆盖或出现字体/布局告警则拒绝，不返回截断或缺字文件；HTML 草稿仍是独立入口。

字体由摘要核验后在进程内使用，配置/字体变化需重启服务。输入经固定 SAX 元素作为文本输出，不解析客户 XML/HTML，不添加链接注释、脚本、表单、图片或嵌入附件。字体资源解析器和 FontManager 均显式限定内存字体 URI，并禁用磁盘字体缓存。

## 下载与恢复

浏览器请求同源 PDF，禁止重定向；核对报告/租户/原冻结摘要、DRAFT、长度、页数、MIME、文件名、完整文件 SHA256 和 PDF 首尾标记后才创建下载 Blob。30秒超时、取消、权限/账号版本/记录变化或卸载都不能发起迟到下载。失败不回退到缓存文件，不自动重复请求。

二进制 Accept 请求的失败仍由原异常处理器追加审计并明确返回 JSON，不能因内容协商丢失可恢复错误。下载仅表示浏览器已发起动作，不声称保存、批准或发布。离线副本含租户数据，后续撤权不能收回。

## 验证结果与保留的失败记录

- 已生成并查看中文、表情符号、缺省配置和选定检查项的实际 PDF 样例；已有结构标签不等于 PDF/UA 或屏幕阅读器验收。部分CJK兼容字符提取后需Unicode NFKC归一化，PDF不是原始字节备份。
- 首轮构建原可执行JAR未带入新增依赖，已重新生成可重复构建产物；后续使用 maven.jar.forceCreation 避免增量重打包保留旧依赖。离线 clean 插件未缓存的失败有记录，没有放宽TLS或checksum校验。
- 初版 Java 的复合 var 声明已改为显式类型。
- 两轮临时 PostgreSQL 的16项报告集成测试通过，但 HTTP 正向 PDF 下载返回503，未算通过。第二轮安全诊断为 glyphNotAvailable；实际内容的字符在两份字体覆盖并集中都存在。
- 问题涉及表情与中文标点相邻时的自动词级字体回退。改为按完整字素选择能覆盖该字素的显式字体，再合并连续字体段，保留未覆盖字素拒绝；已增加混排与组合字符回归；第三轮真实 HTTP 26 项检查及数据库16项集成测试通过。成功下载前后105张表的行指纹均未变化。

最终结果见 [结构化证据](evidence/report-pdf-preview-20261021.json)。真实浏览器/axe/PDF辅助技术、正式发布、客户交付及128项正式TC仍未执行。

## 实现参考

固定使用 Apache FOP 2.12。官方[版本说明](https://xmlgraphics.apache.org/fop/2.12/releaseNotes_2.12.html)、[字体机制](https://xmlgraphics.apache.org/fop/2.11/fonts.html)、[嵌入方式](https://xmlgraphics.apache.org/fop/2.11/embedding.html)用于核对Java兼容、字体和资源配置；不能代替本项目实际字体、权限和输出验收。

- 全量前端3173项/216文件、契约173项、Python120项通过。Java3897项中实际执行2884项、环境条件跳过1013项；新增20项PDF相关测试均执行，包括7项真实字体渲染。
- 第一次前端构建发现Response可空类型与参数化测试联合类型错误，修正为局部明确Response与显式测试参数类型；重跑类型检查、构建、静态发布和策略检查通过。未把仅Vitest通过当作构建通过。
- 对选定来源、缺省配置、长文本/恶意标记及真实HTTP共13页重新渲染逐页检查。页眉、页脚、换行和未填写提示可见；无裁切、叠字或替代方框。长样例为纯版面测试，不是业务快照有效性证据。逐页文本和结构检查拒绝脚本/表单/链接/附件。
- 真实浏览器交互、axe、PDF/UA及辅助技术均 NOT_RUN；44项已发现浏览器脚本仍非执行结果。本轮使用DOM/路由/实际HTTP捕获回放验证下载、取消、迟到响应和身份变化。
