## 本批实际范围

恢复 `ad7a2fc3ee0fa899b73fe03217049fc7264b29d6` 的领域草稿后，新增仓储、V53 候选、服务端同源渲染、API、报告中心页面和原请求恢复。首个真实来源适配器为已有季度巡检冻结文档；不是把全部 R01/R02/R03 宣布完成。月报老板版/完整版、体检、年度范围及重生成新修订后续继续接，不能因领域枚举存在而视为可用。

- 管理员从季度报告详情选择明确来源 ID 与文档 SHA256，服务端在当前授权事务中重验完整冻结输入/输出，再创建独立发布文档。没有接收客户端指标、PDF、HTML、收件人、审批配置或租户覆盖。
- 文档只保存原冻结输出和必要配置/来源指纹；页面和下载不包含完整来源正文或附件。保留来源的人工自述/未批准/未核验证据等待补全项，只核销本次实际接通的 PUBLICATION_PIPELINE_NOT_CONNECTED 项。
- 当前来源仍有未核验项时，领域逻辑和数据库均阻止 APPROVE。私有流程配置中的模板确认不等于来源核验，也不清除这些缺口。
- GENERATE 对应显式 RENDER 操作，生成状态和输出逐修订保存；审核、退回、发布是独立命令。发布同时记录交付意图，不调用通知供应商。重发复用已发布字节和摘要，不重算来源。
- 页面入口：首页紧凑“报告中心”链接、季度详情“进入报告发布流程”；沿用原导航上下文和样式，不新增大块占位。客户只见明确发布给本人的报告，管理权限由当前能力及明确审批名单共同约束。
- 当前已登录明确接收人通过 POST 登记首次阅读，再下载同一已保存文件；重复保持首次时间。记录的是明确阅读操作，不声称文件已读完、消息已送达或客户已验收。
- 原命令在发送前保存最小会话日志，绑定稳定账号/租户/权限范围，重新加载后不自动重发。未知回执保持原 body/key；对照状态、文档、版本增量及来源核验后才清除。主动跳转/上下文切换受未决命令门禁约束，强制撤权清空展示并忽略迟到响应。
- 下载要求 If-Match，读取后再次核验状态和当前成员；前端核对文件长度、租户/报告身份、阶段和 SHA256，下载前检查当前上下文。附件 no-store、sandbox CSP，无在线 HTML 执行或外部资源加载。

## 同源渲染，不假造 PDF

`MOP_PUBLICATION_XHTML_V1` 只渲染服务端冻结输出，全部文本转义，null 明确为未配置/未知，空集合不推断为正常。PDF 通过受限 XML 解析器读取这一份准确 XHTML，复用既有 Apache FOP 2.12 和受控字体加载器，不查询实时来源、不加载外部 URI。产物记录同一个 HTML SHA256、字体组合摘要、模板和渲染器版本。

没有字体配置、字形覆盖不足、页面/字节超限时保留实际 HTML，状态 FAILED，不能审核或发布，也不生成替代 PDF。技术限制为 8 MiB 产物、200 页和既有 200,000 字符预算。PDF/UA、真实浏览器、真实字体版式和客户模板尚未验收。

## 明确配置

配置由受控私有环境提供，未提交任何秘密或实际客户名单：

- `MOP_REPORT_PUBLICATION_TEMPLATE_VERSION`：仅实现值 MOP_PUBLICATION_XHTML_V1；缺失为 null，阻止生成，不猜测客户模板。
- `MOP_REPORT_PUBLICATION_POLICY_JSON`：按明确租户 UUID 分组的 Policy。字段为 reference、reviewers、publishers、customers、self_review_allowed、regeneration、annual_enabled、customer_template_confirmed、customer_confirmation_reference。缺值保持 null；客户确认 true 必须有证据引用。未知字段、重复键、无效人员或格式拒绝启动。
- 审批配置 reference 与完整配置摘要一起绑定，标签相同但内容变更也不能沿用旧批准。当前审批/发布者必须既有服务端管理能力又在对应明确名单中。
- 字体复用 `MOP_REPORT_PDF_PREVIEW_ENABLED`、`MOP_REPORT_PDF_FONT_PATH`、`MOP_REPORT_PDF_FONT_SHA256` 及可选匹配的 FALLBACK_FONT_PATH/SHA256；启用的是本地受限渲染，不代表生产启用或客户模板批准。
