# 季度报告按集合标签分页选择来源

## 交互路径

- 展开季度草稿编辑区后，显式读取来源集合候选；每页15条元数据，展示标签、ID、明确来源数及保存时间，不自动读全量或选择最新集合。
- 点击某行“读取此集合”后，按该ID读取完整来源。当前候选行全部元数据（除projection）须与正文一致，包括标签、来源数、记录身份、文档和清单摘要；正文还要通过既有严格完整性核验。不一致不能用于草稿。
- 原手动精确ID入口保留。列表读取和正文读取状态彼此独立，浏览/取消候选不清掉已核对来源或报告输入。
- 候选失败/取消可按原成对记录时间/ID游标重试；正文重试继续约束原候选，不放宽摘要或标签校验。取消后焦点进入明确状态说明。
- 旧页行事件、账号版本变化、未知写入或已锁定草稿不能重新选择来源。确认清空期间选择新来源，会使旧确认失效。
- 明确空集合显示独立警告，不推断零库存。六项待确认报告配置保持null，不补时区、选取规则或模板版本，不自动保存、发布或发送。

遵循[前端验收标准](frontend-acceptance-standard.md)：原生表格caption/列头、具名滚动区域、可见焦点、44px操作目标以及明确初始/加载/错误/空页状态。
