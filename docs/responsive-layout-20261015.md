本轮以已提交 `ec88c08` 为隔离基线，针对共用样式、布局断点、表格和弹窗。当前主工作区还有其他页面业务修改，本轮不覆盖或混入其未提交文件。复用指定LAN测试API，不使用业务fixture，不提交业务数据。

## 依据与通过标准

- [WCAG Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：普通内容在320 CSS px可重排；表格允许在自身区域横向滚动，不以隐藏正文掩盖溢出。
- [Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)：放大后的文字和操作仍可使用。视口仿真、CSS文字压力检查和原生浏览器缩放分别记录，不相互冒充。
- [Focus Not Obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)：固定导航、弹窗标题与底部操作不能完全遮挡当前操作。
- [Responsive web design basics](https://web.dev/articles/responsive-web-design-basics)：根据实际内容空间安排布局，覆盖断点两侧及中间宽度。

## 第一项：平板工作区、卡片对齐和手机操作栏

基线28页面×9尺寸共252组检查，结合截图发现：配置卡片继承140px最小宽度，在761px窗口、侧栏展开时撑出可用正文；资产卡片继承垂直居中，同一行上下沿相差约10px；320/390px创建按钮被挤成两行。初版量测使用innerWidth，未扣除滚动条占位，随后改用document.clientWidth并完整重跑；[baseline.json](evidence/responsive-layout-20261015/baseline.json)是修正后的正式基线。

已将1024px及以下的常驻侧栏切换为既有抽屉导航，保留所有权限入口；跨回1025px时关闭抽屉并聚焦可见的桌面菜单按钮。折叠偏好仍保留，返回桌面后恢复原宽度。未添加新导航或业务能力。

移除配置卡片不合适的最小宽度，资产统计卡改为同排拉伸对齐，中等宽度使用三列；480px以下的创建动作独占一行，导入/导出各占一格，按钮间距统一，不隐藏文字。修改现有样式规则，没有用全页overflow:hidden掩盖越界。

41项导航/守卫回归、类型/生产构建及产物门禁通过；6个高频页面×9尺寸共54组复验无页面横向溢出、操作越界、按钮文本裁切、工具栏重叠或卡片错位。1024/1025、760/761断点、抽屉回焦、桌面折叠及返回桌面偏好另经真实浏览器验证。页面脚本异常0、业务写入0。最后菜单跨断点处理仅重验相关交互，前述样式矩阵没有冒充再次全跑。
