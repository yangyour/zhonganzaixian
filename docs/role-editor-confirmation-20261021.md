# 角色编辑：完整输入确认与未知提交保护

基线 main aea1525d781921e9a2b58b9d7d0e9e3828b16225。依据[前端验收标准](frontend-acceptance-standard.md)修复既有角色编辑操作链，不实际变更任何真实成员权限。

## 输入与确认

- 角色编辑向共享身份编辑器提供完整输入快照，包括当前范围、打开状态、原角色与所有表单值。刷新、关闭、复制/新建和离开确认都复核原输入，而非只看dirty布尔值。
- 即使开始时没有未保存内容，await返回前出现新输入也不能被原刷新清除。确认弹窗期间按钮/字段锁定；事件处理器仍独立拒绝重复确认和提交。
- 复制/查看必须来自当前列表的原行对象；确认等待期间目标被替换或修改，不沿用旧批准。
- 角色未知提交不可通过放弃确认清除原key和载荷，需原请求恢复。强制会话失效仍按既有安全边界清理范围；浏览器离开提示不能保证用户关闭窗口后恢复内存。

## 导航与回读

共享编辑器在确认后为本次导航注册最后阶段检查，并在完成、失败、错误或卸载时撤销；后续路由守卫改动输入将使导航失败。上下文切换也在所有守卫完成后比较快照。销毁/清理使旧确认失效，旧finally不能解锁新确认。

原写入已接受但等待期间输入改变时，保留新输入和已接受回执，不立即触发会覆盖输入的回读，不声称“最新记录已回读”。已接受写入和回读失败继续分开显示。

完整角色快照及严格未知提交保护在本批为角色页启用；其他共享编辑器调用方尚未因此自动获得其各自完整表单快照，不能据此宣称所有账号/成员/通道表单的确认保护已完成。
