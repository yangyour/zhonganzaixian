# A03 当前配置角色矩阵打印与读取撤权保护

## 复用已有能力，不重复建设

已有项目本地/OIDC身份、可配置自定义角色、成员授权版本及静态四角色五维能力目录继续使用，参见 `project-identity-authorization.md`、`identity-capability-drift.md`、`identity-role-read-scope.md`、`capability-catalog.md`。原能力目录已经能打印代码声明，但不能代替当前租户自定义角色的实际保存配置。本批补后者，不把静态声明当有效对象授权。

## 实际功能

角色页增加“下载打印权限矩阵”，不改现有布局和导航。每次显式点击重新 GET `/identity/roles`，不导出编辑器尚未保存的输入。权限/账号/租户变化或正在进行身份写入时不下载；打印期间发生编辑或刷新也不交付旧意图结果。

输出为自包含、无脚本/外链/远程资源的 HTML 打印文件，按每组最多四个已保存角色展示合同五个维度，包含权限ID、角色名称/基础类别、启停状态、版本和更新时间。停用角色标为“停用（配置保留）”，不冒充正在授予权限。仅输出角色定义，不输出人员绑定、描述自由文本、密码或其他登录凭据。

校验复用已有能力目录的精确四角色/五维、交叉引用和 SHA256 算法。额外核对四个内置角色齐全、角色ID唯一、实际权限在对应基础类别的代码声明范围内。配置快照摘要绑定角色和完整能力目录，文件生成时间单独标为浏览器时钟，不冒充数据库取证时间。

仓储原列表最大201条作为截断哨兵；达到201条直接拒绝打印，不能把部分列表叫完整矩阵。当前完整导出技术边界为200个角色、4MiB文件，超限不给残缺文件。大规模角色分页/分卷仍须后续实现和验收。

客户及供应方签字、日期全部为空，始终标记“未经双方签字确认”。打印文件是配置核对材料，不生成批准记录、不授予新权限、不替代对象级鉴权；离线副本不能随撤权自动收回。

## 后端保护

原 GET 的请求/响应结构不变。新增返回前的完整成员复核，拒绝读取期间的权限版本变化、同版本能力集合变化、会话租户变化及存储返回的跨租户行。显式 `tenant_id` 读取仍可用于另一个已授权租户，同时复核当前会话租户与目标租户；目标范围撤权统一404，不泄露是否存在。
