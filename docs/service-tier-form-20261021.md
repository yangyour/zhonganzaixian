# 服务档位表单：严格整数、明确源版本与回执

基于 main fee3e50，前端修正，不修改后端/迁移/实际客户费用或商务批准。

## 修正

- 删除parseInt解析，避免1e3、1.9或尾随字符变成另一个整数。使用文本输入配numeric输入模式，避免Vue对number控件隐式转换后调用trim出错。
- 仅十进制非负整数通过；空白为null，0为明确0；设备数最大1,000,000，费用以分为单位且不超过9,007,199,254,740,990。非法值不变null、不截断、不提交，原输入保留。
- 先“按当前快照准备变更”，复制当前已读版本和原有值。新租户未知字段保持空，档位和生效方式必须明确选择；不补费用/设备数/周期默认值。
- 保存绑定准备版本；若最新回读已变更版本，阻止静默换版写入。重新准备前可取消丢弃提示，保留旧输入。
- 原回执核对租户、执行人、版本、目标档位、生效方式、设备数、周期和费用。错回执保留同一幂等请求恢复，不能用GET替代。
- 保存确认与回读分开：回读失败保留原回执，清空旧列表和旧数量；不重发成功写入。上下文在回读途中改变时不返回成功清除新范围输入。
- 撤权/换角色/租户清空费用、原因、工单查询和准备版本；SLA核验有独立AbortSignal，迟到结果不回填。离开/刷新保护未保存及未知写入。
- 卡片标为最新登记档位，不把登记冒充正式商务批准；加载未知不显示“未登记”假结论；增加历史第一页入口和键盘滚动区域。

## 证据

25项新增测试：17个解析/工作区回归、8个真实Vue/jsdom组件测试，覆盖原生输入事件、明确零与未知、越界和科学计数法、六类错误回执、原键恢复、版本变化、角色清理和读取取消。既有成功模拟修正为与原请求一致的完整回执，不放宽生产读取器。

本批没有新真实HTTP调用、浏览器/axe/客户验收，相关状态NOT_RUN。不能据此宣称真实合同费用获批、服务档位已由客户批准或正式赔付已执行。
