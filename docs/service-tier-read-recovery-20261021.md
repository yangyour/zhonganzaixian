# 服务档位台账与工单 SLA：独立读取恢复

基线 main 488331be926e72391f10d68da8cc7bd2a304503d。按[前端验收标准](frontend-acceptance-standard.md)落实取消、原目标恢复、输入保留和可达焦点，不修改API、费用、商务审批或SLA计时规则。

## 原目标与隔离

- 台账固定原before_version边界，失败或取消后重试不会跳回第一页。工单SLA固定原工单ID，重试不采用后来填写但未核验的文本。
- 两类GET有独立取消器和恢复目标；取消只停止当前前端读取，不撤销后台业务，也不清未知写入/原幂等键。迟到结果及旧finally不能解锁新请求。
- 已验证的档位最高版本跨读取失败保留；不能从已知版本退回更低版本或“未登记”。成功写回执同样建立版本下限，过旧回读拒绝显示，之后只用GET恢复。
- 同一当前核验工单保留最高workflow_version，失败恢复不接受更低版本；该记忆仅限最近成功核验对象，不是全站历史缓存。没有宣称GET构成原子快照，也不把同版本计时变化当作不可变事实。
- 撤权、账号变化和卸载清理原恢复目标及版本基线，原请求不可在新上下文重发。

## 可用性

取消状态、读取失败、台账标题和SLA结果标题有明确焦点落点；主动移动焦点后，完成的请求不抢回。工单UUID错误有可见说明并聚焦输入，不静默发送错误请求。

台账表格补caption及列标题scope；保留命名键盘滚动区。控件最小高度44px，小屏网格和SLA输入允许收缩，工具栏/视图切换可换行，焦点轮廓不被旧样式覆盖。这些为实现及组件层检查，尚无真实浏览器视口/axe通过证据。
