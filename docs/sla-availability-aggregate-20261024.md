# SLA 可用率的统一有效时长汇总

2026-10-24，M05/R03 子功能。此前 `slaReport` 对服务行的百分比做简单平均，服务窗口或批准排除时长不同时，各行被赋予相同权重。本次改为：**所有服务已核验可用毫秒之和 ÷ 所有服务有效服务毫秒之和 × 100**，只在最终比例按现有规则四舍五入到四位小数。

例如两个明确的测试服务分别为 1000 秒可用/1000 秒有效、0 秒可用/100 秒有效，汇总应为 90.9091%，原简单平均会得到 50%。这是计算边界示例，不是客户实际可用率。

## 计算、API 与页面

既有 `evaluateService` 继续返回原服务行；新增同一计算路径的 `ServiceEvaluation`，在投影为整数秒之前保留有效服务和已核验可用的毫秒度量。`ServiceAvailabilityAggregate` 对唯一服务人群汇总，拒绝重复身份、相互矛盾的度量、溢出或超出安全协议整数范围的数据，不对已舍入的行百分比再次平均。

批准排除、未知区间和现有覆盖资格判定保持：未知时间同时剔除分子与分母；没有观察来源的剩余时间仍未知。任一服务可用率尚未通过原覆盖门禁，总比例保持 null，不把该服务丢弃后只汇总其余服务。没有服务或有效分母为零也保持 null；确有完整不可用证据的零可用率仍为 0。

`GET /api/v1/sla/reports` 的 `kpis` 增加可选 `availability_aggregate`：

- `source_version=mop-availability-effective-milliseconds-v1`，标识计算口径，不表示已接入健康来源。
- `known_available_milliseconds`、`effective_service_milliseconds`：同一人群的精确分子/分母。
- `service_count`、`qualified_service_count`：全部与通过现有覆盖门禁的服务数。
- `coverage_status`：`NO_SERVICES`、`ALL_SERVICES_QUALIFIED` 或 `INSUFFICIENT_COVERAGE`。

原 `mean_verified_availability_pct` 字段继续保留，新投影的值来自上述度量。控制器核对汇总和服务人群；前端按口径版本、人数、秒/毫秒边界、未知/不可用总量及最终比例再次核对，拒绝带新标签却仍为简单平均的结果。旧响应可以不含该对象，前端不会为旧数据补造来源。

页面显示“按有效时长汇总可用率”、分子/分母和合格服务数；缺覆盖显示“样本不足”。服务核对 CSV 增加相同口径、度量、服务数、覆盖状态及汇总比例，旧响应的相应单元格留空。页面布局和菜单保持。原冻结月度工单/赔付记录、财务公式版本及候选金额没有重写；当前服务可用性读取仍是实时投影，不能冒充已冻结的跨业务报告。

## 验证和边界

[独立证据](evidence/sla-availability-aggregate-20261024/validation.json)记录：29 项 Java、137 项 Web、215 项契约与生成一致性通过；类型检查、生产构建和静态策略通过。Java 覆盖不等服务窗口、批准排除、未知双向剔除、单个服务不足、空人群、零分母、真实零、亚秒度量、去重、数值范围及 API 标签一致性。旧控制器夹具和冻结记录回读保持。

指定 LAN PostgreSQL17.9/活动V55 的 3 项实际场景执行、0失败/错误/跳过：新隔离租户缺健康来源时明确 null/0合格、另一租户使用自己的人群、无成员不返回空成功。测试只读取业务投影；工具另行准备并停用本轮 SYNTHETIC 主体/租户，保留记录。原实际租户保护摘要和迁移历史保持，0迁移、新组件、外发、部署。**该 PG 证据验证缺来源门禁和隔离，不是非空健康覆盖的来源联调。** 复验命令：`py -3 -X utf8 tools/verify-report-capture-isolated.py --suite sla-availability-aggregate --output .local/<新的目录>`；新套件必须有新鲜的3项 JUnit 结果，跳过不计通过。

实际 Edge 4 场景通过：1440px 加权结果/CSV、1024px 样本不足/CSV，以及原两项 MTTA/MTTR 未知与真实零回归。新增两场景均无整页横向溢出、axe零问题；实际下载文件中的分母、口径和空值已核对，权限撤销后清除结果。浏览器 API 是显式合成拦截，不是实时监控或客户验收。

开发中曾发现新测试上下文遗漏能力字段、范围格式脚本对 record/构造器重复选择、浏览器 Node JSON 导入属性缺失；分别由校验、编译和浏览器启动检查拒绝，修正后重跑通过，没有放宽验证或修改数据库。实际健康覆盖读取与完备性、同版本跨业务快照、可用性冻结/对账、客户赔付规则和正式 TC 继续保留，M05/R03 不整体标为完成。
