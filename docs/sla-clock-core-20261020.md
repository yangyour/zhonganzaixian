# D16 SLA 时钟与提醒候选核心

本批按剩余功能 D16 推进，不修改 V1–V32，不填客户未确认配置，不声称完整 SLA 服务已上线。

## 开单快照计算

新增 `SlaClockCalculator`，输入固定的开单时间、档位、优先级、配置发布引用、响应 / 恢复预算及明确日历版本。结果保留原开单快照，后续传入其他租户档位或日历不会回写原结果。

- 基础档复用 `WorkingTime`，只消耗明确工作窗口；缺日历、不完整覆盖或工作时间不足均返回无截止时间的 UNRESOLVED。
- 标准 / 进阶档按连续时间计算，覆盖跨夜、跨月、跨年和闰日。
- 基础 / 标准 P3 必须传入已解析的「次日」规则引用与截止时间；没有 Q08 口径则 NEXT_DAY_RULE_MISSING，不能拿四小时兜底。
- 续算从原开单时间与原预算开始。已完成暂停区间先并集，再从工作窗口中扣除，重叠不重复累计。
- Q27 必须显式选择包含全部时间或排除确认暂停；缺少策略或暂停历史不计算恢复截止。响应截止不因重开而重置。
- 日期型 P3 截止遇到需排除的暂停，保持 NEXT_DAY_PAUSE_RULE_MISSING，不擅自按秒移动客户「次日」规则。
- 开放的、终点未知的暂停不能伪装成已完成区间；未来仓储需单独保存并守卫暂停状态。

## 提醒计划

新增 `SlaReminderPlanner`，只读取显式进度节点和已持久化的去重键；不自带默认阈值或收件人。用大整数纳秒与十进制精确比较，50% 前一纳秒不提前触发；长时间跨度不发生 long 纳秒溢出。

稳定去重键为租户 + 工单 + 响应 / 恢复时钟 + 数值归一化进度。延迟扫描可列出所有已达到但未登记的节点；重复扫描在收到持久登记后不再次计划。暂停 / 完成时钟不生成计划；跨租户、跨工单或另一时钟的去重记录拒绝使用。

100% 节点产生升级计划标志，而不是执行电话、短信或其他通知。`claimed=false`、`delivered=false`；将来必须由持有租约的 Worker 在数据库事务内唯一占用键并写 D11 通知意图，不能仅靠此内存集合防并发重复。
