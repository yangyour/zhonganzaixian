# 工单 SLA 核对明细：任务、缺失配置与冻结来源

基线 main 6eb7c8bdf02cea07cbc7af2e4b4aacd7d53e3e81。补齐原接口已经返回但页面未展示的诊断明细，沿用完整性读取器及[前端验收标准](frontend-acceptance-standard.md)，不增加写接口或后台执行。

## 实际可用链路

在原工单SLA核验结果下增加三组独立明细：

1. 耐久时钟任务：任务键、类型、计划时间、原处理回执及完成时间。EMITTED明确为内部事件，绝不显示为外部邮件/企微/短信送达；没有回执不直接判为失败。过时任务与自动关闭回执分别标注。
2. 快照缺失配置：可读项目名、原始键和原始原因；不补时限/费用/审批默认值。空集合仅说明此快照未报告缺失，不代表全部配置已就绪。
3. 冻结配置来源：原键、合同默认/运行发布来源、发布ID、版本和完整SHA-256。合法版本0和null发布ID按原含义显示，不用假ID替代，不生成自动外链，也不声称来源已批准或已认证。

每组本地每页25条，首页/上页/下页/末页独立，全部已返回记录均可到达；不静默只取前N条，不暗示查询了其他租户或其他时点。顶部明确工单ID、流程版本和观察时间。本地翻页不调用网络、存储或后台任务。

## 交互及隔离

table caption、列标题scope、命名可聚焦滚动区、状态范围与分页导航齐全；翻页后焦点移到对应表格。新快照/工单重置页码，过期异步焦点与卸载不抢焦点；账号变化由父级立即卸载旧明细。长摘要/原始文本按纯文本换行显示，无HTML注入或自动执行。按钮44px、小屏表格可横向滚动。

该组件仅接收父级已经通过完整性校验的TicketSlaInspection，不是新的授权入口；服务端当前对象权限仍必需。冻结来源结构新增明确TypeScript类型，不改HTTP契约。
