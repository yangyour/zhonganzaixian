# SLA 报表的监控时间来源与精确恢复时钟

此前SLA页面的MTTA/MTTR取关联工单的创建/接单/恢复时间；无关联工单的监控事件不能进入统计，工单创建延迟也会缩短显示时长。本功能改为当前授权租户监控事件的原问题发生时间t0、首次人工确认t1和经过当前周期证明校验的t2。总卡片与逐资产行使用同一读取事务及来源算法，不使用工单解决时间替代监控恢复。

## 已实现的来源链

`PostgresOnCallEscalationRepository.slaReport`在既有REPEATABLE_READ只读事务内读取完整有界事件与当前周期恢复证明，MTTA复用`EventOperationalMetrics`，MTTR经`PostgresMonitoringRecoveryEvidence`核验后交给`MonitoringSlaLatency`。仍保留1000资产/10000事件技术预算；超限失败而不将局部样本当完整结果。

统计归属为所选上海自然月内首次问题发生的事件，月内截至实际读取时间，过去月份允许使用本次读取已知的后续确认/恢复事实。因此这是实时读取，不是历史月末快照；已经冻结的月度结果不改写。未来月份明确返回`SLA_PERIOD_NOT_OBSERVED`，不假报零故障。跨月故障区间的可用率处理沿用原实现，与故障发生月份的耗时样本归属分别计算。

MTTA仍为事件首次人工确认减原问题时间；新重载将样本月份边界与实际观察时刻分开，既有首页调用及其来源摘要保持。MTTR只接受经现有证明读取器验证的精确t2。RECOVERED但无证明单列unknown，PROBLEM且无恢复证明计未恢复；异常/缺失确认时间或不一致恢复时间不被丢弃来制造好看的均值。

## API、页面及导出

沿用`GET /api/v1/sla/reports`与服务详情路径。当前监控时长对象新增成对字段：

- `source_version=mop-event-acknowledgement-v1`：事件确认时间。
- `source_version=mop-monitoring-recovery-t2-v1`：经核验的监控恢复时间。
- `unknown_count`：存在但未通过来源/时刻核验的记录数；与已验证`sample_count`、仍未恢复`unrecovered_count`分开。

只要一个时长人群含未知来源，均值/P50/P95均为null，保留已知样本和未知数量。真实零可为0，无样本保持null。前端核对成对字段和正确的时钟版本，拒绝混用或伪装；卡片和服务行显示“来源待核验”，不将其显示为零或普通“暂无样本”。核对CSV追加相应来源版本和未知数量列，旧投影留空，不给旧数据补造证明。

旧五字段时长DTO继续可读；冻结月度结果及财务公式版本不重写。新增字段未改变既有租户权限、CSRF、原请求恢复、配额或审批设置。

## 精度修复

指定环境联调发现，现有已验证t2可以含纳秒，而月度核算复用了公开试算的毫秒输入校验，导致报表失败。本次将纯比较逻辑共用，增加仅sla包内可用的`SourceEvidence`；来源读取路径保留精确恢复Instant，公开`Evidence`及其API仍拒绝调用方纳秒输入，没有新增可信标志或可由请求切换的验证模式。

真实截止比较使用原Instant，截止后1纳秒仍为NOT_MET。监控统计保留纳秒至聚合完成，最后将秒级显示统一half-up舍入，避免先截断每条样本造成均值/中位数变化；该显示舍入不参与SLA判定。月度判断回执和新冻结结果保留原始恢复时刻。金额及未确认补偿规则依旧为空/待配置。

## 验证及保留范围

验证计数、失败与复测、源码/环境依据见[验证摘要](evidence/sla-monitoring-source-20261024/validation.json)。Java4179执行/1131条件跳过，前端5522项，Node271项通过；指定PG10执行/1可选实时来源跳过，Edge两桌面视口合成读取通过。目前纯单元覆盖精确t0/t1/t2、纳秒边界、无证据/异常时间、历史月份与真实零；组件检查分别验证当前公开接口与冻结结果。实际测试始终复用指定LAN现有PG17.9，使用新隔离命名空间；不使用旧真实租户或恢复历史测试身份。

首轮发现可空first_ack_at使用了非空读取帮助函数，修正为已有nullableTime。第二轮发现上述纳秒与公开试算精度不兼容，新增内部来源路径。第三轮月度冻结按预期被缺少租户档位挡住，保留门禁并为本轮新隔离租户显式登记SYNTHETIC STANDARD档位、费用null，再复验。失败记录保留，不修改活动客户规则。

本功能未完成可用率统一有效分母聚合、健康采样覆盖、全部经营指标、外部ITSM、真实设备故障正向恢复/完整V42浏览器链、对账审批及客户正式验收。原均值可用率字段未在本功能冒充完成统一指标服务；M05/R01/R03整组仍未完成。HTTPS按用户要求后置，不部署、不外发、不做生产启用。
