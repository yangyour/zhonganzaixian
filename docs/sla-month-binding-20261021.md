# SLA 月报期次绑定与保存回执

基于 main 5366177，仅前端；不执行真实冻结、不变更正式费用/赔付、不新增迁移。

## 缺陷及修正

- 去掉页面写死的2026-10默认月份，进入页面要求明确选择。角色/权限/租户变化清空月份及冻结勾选，不跨上下文沿用。
- 月份输入变化会撤销冻结勾选。已读报告如果仍为旧月，明确显示旧期次提示并禁用保存；必须先查询新月。
- 工作区保存要求已读取的同一月份、相同版本、未冻结记录、布尔冻结选择和合法幂等键。不能用甲月版本保存乙月。
- 新月读取前清空旧报告和明细，失败不保留旧成功快照。
- 原实现忽略POST正文，任何2xx都会当成功。现在严格核对回执结构、租户、月份、执行人、预期版本+1、冻结选择、时刻和计数基本类型。错误/缺失回执保持原请求未知，不用随后GET推断写入完成。
- 请求/重试及传输body独立复制，调用方或传输层修改不能改原幂等身份。恢复直接使用原期次，不回退到硬编码日期。
- 已核对写回执与随后只读回查分开：回查失败仍保留成功回执、旧报告清空，允许手动查询而不重复POST。
- beforeunload与原路由守卫都保护未知写入。

## 验证边界

新增16项测试（13工作区/3组件），覆盖跨月/错版本/未读/已冻结拒绝、6类错误回执原键重试、回读失败、调用方及传输修改、显式月份、冻结勾选重置、角色变化。既有7项SLA/值班测试继续通过。夹具来自既有Java控制器生成数据，对未冻结编辑场景明确使用合成变体。

新真实HTTP/浏览器/客户对账验收NOT_RUN。本次不声称补偿公式已获得客户批准、正式赔付可执行或合同TC通过。固定值/历史公式兼容边界不变。
