# SLA 月报读取恢复与键盘可用性

基线 main e7420b96f5e6159d9f2116788e05cda7dfca6788。只调整前端，不改变任何统计公式、赔付金额、冻结规则、后端API或数据库。

- 月报及服务明细读取期间提供明确取消入口；中止网络并增加请求世代，忽略不遵守AbortSignal的迟到响应。取消后可重新查询，不持续锁住月份输入。
- 只取消读取，不取消POST，不清除结果未知的原请求或固定幂等键。已确认保存但回读被取消时仍保留保存回执，不显示保存失败、不重新提交。
- 取消后回到发起查询或服务明细按钮；成功读取详情后焦点移至明细标题。身份变化、卸载、较新请求之后不会迟到抢焦点。
- 账号版本变化同租户、用户、权限、角色变化一样，立即清除月份、冻结选择、旧数据与状态通知。
- 可横向滚动的SLA表增加键盘焦点、可读区域名称与可见焦点样式。保留44px交互目标。
- 状态文字区分读取、取消、保存回执。开始写入/原请求重试时清除旧的读取提示，不能用读取成功替代保存成功。

验证依据 frontend-acceptance-standard.md。新增4项工作区和4项真实Vue DOM测试，覆盖不响应abort的网络、POST不可取消、回执后读取取消、永久卸载、账号版本、焦点和滚动表格。浏览器/axe与正式TC仍为NOT_RUN，DOM焦点不替代真实浏览器及辅助技术验收。
