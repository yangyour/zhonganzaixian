# SLA 当前服务核对 CSV（2026-10-21）

## 可用任务

在 SLA 月报选择月份并成功读取后，可使用“导出当前服务核对 CSV”。文件绑定当前租户、实际读取月份、服务端 observed_at、Asia/Shanghai、公式版本及已加载服务条数。导出不发 GET/POST，不保存或冻结月报，不发布报告或发送给第三方。

范围固定 CURRENT_LOADED_LIVE_SERVICES_ONLY：只包含本次接收的服务可用性与延迟统计，不代表完整租户资产台账。历史已冻结月度结果、工单明细/说明、区间原文、费用及赔付候选金额均不导出。每行保留 formally_published=false、financial_bill=false、frozen_result_included=false，文件不是正式报告或账单。

## 交互与数据保护

- 使用同一严格月报读取器再次核对范围和数据；不从输入框拼造另一月份的数据。
- 输入月份与当前结果不同时禁用导出；在读取、未知写入或生成中不能发起重复导出。
- 生成前让页面更新一次状态，再核对当前账号/租户/权限/报告身份。账号变化、换月、结果替换或离开页面会取消待生成下载。
- 对象 URL 创建前、创建后及点击前都核对当前范围；下载失败仍保留月报，提示可见错误，不假称文件已经保存。
- 成功文案仅表示已生成并请求浏览器下载，是否保存由浏览器确认。链接在 finally 移除，对象 URL 在 1 秒后通过创建时的 URL 对象释放；创建链接失败同样释放。
- UTF-8 BOM、CRLF、完整引号转义；公式风险文本、前导零数字样式及 16 位以上纯数字加单引号，不使用会执行的 Excel 公式来保留格式。使用方仍应按文本列导入标识，不以电子表格自动转型后的内容替代系统来源。
- null 为留空，明确零为 0；零服务仍导出范围 SUMMARY，不伪造一行“健康”服务。
- 技术保护：沿用读取器最多 1000 个服务，单格最多 10000 UTF-16 字符，文件最多 8 MiB。超过时拒绝，不截断。
