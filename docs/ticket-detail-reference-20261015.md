# 客户参考图：工单详情

依据：用户于 2026-10-15 提供的工单详情截图。图片用于页面结构和交互参考；截图中的公司、人员、工时、P1 两小时等是示例，不能作为客户已批准规则或导入数据。

## 本轮实现与边界

详情改为宽屏双栏：阶段栏、左侧基本信息、右侧真实动态和本人工时、附件/登记凭证折叠区、底部操作入口。手机按单栏重排，工时表独立横滚。

内部处理记录沿用不可变内部备注，客户沟通沿用原评论，工时沿用本人手填区间。保存回执确认后刷新详情。三个来源分别鉴权、校验、加载和报错；切换租户/权限时清空并丢弃旧响应。明示动态各最新 15 条以及工时当前页，不将其标成全部人员或整单总工时。累计使用整数毫秒计算。

“导出详情”下载当前成功读取范围的 UTF-8 文本，保留范围说明、联系方式掩码及未知状态。读取失败或进行中禁止导出。导出不会写库、触发通知或上传文件。

后端现有登记 DTO 的正式状态、优先级和 SLA 均为 null；阶段栏仅将报障发起标为已记录。受理/定位/方案/完结/确认不会依据评论文字推算。转派、挂起、协助缺少后端流程，按钮明确禁用；没有伪造成功或改动客户规则。新增处理记录不等于正式阶段流转。客户界面不加载或展示内部记录与本人工时。

## API 与运行

无新增或改动 HTTP 契约、数据库、迁移和组件。复用 `GET /tickets/{id}`、`GET /tickets/{id}/internal-notes?page_size=15`、`GET /tickets/{id}/comments?page_size=15`、`GET /tickets/{id}/worklogs?page_size=15` 及原面板的写入接口。原 CSRF、幂等、父版本、审计与不确定结果重试保持。`contracts/local-api.openapi.json` 为实际契约。

本地运行 `apps/web`：设置 `MOP_API_PROXY_TARGET` 指向指定测试 API，再运行 `npm run dev -- --port 5186`。仅启动 Web，外部依赖沿用指定 LAN 测试服务器；不使用 fixture 作为联调替代。

## QA 清单（执行前）

- 基本信息、六阶段、真实动态、本人工时及精确汇总；未知状态不伪造，联系人默认掩码。
- 导出文本内容/范围/无 HTML 执行；新增内部记录、客户沟通与工时保存后回读刷新。
- 返回列表、刷新详情、附件/凭证折叠、本人记录分页入口、保留原编辑器与写入恢复。
- 客户角色不读取内部记录/工时；租户或权限切换丢弃迟到响应。
- 异常探索：一个数据来源失败保留其他真实来源；工时失败清空旧累计，禁止导出；恢复可重试。
- 桌面 1440/1920、手机 390/320 和矮屏 844×390；正文重排、表格独立滚动、关闭入口可达、键盘焦点与长文本。
- 单元替身仅验证纯前端状态；真实浏览器独立使用指定测试 API 和明确的虚构测试数据。API/生产批准/客户完整工单流程与 128 项合同验收分别记录。

## 实际验证结果

在最新 ac8dae9 基线上，155 个前端测试文件共 2,194 项全部通过（本轮新增 12 项）；135 项实际 API 契约检查及生成一致性通过；vue-tsc、Vite 生产构建、静态完整性和策略检查通过。最终静态 build_id 为 210f673d36986ba15fc3951407348f73fa0f0c1a3a9afd892d28a2b7430aa681。

指定 lan-test-20261008 实时只读盘点：14 个项目容器运行，PostgreSQL 17.9 / schema V32 / Java 17.0.20.1，ready=true、production_ready=false。无新增组件、迁移、安装、重启或配置更改；只创建一条明确标记的虚构报障、一个内部备注、一条虚构客户可见评论和三条工时（30 分远程、30 分现场、12 分路程），保留审计及测试记录，不删除历史。未向真实客户发送通知。

浏览器使用本地生产静态文件和指定服务器真实 API。直接 localhost 登录被服务端来源校验拒绝；真实内网域名加载本地静态候选时 Edge 私网地址空间检查阻止浏览器直连。测试仅通过 Playwright route.fetch 转发原始真实 API 响应，未伪造响应、身份或成功结果，未更改服务端 CSRF/Origin 保护。此为候选构建联调，不是测试站已发布。

已验证内部备注、客户沟通和本人实填工时经页面保存后自动回显；三个工时间隔准确汇总为 1 小时 12 分，其中处理 1 小时、路程 12 分。真实文本下载含限定读取范围和掩码联系方式。客户角色未请求内部备注/工时且看不到内部内容。工时读取中断会清除旧累计、禁止导出，其他成功来源仍保留，恢复后可独立重试。

1920×945、1440×1000、1024×900、768×1024、390×844、320×844、844×390 共七个视口无整页/抽屉横向溢出，表格单独滚动，关闭入口可达。桌面左右卡片上下沿一致；手机按页滚动，照片及登记凭证在独立折叠区。连续三轮关闭、快速重新打开、Escape 验证通过；关闭导航失败时保留详情与路由，恢复后重试成功。修复了抽屉提前关闭与异步路由结果不同步的问题。
