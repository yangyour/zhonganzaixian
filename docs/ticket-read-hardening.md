# 工单登记Unicode搜索与失效会话防护

## 实现

GET /tickets的收据号/标题/描述搜索从数据库默认lower改为既有pg_catalog.und-x-icu根locale小写后的字面子串。真实niko库默认C/C locale此前遗漏Ä等非ASCII匹配；新测试先复现后修复。原文不变，不作Unicode归一、音译或通配符解释；百分号/下划线/引号仍是普通查询文本。保留原category/urgency枚举、最多100个Unicode码点、创建时间/id升序keyset、签名cursor和10/15/25/50/100技术分页。

客户仍只能查询本人登记，内部角色仍仅当前授权租户；SQL继续核验活跃用户/成员、权限版本及角色。没有扩大到客户全租户共享，没有新增正式工单状态或SLA事实。记录中的state/priority/external_id/截止时间仍可为null。

TicketController在进入任何读/写动作前，拒绝非字符串/空白租户会话和inactive成员，返回401，不因强制类型转换产生500。实际异常advice和安全拒绝响应原先还会再次强转会话租户，新增两项隔离测试复现ClassCastException后修正为共享安全取值：非字符串/空白上下文的拒绝审计tenant为null，拒绝事件仍记录；没有关闭审计。该分支经真实controller/advice的MockMvc及安全响应方法验证，未篡改真实OIDC服务端会话来冒充真实HTTP验收。

OpenAPI V0.16.1补齐既有查询枚举、q的100码点限制和字面语义；响应结构及租户/报告人权限不变。ICU沿用已验证的现有依赖与就绪检查，不修改数据库全局locale、组件权限或schema。V1–V10及原私有配置不改；原服务器可用性仍B01。

## 失败也保留

1. 首次新增PG测试中2项失败，默认C locale大小写查询遗漏；使用既有ICU表达式后10项报障PG测试通过
2. 首次6控制器测试中2项失败：inactive成员未提前拒绝、非字符串租户强转；修复后继续加测实际advice/安全错误写入，8项中另2项因审计二次强转报错；共享安全取值后最终全根通过
3. 契约升级初次测试仍断言旧0.16.0，1项失败；版本断言同步后30项通过。未把旧断言失败解释为接口已通过
4. 首轮HTTP在最后审计比较失败，因为拒绝查询本就写DENIED审计；修正验收窗口而非关闭审计。第二轮描述查询因之前试跑留下同描述数据而命中额外记录；将每轮唯一前缀纳入描述后第三轮62项通过。失败轮的合成记录/日志保留，不删除后重写历史，也不累计失败轮为新增通过用例
