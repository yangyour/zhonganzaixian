# D08 时间区间计算基础

`cn.mop.domain.time.IntervalSets` 实现确定的区间数学，供后续SLA、报告及指标服务复用。本轮没有新增HTTP接口、运行配置或数据库表，没有生成可用率、达标、赔付或SLA截止时间。

## 运算契约

- 输入为绝对时刻 `Instant` 的左闭右开区间 `[start,end)`，必须 `start < end`
- `union` 处理无序、重叠、嵌套、重复及首尾相接区间，返回按时间排序且互不相交的不可变集合
- `intersection` 求交；只在边界接触的两个区间没有共同时间
- `subtract` 做集合差；是否可以排除某个维护/故障区间由另行批准的业务规则决定
- `clip` 按明确窗口裁剪，原始输入不修改；月份窗口由调用方按Asia/Shanghai业务时区生成后转换为Instant
- `duration` 先求并集再累计 `Duration`，保留纳秒精度，不使用浮点数，不重复计算重叠时间
- 已知空集合的时长为0；null集合、null区间或缺失窗口拒绝，不自动解释成空数据或正常

## 不能代替的业务证据

调用方须保留原始事件/采样引用、来源时间、规则版本和数据完整性。这个工具不判断采样质量，不把未知区间计为可用，不默认移除未知分母，不批准维护排除或服务树权重。Q05未知口径、Q08工作日历/次日、Q26补偿及Q27重开统计等仍保持未确认；未确认时正式结果继续null/CONFIG_PENDING。

没有调用监控、PG、API或本机替代组件。纯输入测试可证明集合运算，不能证明真实采样、月报同源、性能合同或完整D08完成。

## 可复核验证

16项JUnit覆盖空/未知输入、重叠/嵌套/重复/相接/分离、差集分裂及跨多个区间排除、纳秒、跨月/闰日/跨年、不同时区偏移对应同一Instant和不可变性。其中一个测试用固定随机种子产生500组输入，与独立逐秒布尔集合判定比较，不用实现本身生成期望值；500组不另算500项JUnit。

复现：`mvn -B -ntp -C -pl server/api -am -Dtest=IntervalSetsTest -Dsurefire.failIfNoSpecifiedTests=false test`。本轮结果见[证据](evidence/dot-interval-sets-20261002.json)。现有API V0.8和V1–V6迁移不变。
