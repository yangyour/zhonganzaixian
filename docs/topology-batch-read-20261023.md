# 拓扑批量读取与站点契约修正

接续 e84f80f 说明书复核，并保留上传期间至ecce9434的上游新功能，保持 API 0.83 字段与前端不变，无迁移、权限授予、真实客户数据写入或部署。

## 查询实现

PlatformRepository 增加 authorizedAssetBatch，默认仓储不支持时明确503，不退回未授权 find/list。PostgresPlatformRepository 对最多101个规范且唯一UUID执行参数化 ANY(uuid[]) 选择，不拼接输入、不读整个租户台账。返回当前租户可见记录，缺失ID不补造。

批次授权、有效权限与资产读取共用只读 REPEATABLE_READ 快照、同一连接。空批次在仓储层仍检查授权；控制器空图没有节点时无须调用批次。语句超时和异常回滚沿用当前仓储策略，JDBC数组总是释放。

客户拓扑先收集本页实际端点（及可选聚焦设备），再进行一次批量资产SELECT。聚焦设备仍先单独检查可见性，避免用图版本或计数泄漏外部对象；批次结果缺失、重复、额外节点或跨租户立即失败，不返回部分图。结果节点顺序按原请求顺序恢复，返回前完整成员复核保持。

测试证明101个节点只需一次资产SELECT，而不是101次；该批次包含另外两条授权SQL。此为JDBC调用结构验证，不声称真实数据库P95性能提升比例。登记图与节点批次仍分别读取，不伪称整份响应在一个事务。

## 站点编码修正

检查 V1 mop_site 定义及资产台账时发现，站点ID是 varchar(64) 代码，而新增拓扑 OpenAPI schema误用了UUID。现修正site_id为与既有台账一致的字符串，加入site-a-main合法、数字非法的契约回归。真实数据无需迁移或改名，客户端字段形状不变。演示准备来源锁及golden同步更新，账号/数据仍未创建。

返回更新时间同时显式投影为ISO字符串，避免不同MVC/Jackson日期序列化设置将其变成数字而违反契约。非空图的MVC回归覆盖此边界。
