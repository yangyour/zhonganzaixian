# 内容区交互与样式重设计（2026-10-23）

## 用户要求与范围

2026-10-23 用户明确要求：“帮我优化我的前端交互、整体样式，不要改变菜单栏样式，剩下的都可以大改，结合系统情况，逐页进行优化，合同里面，附件有个工作说明书，根据这个来”。此要求覆盖 [样式基线](ui-style-baseline-20261022.md) 中“不得自行修改既有视觉样式”的限制，但菜单栏除外。

同日用户补充：“先只改web的，手机端后续优化”。自第二批起只改造并验收桌面 Web（≥1024 CSS 像素）；窄屏只保留防止新版式错位的回流规则，不做专门优化，发现的问题登记在下文“手机端待优化”。

- **菜单栏不变**：顶部模块导航、工作区侧栏、面包屑/租户栏和移动导航抽屉继续使用 `navigation.css`、`HorizontalModuleNavigation.vue`、`SidebarNavigation.vue`，各批均未修改。`App.vue` 仅新增一行 `theme.css` 导入。
- **依据**：合同附件一《工作说明书》M1–M10 条款（`doc/development/evidence/contract_requirements.json` 的 128 项原文提取），结合当前接口实际能力。未接入的指标继续显示“未知/接入中/未接入”，不以占位数值、演示曲线或前端推算冒充合同指标；SLA 超时仍由服务端判定，前端只显示服务端下发的截止时间。
- **逐页实施**：按模块分批改造、验证并提交，下表记录进度；未改造页面先继承新的公共主题层。

## 公共主题层 `apps/web/src/styles/theme.css`

只作用于 `#main-content` 及弹层，最后导入，覆盖旧的分层样式：

- 设计令牌：文字/边框/画布/主色，正常、问题、警告、信息、维护、未知六类状态色；严重级别按 M4-5“灾难/严重/一般/警告/信息/未分类”单独配色并用方角，区别于圆角状态徽标。
- 卡片与卡片头、工具栏、分段控件（时间范围、视图、资源类型）、KPI 卡、数据表（原生与 Element Plus）、标签页、事实网格、分页页脚、内联错误与提示。
- “未接入/未知”使用斜纹虚线区块（与 M1-4“未知区间用斜纹”一致），不再显示为空白或健康外观；空结果改为简洁文字与可执行操作。
- 数据新鲜度指示（M1-9）：读取中、实时、失败三态圆点。
- 窄屏或粗指针设备的标签页和恢复按钮保持 44px 触控目标，分段控件目前为 40px（见“手机端待优化”）；尊重 `prefers-reduced-motion`。

- 六张 KPI 卡（M1-1）：取值仍为未知；补齐分项（正常/未知、五级问题计数、已超 SLA、受理/送达），每张卡按菜单相同的路由门禁提供下钻入口：资产列表、事件中心、SLA 报表、工单处理、工单通知；无权限目标不渲染链接，下钻沿用当前会话租户。
- 告警趋势（M1-2）：原始/归并后图例、“降噪率未知”徽标与三层降噪链说明；服务健康（M1-3）固定三态图例；故障时间线（M1-4）使用服务端 `last_24_hours` 区间生成 6 小时刻度，整段以斜纹显示“数据缺失记为未知”。
- 最近事件（M1-5）改为“级别/问题/资产/状态/发生时间”五列表格，合并显示 ×N、抑制显示“已抑制”，问题链接进入事件详情，资产列链接到资产详情（需 `assets:read`）。

## 手机端待优化（登记，未修改）

用户要求本阶段先改桌面 Web。合成预览 320/390/768 检查发现以下窄屏问题，均由既有规则造成，本阶段不改：

- 内容区文字/链接按钮窄屏仍为 28px：`controls.css` 的 `:is(#main-content, …) .el-button:is(.is-text, .is-link)` 规则（2026-10-22 `251ea43c` 引入）含 ID 选择器，压过 `experience.css`、`prototype.css` 的窄屏 44px 规则，低于 [验收标准](frontend-acceptance-standard.md) §9 的 44×44 产品目标（仍高于 WCAG 24×24 下限）。
- `theme.css` 窄屏/粗指针块的分段控件为 40px，与同块注释“44px targets”不一致。
- 资产状态分段在 375px 宽只显示前 5 项，“已停用”在无提示的横向滚动里。
- 基础网络监控防火墙行的 CPU/内存内联链接窄屏为 40px，768px 宽为 24px。
- 内容区原生按钮（如租户资源台账名称）窄屏/粗指针仍为 36px：`experience.css` 第 38 行 `#main-content button:not([class*="el-"])` 的特异性高于同文件 760px 媒体查询内的 `#main-content button { min-height: 44px }` 及页面窄屏规则；375 宽合成预览实测 36px。第三批的 28px 规则只作用于宽屏细指针，未改变这一行为。
- 本地已验证、未提交的修正思路：文字/链接按钮改用随触控目标切换的高度变量（宽屏 28px，窄屏/粗指针 44px）；分段控件窄屏 44px 并换行显示全部选项。

## 合成预览（开发专用）

真实账号登录做界面复核未获授权，各批视觉检查改用页面内合成接口，不访问任何服务器：

```bash
cd apps/web
MOP_API_PROXY_TARGET=http://127.0.0.1:9 npx vite --config qa/vite.preview.config.ts
```

打开 `http://127.0.0.1:5173/dashboard`。`qa/synthetic-api.ts` 在页面内应答 `/api/v1/*`，写操作一律返回 405 且不发送；`?preview_role=msp|tadmin|viewer` 切换岗位，`?preview_fail=<路由名>` 构造读取失败。名称与标识均为虚构，地址取 RFC 5737 文档网段；唯一例外是演示防火墙资源面板的一行：`readResources()` 只接受指定测试设备地址，因此沿用该地址（不是凭据，仓库既有文档已有记录）。左下角固定标识“合成预览”。该入口不进入生产构建，不是联调、合同或浏览器验收证据。
