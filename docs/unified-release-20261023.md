1. 合并后的OpenAPI增加了其他会话端点，演示准备目录仍固定旧契约摘要。审阅差异后同步契约指纹及派生golden；没有生成演示账号或业务记录。
2. 历史POSIX工具在Windows受文件权限、符号链接和编码限制。保留首次失败，改在服务器独立临时目录运行相关纯单元测试；测试进程采用0077，不修改服务器全局配置、不安装组件。最终所有适用检查通过。3项跳过分别为Windows符号链接限制2项、未显式提供Prometheus二进制1项。
3. 首轮`8b769289`已发布并通过452HTTP和40个四视口读取场景，但首页浅灰说明及窄屏“未知”文字对比度不足。限定首页复用已有深灰色变量后，形成最终`2291ddf8`重新发布；[修正记录](dashboard-contrast-20261023.md)。
4. 浏览器脚本最初假定登录落在首页，实际配置落在资产页；另一次返回检查早于路由恢复，已等待真实界面后复验。持久会话的报告引用也经核对修正，最终强制校验20场景／29交互／2次axe数量，未用空数组当成功。保留初轮记录，不列为应用缺陷。
