## 1. 列表—详情—返回

- 资产与报障从列表进入详情采用独立浏览历史入口。当前页内连续查看上一条/下一条替换同一个详情入口，浏览器后退仍回到原列表。
- 显示“本页第 n / m 条”，不将本页数量冒充全局总数；直接链接或不在当前结果集内的记录不显示邻项按钮。
