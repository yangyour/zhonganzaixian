## 1. 列表—详情—返回

- 资产与报障从列表进入详情采用独立浏览历史入口。当前页内连续查看上一条/下一条替换同一个详情入口，浏览器后退仍回到原列表。
- 显示“本页第 n / m 条”，不将本页数量冒充全局总数；直接链接或不在当前结果集内的记录不显示邻项按钮。
- 保留筛选、分页游标、每页条数及未提交筛选输入。返回时恢复列表滚动、表格横向位置及原触发按钮焦点。
- 返回按钮只在浏览器的上一项确实属于本次同一授权范围的列表时后退；深链接通过当前页面清除详情参数返回列表，不离开系统。
- 授权范围变化清除位置记忆，取消或被原有路由守卫拒绝的操作不改变当前详情。工单已有编辑/未知提交保护继续生效。
- 工单详情抽屉保持组件实例，切换记录不重新创建整个弹层；关闭动画后恢复列表焦点。

## 2. 筛选编辑与查询结果分离

资产和报障的待应用提示新增“应用筛选 / 撤销修改”。撤销仅恢复已应用的输入，不清空当前查询、不回首页、不重新请求；应用仍使用既有中文输入法保护、显式查询及第一页规则。两条路径都将焦点交还搜索输入框，避免按钮消失后焦点丢到页面根部。筛选标签的可访问名称包含完整可见文本，单项移除不误应用其他未提交输入。

## 3. 资产列表—导出准备—返回原筛选列表

从资产列表进入导出时，通过本次浏览历史状态带入已应用的关键词、类型、状态及站点，同时保留原列表分页游标和每页条数用于返回。分页参数不进入导出 API 过滤条件，页面明确说明导出全部匹配记录，不仅当前页。存在尚未应用的筛选时，导出按钮先禁用并说明需应用或撤销修改。
