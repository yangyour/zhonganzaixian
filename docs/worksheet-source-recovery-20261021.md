# 人工执行单来源读取的取消与原页恢复

## 可完成的恢复路径

- 资产候选失败/取消后重试原查询与不透明游标；模板候选保留原查询与成对时间/ID游标。重试不退回第一页，不自动选择第一项。
- 来源GET和准备新单前的双来源核对都有独立取消按钮，位于禁用区域之外。取消使本页来源读取停止等待、解锁原表单，焦点进入具名状态提示；不会保存执行单或运行扫描。
- 原人工结果、备注和时间不被取消清空。候选查询开始时已清除的旧候选不会假装仍有效；迟到响应不能重新填回。
- 资产/模板查询变更清理相应旧列表和选择，并作废原恢复目标；不会把新查询与旧游标拼接。
- 来源核对重试固定原资产ID、模板ID/版本/摘要和确认时原始输入。保持原输入时可恢复同一次准备，不重发写入；结果、备注、时间或选择一旦改变，旧核对立即作废，需要重新明确准备。
- 模板来源已变化时提示刷新和重新选择，不提供无意义的旧来源核对重试。无效本地查询未发请求，也没有伪造的重试入口。
- 未知写入保留原请求身份，来源恢复不能取消写入、另建命令或证明已经成功。强制账号范围变化清理所有旧恢复目标。

遵循[前端验收标准](frontend-acceptance-standard.md)的错误恢复、键盘焦点、忙碌语义和原始输入保护。未新增API或自动设备操作。
