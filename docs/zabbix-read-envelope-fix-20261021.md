# Zabbix读取响应信封校验修复（2026-10-21）

## 复现

准备扩展事件读取时，对既有ZabbixReadClient.decode加入3项定向测试。原实现有2项预期拒绝测试失败：

1. 请求ID为1时，返回超出long范围的整数18446744073709551617，longValue截断后变成1，错误通过匹配。
2. jsonrpc为数字2.0时，asText转换为字符串“2.0”，错误通过协议版本校验。

这是隔离构造响应复现，不证明真实Zabbix返回过这些数据或项目曾被利用。第三项正常字符串版本/精确ID/数组结果验证继续通过。

## 修复

必须先确认响应ID可无损转换为long，再比较请求ID；协议版本必须是文本节点且严格等于“2.0”。保留原有固定只读方法、认证方式、loopback端点限制、正文上限、JSON重复键与尾随内容拒绝、错误脱敏，不新增方法或网络权限。

## 验证

修复后3项定向测试通过；完整Maven verify为2283项执行、897项环境跳过，0失败/错误。前后回归明确保留了失败复现和修复后结果。没有使用真实凭据、网络连接或供应商响应，不增加真实事件接收/处理验收状态。
