# 客户网络拓扑

入口：左侧“监控 → 网络拓扑”，以及租户管理表格中的“查看拓扑”。原型首页也已加入页面入口。

每个客户单独维护一张拓扑，支持站点分组、设备和链路详情、名称修改、拖动与方向键调整位置、添加和删除节点、添加和删除连线、保存及取消修改。节点可绑定本客户已有资产，并跳转监控详情；链路可维护两端端口、带宽、VLAN、类型和状态。移除节点只修改拓扑，同时清理关联连线，不删除监控资产。

全部租户视图显示客户拓扑列表，不合并客户设备。观察者只读；客户管理员、MSP 工程师和平台管理员可编辑。拓扑按客户独立保存在浏览器本地，刷新后保留，支持 JSON 导出；保存时检查版本冲突，并记录可在审计页查看的本地维护记录。未保存的草稿切换客户时经提示保留，关闭或离开页面前提示保存。

初始拓扑是基于现有资产生成的演示关系，并非自动发现的真实网络。关联资产沿用原型中已有的监控状态；未配置独立监测的节点或链路显示未知，不伪造正常、延迟或流量。

沿用既有布局和设计样式，没有新增手机端或桌面尺寸适配。无外部库或网络依赖，可直接打开 `network-topology.html`。
